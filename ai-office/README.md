# 🌲 꿀TMI 숲 사무실

숲속 동물 직원 7명에게 블로그 일을 맡기는 나만의 AI 사무실입니다.
직원들은 **사무실 서버를 켠 컴퓨터에 로그인된 Claude Code**로 실제 작업(자료조사, 글쓰기, 도식, SEO, 검수, 홍보 문안)을 합니다. API 키는 쓰지 않습니다.

맥북·윈도우·휴대폰 어디서 열어도 **같은 사무실**이 보이고, 대화·작업 보드가 실시간으로 맞춰집니다.

```
 [사무실 서버: 맥북 또는 윈도우 중 한 대]  ← claude 로그인, 실제 작업은 여기서
        ▲            ▲             ▲
   그 컴퓨터 브라우저   다른 컴퓨터     휴대폰 (Tailscale 또는 같은 와이파이, 6자리 숫자로 접속)
```

## 직원

| 이름 | 동물 | 역할 |
| --- | --- | --- |
| 솔이 | 사슴 | 편집장(팀장). 일을 쪼개 팀원에게 나눠 주고 결과를 검수해 보고 |
| 부엉 | 부엉이 | 자료조사. 공식 출처·확인일 정리 |
| 도토 | 다람쥐 | 글쓰기. posts/ 서식에 맞춘 HTML |
| 모찌 | 토끼 | 도식·이미지. assets/ SVG·썸네일 |
| 여울 | 여우 | SEO·발행 준비. 메타·목록·사이트맵 |
| 밤송 | 고슴도치 | 검수. 사실·링크·모바일·광고 정책 |
| 덕구 | 오리 | 홍보 문안. promotion-*.md |

역할은 `agents.js`에서 바꿀 수 있습니다. 직원은 **git commit·push를 하지 않습니다.** 발행은 직접 확인한 뒤 하세요.

## 처음 켜기

필요한 것: Node.js 18 이상(https://nodejs.org LTS), Claude Code(`claude` 명령, 한 번 실행해서 로그인).

1. 이 저장소를 사무실로 쓸 컴퓨터에 내려받습니다 (`git clone` 후 `git checkout ccr-daf5d621-o4grpg`).
2. 실행
   - **맥**: `ai-office/start.command` 더블클릭 (처음엔 우클릭 → 열기)
   - **윈도우**: `ai-office\start.bat` 더블클릭
   - 터미널: `cd ai-office && node server.js`
3. 브라우저에 `http://localhost:4747` 이 열립니다. 직원을 누르고 일을 적으세요.

작업 폴더는 기본으로 이 블로그 저장소입니다. 채팅창 위 📁 줄을 눌러 바꿀 수 있습니다.

## 휴대폰·다른 컴퓨터에서 쓰기

1. 사무실 컴퓨터와 휴대폰(또는 다른 노트북)에 **Tailscale**을 깔고 같은 계정으로 로그인합니다. 같은 와이파이라면 생략 가능.
2. 사무실 화면 위쪽 **📱 기기 연결**을 누르면 주소와 6자리 숫자가 나옵니다.
3. 다른 기기에서 주소를 열고 숫자를 넣으면 끝. 휴대폰은 공유 → "홈 화면에 추가"로 앱처럼 쓸 수 있습니다.

처음 켤 때 방화벽 창이 뜨면 "허용"을 누르세요. 숫자를 바꾸려면 서버를 끄고 `data/auth.json`을 지운 뒤 다시 켜세요.

> 사무실 서버는 **한 대에서만** 켜세요. 맥과 윈도우에서 동시에 켜면 대화 기록이 따로 쌓입니다.

## 기능

- **작업 보드**(왼쪽): 맡긴 일 / 진행 중 / 확인 대기 / 완료. 카드를 누르면 그 직원 채팅으로 이동. 폭 조절·접기·크게 보기.
- **채팅**(오른쪽): 실시간으로 글이 써지는 모습, 결과 그림·영상 바로 보기(누르면 크게), 파일 첨부, 바로 완성 / 시안 먼저, 새 대화(이전 대화는 `data/chats/archive`에 보관), 중지.
- **선택지 버튼**: 직원이 물어볼 때 버튼으로 답할 수 있습니다.
- **📒 가이드**: 브랜드·말투 등 공통 정보를 저장하면 모든 직원이 참고합니다.
- **🔔 알림**: 브라우저 알림, 휴대폰 ntfy 앱 푸시(주제 이름 저장).
- **사용량**: 위쪽에 Claude 5시간·7일 사용량 표시(작업이 한 번 돌아야 나타남).
- **자동 백업**: 3시간마다 `data/backups/`에 대화·보드 저장(최근 16개 유지).

## 설정 (`config.json`, 선택)

`config.example.json`을 `config.json`으로 복사해 고칩니다.

| 항목 | 설명 |
| --- | --- |
| `port` | 기본 4747 |
| `workspace` | 작업 폴더 절대 경로. 비우면 이 저장소 |
| `model` | 비우면 Claude Code 기본 모델 |
| `permissionMode` | 기본 `acceptEdits` (파일 수정은 자동 허용, 위험한 명령은 막힘) |
| `allowedTools` / `disallowedTools` | 직원이 쓸 수 있는/없는 도구. 기본으로 git push·commit·reset, rm -rf 차단 |
| `ntfyTopic` | 휴대폰 푸시 주제 |

## 막혔을 때

| 증상 | 해결 |
| --- | --- |
| 직원이 일을 안 해요 / "작업이 끝나지 못했어요" | 사무실 컴퓨터에서 터미널을 열고 `claude`를 실행해 로그인 상태 확인 |
| `claude 실행 실패` | Claude Code 설치 확인. 다른 경로라면 `config.json`의 `claudeCommand`에 전체 경로 |
| 휴대폰에서 안 열려요 | 사무실 서버가 켜져 있는지, Tailscale이 양쪽 모두 연결됐는지, 방화벽 허용 확인 |
| 고쳤는데 그대로예요 | 서버 창을 닫고 다시 실행 |

## 주의

- 이 폴더는 블로그 저장소 안에 있습니다. **main 브랜치에 합치면 GitHub Pages로 공개 사이트에 함께 올라갑니다**(비밀 정보는 없지만 불필요한 파일). 작업 브랜치에 두거나 별도 저장소로 옮겨 쓰는 것을 권장합니다.
- `data/`(대화·접속 숫자)와 `config.json`은 `.gitignore`로 저장소에 올라가지 않습니다.
