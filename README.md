# 막힘해결 운영

GitHub Pages: main 브랜치 루트. 도메인: https://www.innerapple.com

## 글 발행

1. posts의 발행 글을 복사해 제목, 설명, canonical, SNS 메타, 본문을 수정합니다.
2. 공식 출처와 확인일을 기록하고 실제 사용 환경에서 절차를 점검합니다.
3. assets에 설명 도식 또는 개인정보를 가린 실제 캡처를 넣습니다. 도식을 캡처로 표기하지 않습니다.
4. index.html과 assets/site.js에 발행 글을 추가합니다. 검색 status는 live입니다.
5. sitemap.xml에는 완성된 공개 글만 추가합니다. 예정 글을 발행할 때 noindex 메타를 제거합니다.
6. 링크·모바일 화면을 검사한 뒤 main에 커밋합니다. Pages 배포 완료 후 실제 도메인에서 확인합니다.

## 광고와 제휴

사용자가 제공한 pub-1328779882408752로 홈·전체 글 목록에서 AdSense 자동광고 스크립트를 로드하고, 공개 페이지에는 계정 확인 메타를 유지하며 ads.txt를 구성했습니다. 글 본문은 가독성을 위해 자동광고를 로드하지 않습니다. 사이트 승인과 자동 광고 활성화 여부는 AdSense 계정에서 확인해야 합니다. 예정 글·404에는 광고를 넣지 않았습니다. 제휴 계약·URL이 없는 상품은 일반 공식 링크로만 소개합니다.

### 광고 가독성 정책

- 글 본문(`posts/*.html`)에서는 AdSense 자동광고 스크립트를 로드하지 않습니다. 자동광고가 단계 사이와 좌우 오버레이에 반복 삽입되어 해결 절차를 읽기 어렵게 만들기 때문입니다.
- 게시자 확인용 `google-adsense-account` 메타는 유지하고, 자동광고 스크립트는 홈과 전체 글 목록에서만 로드합니다.
- 앞으로 본문 광고를 다시 넣으려면 AdSense에서 수동 광고 단위와 슬롯 ID를 만든 뒤, 글당 최대 2개를 제목·단계 사이가 아닌 목차 뒤와 관련 글 앞에만 배치하고 모바일·데스크톱을 모두 확인합니다.
- 새 글은 기존 글을 복사하더라도 본문 페이지에 자동광고 스크립트를 추가하지 않습니다.
