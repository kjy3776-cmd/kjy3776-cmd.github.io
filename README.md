# 막힘해결 운영

GitHub Pages: main 브랜치 루트. 도메인: https://www.innerapple.com

## 글 발행

1. posts의 발행 글을 복사해 제목, 설명, canonical, SNS 메타, 본문을 수정합니다.
2. 공식 출처와 확인일을 기록하고 실제 사용 환경에서 절차를 점검합니다.
3. assets에 설명 도식 또는 개인정보를 가린 실제 캡처를 넣습니다. 도식을 캡처로 표기하지 않습니다.
4. index.html과 assets/site.js에 발행 글을 추가합니다. 검색 status는 live입니다.
5. sitemap.xml에는 완성된 공개 글만 추가합니다. 예정 글을 발행할 때 noindex 메타를 제거합니다.
6. 링크·모바일 화면을 검사한 뒤 main에 커밋합니다. Pages 배포 완료 후 실제 도메인에서 확인합니다.

## 광고와 제휴

사용자가 제공한 pub-1328779882408752로 홈·전체 글 목록·공개 글에서 AdSense 자동광고 스크립트와 계정 확인 메타를 로드하고 ads.txt를 구성했습니다. 자동광고는 AdSense 계정에서 저밀도 설정으로 제한합니다. 사이트 승인과 실제 노출·수익은 AdSense 계정에서 확인해야 합니다. 예정 글·404에는 광고를 넣지 않았습니다. 제휴 계약·URL이 없는 상품은 일반 공식 링크로만 소개합니다.

### 광고 가독성 정책

- 2026-09-21 AdSense 사이트 설정: 자동광고 사용, 인페이지 배너 사용, 페이지당 최대 광고 수 최저값 `6`, 광고 간 최소 간격 최댓값 `60`, 기사 페이지 추가 게재위치 탐색 사용 안 함.
- 멀티플렉스·사이드 레일·모바일 전면광고·광고 인텐트는 사용하지 않습니다. 앵커 광고는 모바일 하단만 유지하고 1,000px 초과 데스크톱에서는 표시하지 않습니다.
- 새 공개 글은 `google-adsense-account` 메타와 자동광고 로더를 포함해야 합니다. 예정 글·404에는 넣지 않습니다.
- AdSense 설정은 반영에 최대 1시간이 걸릴 수 있습니다. 변경 뒤 데스크톱·모바일 가독성, 페이지당 실제 광고 수, RPM을 함께 확인하고 수익만을 이유로 과밀도를 높이지 않습니다.
- 수동 광고 단위를 추가할 경우 목차 뒤와 관련 글 앞 등 읽기 경계를 사용하고 글당 최대 2개로 제한합니다.
