# 건강보험 자격확인서 제출 경로 개선

- 확인일: 2026-10-23, 기존 URL 유지. 신규 아님. 배포 완료 시 당일 신규 2편·개선 2편.
- 중복 의도의 신규 글 대신 제출 방식 선택표, 팩스·전자문서 전달 실패 점검 4단계, 문의 준비 문구를 추가.
- 정부24 https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=PG4CADM0106 : 인터넷·본인/대리(온라인 대리 불가)·무료·근무시간 내 3시간 재확인. 페이지의 최근 내용 확인일 2016-12-27을 본문에 별도 명시.
- 국민건강보험공단 https://www.nhis.or.kr/nhis/minwon/minwonServiceBoard.do?articleNo=10945782&mode=view : 홈페이지·건강보험25시·디지털ARS·지사 채널, 앱 팩스, 전자문서지갑 조건, 상담사 팩스 대상(만 65세 이상/등록 장애인) 재확인.
- 작성자의 실무 점검 권고와 공식 채널 조건을 구분. 로그인·실제 증명 발급·개인정보 조회는 수행하지 않음. 승인·자격·수신 성공 보장 없음.
- 기존 썸네일·카드뉴스·홈/목록 연결·OG·canonical·광고 설정 보존. datePublished 유지, dateModified와 확인일·sitemap lastmod 갱신.
- Search Console·AdSense 실적 조회 없음, 수치 추정 없음. 외부 게시 없음.
- 정적 링크·이미지·JSON-LD·카테고리 검사 및 모바일 표 스크롤 검수 후 기존 SSH main 배포. 배포 성공 및 공개 HTTP 200 결과는 자동운영 응답에 기록.
