X(구 트위터)에 로그인하지 못할 때 비밀번호를 여러 번 바꾸기 전에 웹·앱 문제인지, 계정 정보를 잊은 것인지, 인증 수단에 접근할 수 없는지를 구분하세요. X 공식 도움말을 기준으로 데이터 손실과 추가 잠금을 피하는 순서입니다.

2. X 로그인 복구 7단계

1단계: 앱과 웹을 서로 비교

앱에서 실패하면 최신 Chrome·Safari·Edge의 x.com 로그인에서 같은 계정을 시험합니다. 웹은 되고 앱만 안 되면 앱 업데이트와 재시작부터 진행하세요.

2단계: 브라우저 문제 분리

X 공식 도움말은 네트워크 확인, VPN 끄기, 비공개 창, 브라우저 업데이트, 캐시·쿠키 삭제, 확장 프로그램 끄기를 권합니다. 먼저 비공개 창에서 시험하고, 해결될 때만 x.com의 사이트 데이터와 충돌하는 확장을 좁히세요. 브라우저 전체 데이터를 처음부터 지우면 다른 사이트에서도 로그아웃될 수 있습니다.

3단계: 이메일 대신 사용자 아이디로 로그인

등록 이메일이 기억나지 않으면 @를 제외한 X 사용자 아이디와 비밀번호로 로그인해 봅니다. 다른 기기나 X 앱에 로그인된 세션이 남아 있다면 프로필에서 정확한 사용자 아이디를 확인하세요. 공개 프로필 이름과 사용자 아이디는 다를 수 있습니다.

4단계: 공식 비밀번호 재설정

X 비밀번호 재설정에 사용자 아이디, 이메일 주소 또는 휴대폰 번호를 입력합니다. 휴대폰 번호가 여러 X 계정에 연결된 경우 전화번호만으로는 이 단계에서 계정을 특정하지 못할 수 있으므로 사용자 아이디나 이메일을 사용하세요.

5단계: 이메일·문자 코드 확인

X가 보내는 재설정 코드는 공식 안내상 60분 동안 유효합니다. 받은편지함과 스팸함에서 X 발신 메일을 확인하고 가장 최근에 요청한 코드를 사용하세요. 반복 요청하면 이전 코드와 혼동하기 쉬우므로 한 번 요청한 뒤 잠시 기다립니다.

6단계: 새 비밀번호 설정 후 다시 로그인

다른 사이트에서 쓰지 않는 긴 비밀번호를 설정합니다. 비밀번호를 재설정하면 현재 변경 작업에 쓰는 세션을 제외한 활성 X 세션에서 로그아웃됩니다. 다른 기기에서 다시 로그인해야 할 수 있습니다.

7단계: 인증 수단이 없으면 공식 지원

등록 이메일과 전화번호에 모두 접근할 수 없거나 해킹으로 정보가 변경됐다면 X 계정 액세스 지원을 이용합니다. 마지막으로 기억하는 사용자 아이디, 이전 이메일, 오류 문구를 정확히 제출하세요. 본인 확인 수단이 전혀 없으면 복구가 어려울 수 있습니다.

3. 재설정 코드가 오지 않을 때 체크

  1. 입력한 이메일 주소의 철자와 도메인을 확인합니다.
  2. 스팸·정크·프로모션함에서 X 메일을 검색합니다.
  3. 문자 차단, 해외 발신 차단, 통신 상태를 확인합니다.
  4. 여러 계정에 연결된 전화번호라면 사용자 아이디나 이메일로 다시 요청합니다.
  5. 로그인 인증을 사용하는 계정은 문자 비밀번호 재설정이 제한될 수 있으므로 이메일 방식을 사용합니다.
  6. 60분이 지난 코드는 폐기하고 새 코드 하나만 요청합니다.

4. 계정 복구 중 보안 주의

비밀번호와 인증 코드를 지식인·커뮤니티 답변자, 원격 지원자 또는 메신저 상대에게 보내지 마세요. X 공식 로그인·도움말 주소인지 확인하고 직접 입력해야 합니다.

요청하지 않은 재설정 메일이 반복되면 메일의 링크를 누르지 말고 x.com에 직접 접속해 비밀번호 재설정 보호와 2단계 인증을 확인하세요. 계정 해킹이 의심되면 이메일 계정 비밀번호도 함께 점검합니다.

5. FAQ

비밀번호를 재설정하면 모든 기기에서 로그아웃되나요?

X 공식 안내에 따르면 재설정에 사용하는 세션을 제외한 활성 세션에서 로그아웃됩니다.

전화번호로 계정을 찾을 수 없습니다.

같은 번호가 여러 계정에 연결됐거나 로그인 인증이 설정된 경우일 수 있습니다. 사용자 아이디나 등록 이메일로 다시 시도하세요.

계정을 비활성화하면 로그인 오류가 고쳐지나요?

아닙니다. X는 로그인·해킹·게시물 오류 해결을 위해 계정을 비활성화하는 방법을 권하지 않습니다. 비활성화 후 30일 동안 로그인하지 않으면 계정 삭제로 이어질 수 있습니다.

캐시를 삭제하면 게시물이 사라지나요?

서버에 게시된 글은 삭제되지 않지만 브라우저 로그인과 일부 로컬 상태가 초기화됩니다. 작성 중인 미게시 내용은 먼저 따로 저장하세요.
