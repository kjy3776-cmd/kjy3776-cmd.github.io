Excel ‘#SPILL! — 분산 범위가 비어 있지 않음’ 해결 7단계

2026-09-23 확인·Microsoft 365용 Excel·Excel 2024/2021, Windows·Mac·웹Excel#SPILL!

Excel의 FILTER·UNIQUE·SORT 같은 동적 배열 수식은 한 셀에 입력해도 결과가 주변 셀로 펼쳐집니다. 결과가 들어갈 자리에 다른 값이나 병합 셀이 있으면 #SPILL!이 나타날 수 있습니다. 특히 오류 메뉴에 “분산 범위가 비어 있지 않음”이 표시된다면, 파일 전체를 초기화하거나 주변 행을 통째로 삭제하기 전에 점선으로 표시된 출력 범위의 장애 셀부터 찾으세요. 같은 #SPILL!이라도 ‘표 수식’, ‘워크시트 가장자리’, ‘불확실한 크기’는 해결법이 다릅니다.

1. 1분 해결 요약

  1. 원본 통합 문서를 다른 이름으로 저장해 사본을 만듭니다.
  2. #SPILL! 셀을 선택해 점선 출력 범위와 오류 아이콘의 설명을 봅니다.
  3. ‘분산 범위가 비어 있지 않음’이면 장애 셀 선택으로 막는 셀을 찾습니다.
  4. 그 셀의 값·수식이 필요한 데이터라면 다른 빈 위치로 옮긴 뒤, 확인된 장애 셀만 비웁니다.
  5. 병합 셀·Excel 표 내부·시트 가장자리라면 아래 원인표에 맞게 수식 위치나 범위를 조정합니다.

중요: ‘빈 행 일괄 삭제’나 전체 열 지우기는 #SPILL!의 첫 해결법이 아닙니다. 다른 수식과 데이터까지 손상시킬 수 있습니다.

2. 증상별 원인표

겉으로는 빈칸인데 동일 오류보이지 않는 수식 결과·숨은 데이터 가능선택된 셀의 수식 입력줄 확인
병합된 셀에 분산출력 범위와 병합 셀이 겹침병합 해제 영향 확인 또는 수식 이동

3. 쉬운 방법부터 해결하는 7단계

1단계: 원본 사본을 만들고 오류가 난 수식 셀 확인

파일을 파일 → 다른 이름으로 저장해 사본을 만든 뒤 작업합니다. 공동 편집 문서라면 변경 전에 소유자나 협업자에게 알리고 버전 기록도 확인하세요. #SPILL!이 보이는 셀 하나를 선택해 수식 입력줄의 원래 수식을 기록합니다. 출력된 다른 셀이 아니라 수식을 입력한 왼쪽 위 셀이 수정 지점입니다.

2단계: 점선 출력 범위와 오류 설명 읽기

수식 셀을 선택하면 Excel이 의도한 출력 영역을 점선 테두리로 보여 줍니다. 오류 경고 아이콘을 열어 ‘분산 범위가 비어 있지 않음’인지 먼저 확인하세요. ‘표 수식’이나 ‘워크시트 가장자리’라면 5~6단계로 가고, 다른 설명이 나오면 해당 원인을 따릅니다. 웹·Mac·모바일에서는 메뉴 이름과 배치가 다를 수 있습니다.

3단계: 장애 셀을 찾아 보존 후 이동

오류 메뉴의 장애 셀 선택을 이용하거나 점선 범위 안의 셀을 하나씩 살펴보세요. 선택된 셀에 값이나 수식이 있다면 먼저 다른 빈 영역이나 백업 시트로 옮깁니다. 겉보기에는 빈칸이어도 수식 입력줄에 수식이 남아 있는지 확인하세요. 데이터의 용도를 모르면 삭제하지 말고 수식을 다른 빈 위치로 이동하는 편이 안전합니다.

4단계: 확인된 장애 셀만 비우거나 병합 셀 처리

막는 셀이 필요 없는 입력임을 확인했다면 그 셀의 내용만 지우고 계산 결과를 확인합니다. 행·열 전체를 선택해 삭제하면 참조가 이동할 수 있습니다. 출력 범위가 병합 셀과 겹친다면 병합을 해제했을 때 서식과 데이터가 어떻게 바뀌는지 확인하거나, 수식을 병합 셀과 겹치지 않는 곳으로 옮기세요. Microsoft는 병합 해제 또는 수식 이동을 공식 해결책으로 안내합니다.

5단계: 수식이 Excel 표 안에 있으면 표 밖으로 이동

필터 화살표가 있는 Excel 표 내부에 동적 배열 수식을 입력했다면 표의 행마다 독립된 값이 있어야 하는 구조와 충돌합니다. 표를 보존하고 싶다면 수식을 표 밖의 충분히 빈 그리드로 옮기고, 필요하면 원본 표를 참조하게 하세요. 표 디자인 → 범위로 변환도 가능하지만 표 기능·구조화된 참조·자동 확장에 영향을 줄 수 있으므로 백업한 뒤 의도적으로만 선택합니다. 단순한 자동 필터 범위와 Excel 표는 구분해야 합니다.

6단계: 전체 열 참조와 시트 경계 확인

예를 들어 동적 배열이 A:A처럼 전체 열을 결과로 만들면 수식이 아래쪽에 있을 때 시트 끝을 넘을 수 있습니다. Microsoft는 VLOOKUP(A:A,A:C,2,FALSE) 같은 예를 들며 필요한 행만 참조하거나, 같은 행의 단일 값만 조회하거나, 수식 위치를 옮기는 방법을 제시합니다. 무조건 @를 붙이면 여러 결과가 한 결과로 바뀔 수 있으므로 원래 여러 값이 필요한지 먼저 결정하세요.

7단계: 출력 크기가 계속 바뀌면 수식·버전별 문제 분리

SEQUENCE(RANDBETWEEN(1,1000))처럼 결과 크기가 재계산마다 달라지면 Excel이 안정된 출력 범위를 정하지 못할 수 있습니다. 이때는 임의 크기를 다시 계산하는 부분을 제거하거나 고정된 입력값으로 비교하세요. 메모리 부족이면 전체 열 대신 실제 데이터 범위만 참조합니다. 피벗 테이블에서 생긴 #SPILL!은 일반 FILTER 수식과 구분해 피벗 전용 공식 안내를 따르세요. 해당 피벗 기능은 Microsoft 문서에서 참가자 프로그램 단계로 표시되어 있으므로 본인 Excel 빌드에 따라 다를 수 있습니다.

4. 정상 확인과 실패 시 다음 조치

  • 오류 셀에 값이 아닌 첫 결과가 보이고, 점선으로 예상한 영역까지 여러 결과가 펼쳐지는지 확인합니다.
  • 원본 데이터·이동한 장애 셀의 값과 수식이 사본에 그대로 있는지 비교합니다.
  • FILTER 조건이나 원본 표의 항목을 바꿔 결과 크기가 자연스럽게 늘고 줄어드는지 확인합니다.
  • 하위 수식·차트·피벗이 새 위치를 제대로 참조하는지 확인한 뒤 원본 파일에 같은 조치를 적용합니다.

계속 실패한다면 수식, 오류 메뉴의 정확한 설명, 점선 범위, Excel 제품·버전, 표/병합 여부를 기록해 Microsoft의 #SPILL! 공식 안내와 Excel 기술 커뮤니티에서 해당 원인을 확인하세요. 회사 문서의 참조 구조나 공동 편집 변경이 얽혔다면 관리자·소유자에게 검토를 요청하세요.

5. 데이터·결제·계정·보안 주의

  • 데이터: 장애 셀을 찾았다고 시트 전체·빈 행 전체를 지우지 마세요. 다른 수식, 수동 입력, 피벗 원본이 손상될 수 있습니다. 사본에서 먼저 확인하세요.
  • 결제: #SPILL! 해결을 위해 유료 복구 도구나 플랜 업그레이드가 필요한 것은 아닙니다. 다만 지원되는 함수와 피벗 기능은 Excel 버전·라이선스에 따라 달라질 수 있습니다.
  • 계정: OneDrive·SharePoint 공동 편집 파일이라면 타인의 수정과 버전 기록에 영향을 줄 수 있으므로 파일 소유권과 권한을 확인하세요. 로그인 정보를 제3자에게 넘길 필요는 없습니다.
  • 보안: 통합 문서에 고객·재무·인사 데이터가 있으면 공개 커뮤니티에 원본 파일을 올리지 말고 개인 정보를 지운 최소 재현 예제로 문의하세요. 출처를 모르는 매크로·추가 기능으로 오류를 ‘자동 복구’하지 마세요.

6. FAQ

#SPILL!이 뜨면 주변 셀을 모두 삭제해야 하나요?

아닙니다. 먼저 점선 출력 범위와 오류 메뉴의 장애 셀을 확인하고, 필요한 데이터는 백업·이동하세요. 실제로 막는 셀만 비우거나 수식을 빈 곳으로 옮기면 됩니다.

빈칸인데 왜 ‘분산 범위가 비어 있지 않음’이라고 하나요?

겉으로는 비어 보여도 해당 셀에 수식이나 데이터가 남아 있을 수 있습니다. 오류 메뉴의 장애 셀 선택과 수식 입력줄로 확인하세요. 단, 원인을 확인하지 않고 서식·내용을 일괄 지우지는 마세요.

Excel 표 안의 FILTER 수식은 왜 #SPILL!이 되나요?

Microsoft는 동적 배열의 분산 결과가 Excel 표 내부에서 지원되지 않는다고 설명합니다. 수식을 표 밖의 빈 영역으로 옮기는 것이 표를 보존하는 방법입니다.

Ctrl+Shift+Enter를 누르면 해결되나요?

일반적인 해결법이 아닙니다. 최신 동적 배열 수식은 보통 Enter로 입력하고, 출력 범위를 막는 원인을 해결해야 합니다. 오래된 CSE 배열 수식과는 동작이 다릅니다.

수식의 A1#도 오류 표시인가요?

아닙니다. 셀 주소 뒤의 #는 성공적으로 분산된 결과 전체를 참조하는 연산자입니다. 셀 자체에 보이는 #SPILL! 오류와 구별하세요.

한 줄 요약

사본 저장 → 오류 셀의 점선 출력 범위·설명 확인 → 장애 셀 보존·이동 → 병합·표·시트 경계 점검 → 결과와 원본 비교 순서로 해결하세요.
