디스코드(Discord) ‘RTC 연결 중(RTC Connecting)’ 무한 대기 해결 7단계

디스코드 음성 채널에 들어갔는데 ‘RTC 연결 중(RTC Connecting)’만 계속 표시되고 대화가 시작되지 않나요? Discord는 RTC Connecting·No Route·ICE Checking·Connecting을 음성 서버 연결이 막힌 상태로 분류합니다. 채널에는 들어갔는데 내 마이크만 안 들리는 문제와 다르므로 입력 장치 초기화부터 할 필요가 없습니다. 이 글은 2026년 9월 27일 Discord와 Microsoft 공식 문서를 대조한 Windows 11 데스크톱 앱 기준 진단입니다. 앱·서버 설정 이름은 업데이트나 언어에 따라 달라질 수 있습니다.

1. 1분 해결 요약

  1. Discord 상태 페이지에서 Voice 또는 접속 지역 장애를 확인합니다. 텍스트 채팅이 된다고 음성 서버까지 정상인 것은 아닙니다.
  2. 음성 채널에서 나갔다 다시 들어가고 Discord를 Ctrl+R로 새로고침합니다. 계속되면 트레이에서도 종료한 뒤 재실행합니다.
  3. 다른 음성 채널과 자신의 브라우저 discord.com에서 같은 계정으로 비교합니다. 한 채널만 실패하는지, 데스크톱 앱만 실패하는지 구분하세요.
  4. 본인이 관리하는 다른 신뢰할 수 있는 네트워크에서 비교한 후, 필요한 경우에만 Discord의 방화벽 허용 상태를 확인합니다. 방화벽 전체 해제·임의 포트 개방은 하지 마세요.

멈춤 기준: 회사·학교 네트워크 정책이나 다른 사람의 서버 설정을 임의로 바꾸지 마세요. 관리 권한이 없는 채널의 지역 설정은 관리자에게 증상과 비교 결과를 전달하세요.

3. 쉬운 방법부터 해결하는 7단계

1단계: 오류 문구와 공식 서비스 상태 확인

표시 문구가 RTC Connecting인지, No Route·ICE Checking인지, Waiting for Voice Server인지 적어 두세요. Discord Status에서 Voice와 해당 지역의 상태를 확인합니다. ‘Waiting for Voice Server’는 Discord가 서버 측 문제로 구분하므로 개인 PC를 초기화하지 말고 장애 공지를 확인하세요. 특정 시간대 장애가 이미 해결됐더라도 현재 증상과 같은 원인이라고 단정하지 마세요.

2단계: 채널 재입장·앱 새로고침

음성 채널에서 나갔다가 다시 들어갑니다. Discord 데스크톱 앱에서 Ctrl+R로 새로고침하고, 변화가 없으면 시스템 트레이의 Discord도 종료한 뒤 앱을 다시 실행합니다. Discord 공식 음성·영상 안내는 앱 새로고침, 완전 종료·재시작과 OS·앱 업데이트 확인을 초기 조치로 둡니다. 진행 중인 화면 공유나 통화는 끊길 수 있으므로 참여자에게 먼저 알리세요.

3단계: 다른 채널·브라우저로 범위 구분

같은 서버의 다른 음성 채널 또는 자신이 접근 가능한 다른 서버를 한 번 시험합니다. 이어 같은 계정으로 discord.com의 브라우저 음성 통화도 비교하세요. 브라우저에서 마이크 권한 요청이 뜬다면 자신이 접속한 공식 사이트인지 확인하고 필요한 범위에서만 허용합니다. 브라우저에서는 접속되고 앱만 실패하면 앱·로컬 환경에 집중하세요. 두 클라이언트가 모두 같은 네트워크에서 실패한다면 회선·정책·서비스 상태를 더 확인하세요. 연결이 완료된 뒤 마이크만 안 되면 마이크 문제 글로 넘어갑니다.

4단계: 허용된 다른 네트워크와 공유기 상태 비교

자신이 관리하거나 사용이 허용된 네트워크에서만 비교하세요. 예를 들어 집 Wi-Fi와 자신의 모바일 데이터를 비교하면 특정 회선·공유기 경로인지 판단하는 데 도움이 됩니다. Discord는 모뎀·공유기·컴퓨터 재시작과 ISP 장애 확인을 안내합니다. 가족의 연결을 끊지 않도록 공유기 재시작 전에 이용자를 확인하세요. 회사·학교망에서만 실패하면 보안 정책을 무시하거나 VPN·DNS로 우회하지 말고 네트워크 관리자에게 Discord 음성 연결이 허용되는지 문의하세요.

5단계: Windows 방화벽은 전체 해제 대신 앱 허용만 검토

다른 허용된 네트워크에서는 정상이고 Windows PC의 특정 방화벽 설정이 Discord를 차단한다고 확인된 경우에만 Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용에서 신뢰할 수 있는 Discord 앱 항목과 현재 네트워크 유형을 확인합니다. Microsoft는 임의 포트 개방보다 앱 허용 목록이 덜 위험하지만 둘 다 신중해야 한다고 안내합니다. Discord 공식 글에는 방화벽·백신 임시 해제도 나오지만, 이 글은 전체 방화벽·백신 해제나 광범위한 포트 개방을 권하지 않습니다. 조직 관리 PC라면 관리자에게 막힌 연결 증거를 전달하세요.

6단계: 한 채널만 실패하면 지역 설정은 권한자만 비교

Discord는 음성 지역이 Automatic이라면 먼저 채널에서 나갔다 다시 들어갈 것을 권합니다. 특정 채널에서만 반복되고 관리 권한이 있는 경우에 한해 음성 채널 설정 → 개요 → 지역 재정의(Region Override)를 잠시 다른 지역으로 바꾸어 비교할 수 있습니다. 일반 참가자는 채널 관리자에게 증상·시간·다른 채널 결과를 전달하세요. 임의로 고정한 지역이 더 느릴 수도 있으므로 개선이 없다면 원래 설정으로 돌립니다. 개인 통화는 통화 화면에서 지역 선택 기능이 제공되는 경우에만 비교하세요.

7단계: 앱 설정은 기록 후 마지막에 조정·공식 지원 요청

서비스·채널·네트워크가 정상이면서 앱에서만 반복된다면 Discord의 사용자 설정 → 음성 및 비디오에서 현재 값을 기록하고 Quality of Service High Packet Priority 옵션을 한 번 바꿔 비교합니다. 이 옵션은 모든 RTC 오류의 원인이 아닙니다. 그래도 실패하면 음성 및 비디오 → 디버깅 → 음성 및 비디오 설정 재설정을 검토하세요. 입력·출력 장치, 감도 등 개인 설정이 돌아갈 수 있습니다. AMD CPU/GPU가 있는 오래된 모델에서 브라우저만 정상이고 앱만 RTC 연결 중인 드문 경우에는 Discord의 AMD 전용 문서를 확인하되 다른 PC에 무조건 적용하지 마세요. 마지막에는 오류 문구·앱/Windows 버전·채널/브라우저/네트워크 비교 결과를 Discord 지원에 전달하세요.

4. 정상 확인과 실패 시 다음 조치

  • 음성 채널의 RTC 연결 중 표시가 사라지고 실제로 다른 사람과 짧은 음성 대화가 되는지 확인합니다. 연결 후 목소리만 안 들리면 연결 오류와 구분해 마이크·출력 설정을 확인합니다.
  • 한 채널·한 네트워크에서만 재발하는지 비교해 기록합니다. 지역 재정의·QoS 설정을 시험했다면 나아지지 않은 변경은 원래대로 되돌립니다.
  • Discord 지원에는 오류 문구와 시각, Windows·앱 버전, 채널·브라우저·다른 네트워크 결과를 전달합니다. 공식 안내가 요청하는 경우에만 디버그 로그를 제출하고, 계정 토큰·개인 메시지·사적인 서버 정보가 보이는지 먼저 검토하세요.

5. 데이터·결제·계정·보안 주의

  • 데이터: 음성·비디오 설정 재설정은 입력·출력 장치 등 개인 설정을 바꿀 수 있습니다. 앱 재설치나 캐시 폴더 삭제는 이 오류의 첫 조치가 아니며 로컬 설정을 잃을 수 있습니다.
  • 결제: 음성 연결 오류 해결을 위해 Nitro 구독이나 유료 ‘네트워크 수리’ 앱을 먼저 구매할 필요는 없습니다.
  • 계정: 새 계정 생성·로그아웃 반복은 RTC 연결 경로 문제를 확인하는 방법이 아닙니다. 조직·서버 권한 문제는 관리자에게 문의하세요.
  • 보안: 방화벽·백신을 통째로 끄거나 임의 UDP 포트를 열지 마세요. 회사·학교 정책을 우회하지 말고, 출처 불명의 Discord 설치 파일·설정 스크립트를 실행하지 마세요. 지원 로그·스크린샷에 민감한 내용이 없는지 확인하세요.

6. FAQ

채팅은 되는데 RTC 연결 중에서 멈추는 이유는?

텍스트 채팅과 음성 연결은 점검할 경로가 다릅니다. Discord는 RTC Connecting·No Route·ICE Checking을 음성 서버 연결 실패 상태로 분류합니다. 서비스 상태와 다른 채널·클라이언트·네트워크 결과를 비교하세요.

방화벽을 꺼야 해결되나요?

방화벽 전체 해제나 임의 포트 개방을 권하지 않습니다. 특정 Discord 앱 차단이 확인된 경우에만 Microsoft의 앱 허용 경로를 검토하고, 관리형 PC라면 관리자에게 문의하세요.

음성 채널 지역을 바꾸면 항상 해결되나요?

아닙니다. 자동 지역일 때는 재입장이 먼저입니다. 한 채널에서만 실패하고 권한이 있을 때 일시 비교할 수 있지만 개선이 없으면 원래 설정으로 되돌리세요.

마이크가 안 들리는 것과 같은 문제인가요?

RTC 연결 중은 음성 채널 접속이 완료되지 않은 상태입니다. 접속 후 음성이 전달되지 않는다면 입력 장치·권한·음소거를 별도로 점검하세요.
