크롬 메모리 사용량 줄이기: 원인 찾는 6단계

Chrome은 탭·확장 프로그램·GPU 작업을 여러 프로세스로 나눕니다. Windows 작업 관리자에 Chrome이 여러 개 보이는 것만으로 오류는 아닙니다. 어떤 탭이나 확장 프로그램이 많이 쓰는지 확인한 뒤 효과가 큰 설정부터 하나씩 적용하세요.

1. 먼저 원인 진단

Chrome에서 Shift+Esc를 눌러 Chrome 작업 관리자를 여세요. 메모리 열을 클릭해 큰 순서로 봅니다.

결과먼저 할 일
특정 탭 하나만 큼입력 내용을 저장한 뒤 새로고침하거나 종료
특정 확장 프로그램이 큼chrome://extensions에서 끄고 비교
여러 탭이 조금씩 큼메모리 절약을 켜고 불필요한 탭 정리
탭이 적어도 계속 증가확장 격리 후 Chrome 업데이트·초기화

주의: 문서 작성·결제·업로드 탭에서 프로세스를 종료하면 저장하지 않은 내용이 사라질 수 있습니다.

2. 30초 빠른 조치

  1. 사용하지 않는 탭을 닫고 다운로드·화상회의가 끝났는지 확인합니다.
  2. 주소창에 chrome://settings/performance를 입력합니다.
  3. 메모리 절약 모드를 켜고 ‘균형 조정’을 선택합니다.
  4. Chrome을 완전히 종료했다가 다시 열어 사용량을 비교합니다.

Google 설명에 따르면 메모리 절약은 쓰지 않는 탭을 비활성화하고 다시 열 때 새로고침합니다. 오디오·영상, 화면 공유, 다운로드, 일부 입력 양식과 고정 탭은 비활성화되지 않을 수 있습니다.

3. 크롬 메모리를 줄이는 6단계

1단계: 메모리 절약 수준 선택

설정 → 성능 → 메모리 절약 모드에서 먼저 균형 조정을 사용하세요. 탭이 아주 많다면 ‘최대’를 시험할 수 있지만 돌아간 탭이 더 자주 새로고침됩니다. 메일처럼 계속 작동해야 하는 사이트만 ‘항상 활성 상태로 유지’에 넣으세요.

2단계: 큰 탭 찾기

  1. Shift+Esc를 누릅니다.
  2. 메모리 사용량이 큰 탭을 확인합니다.
  3. 작업을 저장한 뒤 새로고침합니다.
  4. 같은 사이트에서 다시 급증하면 열린 문서·영상·웹앱 작업을 줄입니다.

3단계: 확장 프로그램 격리

  1. chrome://extensions를 엽니다.
  2. 필수적이지 않은 확장을 모두 끕니다.
  3. Chrome을 다시 열어 같은 작업을 반복합니다.
  4. 정상이면 하나씩 켜 원인을 찾습니다.
  5. 쓰지 않거나 출처가 불분명한 확장은 삭제합니다.

모든 페이지를 읽는 광고 차단·문법 검사·쇼핑 확장은 탭이 많을수록 부담이 커질 수 있습니다. 메모리 절약 확장을 새로 설치하기 전에 Chrome 내장 기능부터 사용하세요.

4단계: 페이지 사전 로드 줄이기

설정 → 성능 → 페이지 미리 로드에서 ‘확장된 미리 로드’를 쓴다면 ‘표준’으로 바꾸거나 잠시 꺼 비교합니다. 끄면 메모리와 네트워크 사용이 줄 수 있지만 페이지가 약간 늦게 열릴 수 있습니다.

5단계: 업데이트와 재시작

⋮ → 도움말 → Chrome 정보에서 업데이트하고 재시작합니다. 먼저 열린 문서와 입력 내용을 저장하세요. chrome://flags를 임의로 바꾸지 마세요. Google은 플래그가 예고 없이 바뀌거나 사라질 수 있고 보안·개인정보 위험이 있다고 안내합니다.

6단계: 마지막으로 설정 초기화

확장을 꺼도 비정상적으로 증가할 때만 설정 → 설정 재설정 → 설정을 기본값으로 복원을 실행합니다. Google 안내상 북마크와 저장된 비밀번호는 삭제되지 않지만 시작 페이지·검색엔진·고정 탭·사이트 설정·쿠키 관련 설정과 확장 상태 등이 바뀔 수 있으므로 필요한 설정을 기록하세요.

4. 그래도 높을 때

상황판단
시크릿 창은 정상일반 창의 확장이나 프로필 설정 가능성이 큼
Chrome을 닫아도 남음백그라운드 앱을 확인하고 Windows 재시작
다른 브라우저도 느림Windows 작업 관리자에서 전체 메모리와 다른 앱 확인
한 사이트에서만 반복해당 웹앱의 문서·영상 수를 줄이고 사이트 지원 확인

RAM이 거의 가득 차면 PC 전체가 느려질 수 있습니다. 숫자만 보고 정상 프로세스를 강제 종료하거나 검증되지 않은 ‘RAM 정리 프로그램’을 설치하지 마세요.

5. FAQ

프로세스가 여러 개인 것은 바이러스인가요?

그 사실만으로는 아닙니다. Chrome은 안정성과 격리를 위해 탭, 확장, GPU 등을 별도 프로세스로 실행합니다.

하드웨어 가속을 끄면 되나요?

영상 깨짐이나 GPU 오류 진단에는 쓰지만 메모리 절약의 기본 조치는 아닙니다. 끄면 CPU 사용량이나 영상 성능이 나빠질 수 있습니다.

탭이 자꾸 새로고침됩니다.

메모리 절약의 정상 동작일 수 있습니다. 계속 켜야 하는 사이트만 예외에 추가하세요.

캐시와 쿠키를 지워야 하나요?

특정 사이트 오류에는 도움이 되지만 RAM 절약의 첫 단계는 아닙니다. 로그아웃될 수 있으므로 전체 삭제를 먼저 하지 마세요.

한 줄 요약
