Windows 11 업데이트 ‘설치 오류 0x80070002’ 해결 7단계

Windows 11의 설정 → Windows Update에서 “설치 오류 - 0x80070002”가 반복되면 업데이트에 필요한 파일이 없거나 손상됐거나, 이전 설치가 끝나지 않은 경우가 많습니다. 같은 코드는 Microsoft Store나 다른 프로그램에서도 보일 수 있으므로 이 글은 Windows Update 화면에서 나온 0x80070002만 다룹니다. 아래 순서는 Microsoft 공식 문서를 2026년 9월 21일에 교차 확인해 쉬운 방법부터 복구 재설치까지 정리했습니다.

1. 1분 해결 요약

  1. 작업을 저장하고 PC를 재시작한 뒤 업데이트를 다시 확인합니다.
  2. 설정 → 시스템 → 문제 해결 → 다른 문제 해결사 → Windows Update → 실행을 선택합니다.
  3. 날짜·시간 자동 설정, 안정적인 인터넷, 시스템 드라이브 여유 공간을 확인합니다.
  4. 계속 실패하면 Windows Update 서비스를 중지하고 C:\Windows\SoftwareDistribution 안의 캐시만 지웁니다.
  5. 관리자 터미널에서 DISM을 먼저, SFC를 다음에 실행합니다.

같은 업데이트만 계속 실패하면 KB 번호와 오류 시각을 기록한 뒤 6~7단계로 넘어가세요.

3. 쉬운 방법부터 해결하는 7단계

1단계: 오류 화면과 Windows 버전을 기록하고 재시작

설정 → Windows Update → 업데이트 기록에서 실패한 항목의 KB 번호와 오류 코드를 기록합니다. Windows+R을 누르고 winver를 실행해 버전과 OS 빌드도 적어 두세요. 작업을 저장하고 PC를 재시작한 뒤 업데이트 확인을 다시 누릅니다. 다운로드가 중단됐거나 재시작 대기 중이었다면 이 단계에서 해결될 수 있습니다.

2단계: Windows Update 문제 해결사 실행

설정 → 시스템 → 문제 해결 → 다른 문제 해결사에서 Windows Update → 실행을 선택합니다. Windows 11에서는 Get Help 앱이 열려 진단을 이어갈 수 있습니다. 화면의 권장 조치를 적용한 뒤 PC를 재시작하세요. 오래된 글의 업데이트 및 보안 → 문제 해결 경로는 Windows 10용이므로 Windows 11에서는 위 경로를 사용합니다.

3단계: 시간·인터넷·저장 공간·외부 장치 확인

설정 → 시간 및 언어 → 날짜 및 시간에서 시간과 표준 시간대 자동 설정을 켜고 지금 동기화합니다. VPN·프록시는 조직에서 요구하지 않는 경우 잠깐 끄고 안정적인 Wi-Fi 또는 유선 연결을 사용하세요. 시스템 드라이브의 여유 공간을 확보하고, 업데이트에 불필요한 USB 저장 장치·도크는 분리한 뒤 다시 시도합니다.

4단계: Windows Update 캐시만 초기화

Windows+R → services.msc를 실행합니다. Windows Update 서비스를 우클릭해 중지합니다. 파일 탐색기에서 C:\Windows\SoftwareDistribution을 열어 폴더 자체가 아니라 안의 파일과 폴더만 삭제합니다. 다시 서비스 창으로 돌아가 Windows Update를 시작하고 업데이트를 확인하세요. 삭제 중 사용 중이라는 메시지가 나오면 서비스가 실제로 중지됐는지 확인하고, 다른 Windows 폴더는 건드리지 않습니다.

5단계: DISM을 먼저, SFC를 다음에 실행

시작 버튼을 우클릭해 터미널(관리자)을 열고 아래 명령을 한 줄씩 실행합니다. Microsoft는 DISM으로 Windows 구성 요소를 복구한 뒤 SFC로 보호된 시스템 파일을 검사하는 순서를 안내합니다.

DISM.exe /Online /Cleanup-Image /RestoreHealth
sfc /scannow

각 명령이 끝날 때까지 창을 닫지 마세요. The operation completed successfully 또는 Windows 리소스 보호에서 무결성 위반을 발견하지 못했습니다가 표시되면 재시작 후 업데이트를 다시 시도합니다.

6단계: 한 KB만 실패하는지, 전체가 실패하는지 구분

설정 → Windows Update → 업데이트 기록에서 보안 인텔리전스·드라이버 등 다른 항목은 성공하고 특정 누적 업데이트만 실패하는지 봅니다. 특정 KB만 실패하면 KB 번호와 현재 OS 빌드를 함께 기록해 Microsoft 지원 또는 PC 제조사 지원에 전달하세요. 출처를 알 수 없는 ‘업데이트 수리 도구’, 레지스트리 파일, 드라이버 묶음은 설치하지 않습니다.

7단계: Windows Update로 현재 Windows 11 버전 복구 재설치

앞 단계가 모두 실패하면 설정 → 시스템 → 복구 → Windows Update를 사용하여 문제 해결 → 지금 다시 설치를 확인합니다. 이 기능은 같은 Windows 버전을 다시 설치해 시스템 파일과 구성 요소를 복구하면서 앱·파일·설정을 보존하도록 설계됐습니다. 전원과 인터넷을 계속 연결하고 중요한 파일은 먼저 백업하세요. 조직에서 관리하는 PC, 일부 정책이 적용된 PC, 필요한 업데이트가 없는 PC에는 이 옵션이 표시되지 않을 수 있습니다.

4. 정상 확인과 실패 시 다음 조치

  • 설정 → Windows Update에 최신 상태입니다가 표시되는지 봅니다.
  • 업데이트 기록에서 문제의 KB가 성공적으로 설치됨인지 확인합니다.
  • winver의 OS 빌드가 설치 전 기록보다 갱신됐는지 비교합니다.
  • 재시작 뒤에도 Windows Update 서비스가 실행되고 오류가 다시 나타나지 않는지 확인합니다.

0x80070002가 계속되면 실패한 KB, winver 결과, 발생 시각, DISM·SFC 마지막 메시지를 함께 적어 Microsoft 지원 또는 PC 제조사에 문의하세요. 회사·학교 PC는 업데이트 정책을 바꾸거나 캐시를 반복 삭제하지 말고 IT 관리자에게 전달합니다.

5. 데이터·계정·보안 주의

  • 캐시 초기화 전에 작업을 저장하고, 복구 재설치 전에는 중요한 파일을 백업합니다.
  • C:\Windows\SoftwareDistribution의 내용만 대상으로 하며 WinSxS, System32, 레지스트리를 임의로 삭제하지 않습니다.
  • 다른 PC에서 내보낸 레지스트리 키나 DLL을 가져오지 마세요. 시스템 버전·드라이버가 달라 부팅 문제를 만들 수 있습니다.
  • BitLocker가 켜져 있다면 복구 작업 전에 Microsoft 계정이나 조직 포털에서 복구 키를 확인합니다.
  • Microsoft 지원을 사칭해 원격 제어, 결제, 암호 또는 인증 코드를 요구하는 연락은 거절하고 공식 지원 페이지에서 직접 문의합니다.

6. FAQ

0x80070002는 무슨 뜻인가요?

Windows Update에서는 필요한 업데이트 파일을 찾지 못했거나 설치가 완료되지 않았을 때 표시될 수 있습니다. Microsoft의 Windows Update 문서는 이 코드를 ‘업데이트 설치 실패’ 범주로 안내합니다. Microsoft Store나 작업 스케줄러 등 다른 화면의 같은 코드는 원인과 해결법이 다를 수 있습니다.

SoftwareDistribution 폴더 전체를 삭제해도 되나요?

Microsoft 공식 절차처럼 Windows Update 서비스를 먼저 중지하고 폴더 안의 캐시 내용만 지운 뒤 서비스를 다시 시작하세요. Windows Update 기록 화면의 표시가 일부 초기화될 수 있지만 이미 설치된 업데이트 자체를 제거하는 절차는 아닙니다.

현재 버전 재설치를 하면 파일과 앱이 지워지나요?

Windows Update를 사용하여 문제 해결은 앱·파일·설정을 유지하며 같은 Windows 11 버전을 다시 설치하는 기능입니다. 다만 정전·저장 장치 오류 같은 예외에 대비해 백업은 필요합니다.

Windows 10에서도 같은 방법을 써도 되나요?

문제 해결사 경로와 복구 옵션이 다릅니다. 이 글은 지원 중인 Windows 11 개인용 PC 기준입니다. Windows 10은 일반 지원 상태와 기기별 지원 계약을 먼저 확인하고 해당 버전용 Microsoft 안내를 따르세요.

한 줄 요약

재시작 → Windows Update 문제 해결사 → 시간·인터넷·공간 확인 → 업데이트 캐시 초기화 → DISM·SFC → KB 구분 → 현재 버전 복구 재설치 순서로 진행하세요.
