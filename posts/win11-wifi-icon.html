윈도우11 와이파이 아이콘 사라짐 해결 7단계

2026-09-14·WindowsWi-Fi무선랜드라이버

Windows 11 작업 표시줄에 예전처럼 Wi-Fi 단독 아이콘이 보이지 않는다고 고장인 것은 아닙니다. 네트워크·소리·배터리가 묶인 빠른 설정 영역을 클릭했을 때 Wi-Fi 버튼이나 사용 가능한 네트워크 목록까지 없어졌는지를 먼저 구분하세요.

1. 증상부터 구분

보이는 상태가능성이 큰 원인
지구본·모니터 아이콘이 보임Wi-Fi 미연결 또는 유선 연결 상태일 수 있음
빠른 설정에 Wi-Fi 버튼만 없음무선 어댑터 비활성화·서비스·드라이버 문제
Wi-Fi 버튼은 있는데 목록이 비어 있음비행기 모드, 공유기·거리, 어댑터 문제
장치 관리자에 무선 어댑터가 없음드라이버 또는 하드웨어·노트북 무선 스위치 문제

2. 30초 확인

  1. Win+A를 눌러 빠른 설정을 엽니다.
  2. 비행기 모드가 꺼져 있는지 확인합니다.
  3. 노트북의 무선 기능 키나 물리 스위치가 꺼지지 않았는지 봅니다.
  4. PC와 공유기를 재시작합니다. 공유기는 전원을 뺀 뒤 잠시 기다렸다 다시 연결합니다.
  5. 휴대폰에서도 같은 Wi-Fi가 안 보이면 PC보다 공유기 쪽을 먼저 점검합니다.

3. 복구 7단계

1단계: ‘도움말 보기’ 네트워크 진단

설정 → 시스템 → 문제 해결 → 기타 문제 해결사 → 네트워크 및 인터넷에서 실행하거나 시작 메뉴에서 ‘도움말 보기’를 열어 네트워크 문제 해결을 실행합니다. Microsoft는 Windows 11에서 자동 진단을 먼저 권장합니다.

2단계: Wi-Fi 어댑터 켜기

  1. 시작 버튼을 우클릭하고 장치 관리자를 엽니다.
  2. 네트워크 어댑터를 펼칩니다.
  3. 이름에 Wireless, Wi-Fi, WLAN, 802.11 등이 있는 장치를 찾습니다.
  4. 아래쪽 화살표가 표시되면 우클릭 → 디바이스 사용을 선택합니다.

장치가 아예 없다면 보기 → 숨겨진 장치 표시도 확인하세요. 그래도 없으면 PC 제조사 지원 페이지에서 정확한 모델용 무선랜 드라이버를 준비합니다.

3단계: WLAN AutoConfig 다시 시작

  1. Win+R → services.msc → Enter
  2. WLAN AutoConfig를 찾습니다.
  3. 우클릭 → 다시 시작을 선택합니다.
  4. 중지 상태라면 속성에서 시작 유형을 ‘자동’으로 확인하고 시작합니다.

회사에서 정책으로 서비스를 관리하는 PC라면 임의로 바꾸지 말고 관리자에게 문의하세요.

4단계: Windows 업데이트와 선택적 드라이버 확인

설정 → Windows 업데이트 → 업데이트 확인을 실행합니다. 이어서 고급 옵션 → 선택적 업데이트에 무선랜 드라이버가 있는지 확인하세요. Microsoft는 장치 드라이버를 Windows Update로 받는 방법을 우선 권장합니다.

5단계: 드라이버 업데이트 또는 되돌리기

장치 관리자에서 무선 어댑터를 우클릭해 드라이버 업데이트를 실행합니다. 문제가 업데이트 직후 시작됐다면 속성 → 드라이버 → 드라이버 롤백이 활성화되어 있는지 확인하세요. 출처가 불분명한 드라이버 다운로드 사이트는 사용하지 않습니다.

6단계: 드라이버 재설치

앞 단계가 실패했을 때만 시도합니다. 인터넷이 끊긴 상태에서도 설치할 수 있도록 먼저 제조사 공식 사이트에서 모델에 맞는 드라이버를 다른 PC나 유선 연결로 내려받아 보관하세요.

  1. 장치 관리자 → 네트워크 어댑터 → 무선 어댑터 우클릭
  2. 디바이스 제거를 선택합니다.
  3. PC를 재시작해 Windows의 자동 재설치를 확인합니다.
  4. 자동 설치되지 않으면 미리 받은 제조사 드라이버를 설치합니다.

7단계: 네트워크 초기화

마지막 수단입니다. 설정 → 네트워크 및 인터넷 → 고급 네트워크 설정 → 네트워크 초기화 → 지금 다시 설정을 선택합니다. 네트워크 어댑터와 설정이 제거된 뒤 재부팅 과정에서 다시 설치됩니다.

4. 네트워크 초기화 전 주의

Microsoft 안내에 따르면 초기화 후 알려진 연결이 공용 네트워크 프로필로 바뀔 수 있고, VPN 클라이언트나 Hyper-V 가상 스위치 같은 네트워크 소프트웨어를 다시 설치·설정해야 할 수 있습니다. 회사 PC라면 관리자에게 먼저 문의하고, VPN 설정과 Wi-Fi 암호를 준비하세요.

인터넷이 급하면 스마트폰 USB 테더링이나 유선 LAN을 임시로 사용해 공식 드라이버를 받을 수 있습니다. 공용 PC에서는 개인 휴대폰 연결 정책을 확인하세요.

5. FAQ

빠른 설정에 Wi-Fi 버튼을 다시 추가하면 해결되나요?

버튼 배치만 빠진 경우에는 도움이 됩니다. 하지만 설정 앱에서도 Wi-Fi 메뉴가 없고 장치 관리자에서 어댑터가 비활성화됐다면 2~6단계를 확인해야 합니다.

네트워크 명령어부터 실행해도 되나요?

netsh나 ipconfig 명령은 Wi-Fi 장치는 보이지만 인터넷 연결만 안 될 때 유용합니다. Wi-Fi 항목 자체가 사라진 경우에는 어댑터·WLAN 서비스·드라이버 확인이 먼저입니다.

장치 관리자에도 무선랜이 없습니다.

숨겨진 장치를 확인하고 완전히 종료 후 다시 켜 보세요. 이후에도 없으면 제조사 공식 드라이버와 BIOS의 무선 설정, 물리 스위치를 확인해야 합니다. 하드웨어 고장 가능성도 있습니다.

초기화하면 개인 파일이 지워지나요?

네트워크 초기화는 Windows의 개인 문서를 지우는 PC 초기화와 다릅니다. 다만 네트워크 어댑터 설정, VPN·가상 네트워크 구성 등에 영향을 줄 수 있습니다.

한 줄 요약

비행기 모드·재시작 → 자동 진단 → 어댑터 사용 → WLAN 서비스 → Windows 업데이트 → 드라이버 재설치 → 마지막에 네트워크 초기화 순서로 확인하세요.
