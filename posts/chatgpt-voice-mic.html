ChatGPT 음성모드 마이크 안 될 때 해결 7단계

ChatGPT 음성 대화가 시작되지 않거나 내 말을 듣지 못하면 먼저 음소거, ChatGPT 권한, 브라우저 권한, 운영체제 권한, 입력 장치를 분리해 확인하세요. OpenAI 공식 안내에 따르면 모바일 앱은 ChatGPT의 마이크 권한이, 웹은 브라우저의 마이크 권한이 필요합니다.

1. 30초 안에 원인 구분

  1. 휴대폰 녹음기나 Windows 녹음 앱에서 목소리가 들어오는지 시험합니다.
  2. 다른 앱도 못 들으면 장치·운영체제 권한 문제부터 해결합니다.
  3. ChatGPT만 못 들으면 앱 또는 chatgpt.com의 사이트 권한을 확인합니다.
  4. 내 목소리는 인식하지만 답변 소리만 안 나면 마이크가 아니라 출력 음량·스피커 문제입니다.
  5. ‘한도 도달’ 안내가 보이면 권한 변경 대신 안내된 초기화 시점까지 기다립니다.

2. 해결 7단계

1단계: 음성 화면의 음소거 확인

메시지 입력창의 음성 아이콘으로 대화를 시작하고, 음성 화면의 마이크가 음소거 상태인지 확인합니다. 헤드셋 케이블이나 블루투스 이어폰에도 물리 음소거가 있는지 보세요. OpenAI는 한 번에 하나의 음성 대화만 사용할 수 있다고 안내합니다.

2단계: 아이폰·아이패드 권한 켜기

설정 → 개인정보 보호 및 보안 → 마이크에서 ChatGPT를 켭니다. Apple 공식 안내에 따르면 마이크를 요청한 앱별로 접근을 변경할 수 있습니다. 목록에 ChatGPT가 없다면 앱에서 음성 기능을 다시 열어 권한 요청을 띄워 보세요.

3단계: 갤럭시·안드로이드 권한 켜기

설정 → 보안 및 개인정보 보호(또는 개인정보 보호) → 개인정보 보호 대시보드 → 마이크에서 ChatGPT 권한을 확인합니다. Android 12 이상에서는 빠른 설정의 전체 마이크 접근 스위치가 꺼져 있지 않은지도 봅니다. 제조사와 Android 버전에 따라 메뉴 이름은 다를 수 있습니다.

4단계: 웹 브라우저 사이트 권한 확인

chatgpt.com 주소 왼쪽의 사이트 정보 아이콘에서 마이크를 허용으로 바꾼 뒤 페이지를 새로고침합니다. Chrome에서는 설정 → 개인정보 보호 및 보안 → 사이트 설정 → 마이크에서 chatgpt.com이 차단 목록에 있는지 확인하고, 올바른 기본 마이크를 선택합니다.

5단계: Windows 11 마이크 권한 확인

설정 → 개인정보 및 보안 → 마이크에서 마이크 액세스, 앱에서 마이크에 액세스하도록 허용, 데스크톱 앱에서 마이크에 액세스하도록 허용을 확인합니다. 브라우저는 데스크톱 앱으로 분류될 수 있습니다.

6단계: 입력 장치와 충돌 분리

  1. 블루투스를 잠시 끄고 휴대폰 내장 마이크로 시험합니다.
  2. PC는 Chrome 마이크 설정에서 실제 사용할 장치를 선택합니다.
  3. 회의·녹음 앱을 종료해 마이크 충돌을 줄입니다.
  4. ChatGPT 또는 브라우저를 완전히 종료하고 다시 엽니다.
  5. 조용한 곳에서 짧은 문장으로 새 음성 대화를 시험합니다.

7단계: 업데이트·재로그인·상태 확인

ChatGPT 앱과 브라우저를 최신 버전으로 업데이트하고 기기를 재시작합니다. 그래도 안 되면 새 채팅에서 시험한 뒤 재로그인합니다. 회사·학교 계정은 관리자가 Voice를 끌 수 있으므로 조직 관리자에게 확인하세요. 여러 기기에서 동시에 실패한다면 잠시 뒤 다시 시도하고 OpenAI 상태 페이지를 확인합니다.

3. 증상별 확인표

증상먼저 확인할 것
음성 아이콘이 안 보임로그인, 앱·브라우저 업데이트, 요금제·지역·워크스페이스 설정
권한 거부 오류앱·사이트 권한과 운영체제 마이크 권한
파형이 움직이지 않음음소거, 전체 마이크 스위치, 입력 장치
말을 자꾸 끊음배경 소음, 긴 침묵, 이어폰 사용, 네트워크
다른 언어로 인식ChatGPT 설정 → Voice → Language
목소리는 들어가지만 소리가 안 남미디어 음량, 출력 장치, 블루투스 연결

4. 권한과 사용량을 구분하세요

음성 기능의 제공 방식과 한도는 요금제, 계정, 지역, 앱 버전, 조직 설정에 따라 달라질 수 있습니다. 화면에 사용량 한도 안내가 나타나면 마이크 권한 문제로 오해하지 마세요. 권한을 허용하면 앱이나 사이트가 마이크를 사용할 수 있으므로 공용 PC에서는 사용 후 사이트 권한을 다시 차단하고 음성 대화를 종료하세요.

5. FAQ

마이크 권한을 켰는데도 파형이 안 움직입니다.

휴대폰 녹음기에서 먼저 시험하세요. 녹음기도 실패하면 ChatGPT보다 운영체제 권한이나 장치 문제입니다. 녹음기는 되면 블루투스를 끄고 ChatGPT 권한을 다시 확인합니다.

Chrome에서 ‘허용’을 눌렀는데 안 됩니다.

Windows의 데스크톱 앱 마이크 접근과 Chrome의 기본 입력 장치를 함께 확인한 뒤 브라우저를 재시작하세요.

대화가 자꾸 중간에 끊깁니다.

OpenAI는 배경 소음과 긴 침묵이 끊김에 영향을 줄 수 있다고 안내합니다. 이어폰을 쓰고 조용한 환경에서 시험하세요. 한도 또는 최대 세션 길이 안내가 표시됐는지도 확인합니다.

음성 기록은 글자 그대로 저장되나요?

음성 대화가 끝난 뒤 대화 기록에 전사가 추가될 수 있지만 실제 대화와 정확히 일치하지 않을 수 있습니다. 민감한 정보는 말하지 말고 중요한 내용은 원문과 대조하세요.

한 줄 요약

음소거 → 휴대폰 앱 권한 또는 브라우저 사이트 권한 → 운영체제 마이크 권한 → 입력 장치 → 업데이트·재시작 → 계정·사용량 확인 순서로 해결하세요.
