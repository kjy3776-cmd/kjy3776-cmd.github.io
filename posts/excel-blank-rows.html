엑셀 빈 행 한 번에 삭제하는 3가지 방법 (이동 옵션·필터·COUNTA)

엑셀에서 데이터를 붙여 넣거나 CSV를 불러오면 빈 행이 군데군데 끼어 있는 경우가 많습니다. 정렬이 꼬이고, 피벗 테이블 범위가 이상해지고, VLOOKUP도 예상과 다르게 동작합니다. 이 글에서는 Windows 엑셀(Microsoft 365 / Excel 2021) 기준으로 엑셀 빈 행 삭제 방법을 세 가지로 정리합니다.

1. 문제 정의: “빈 행”이란?

여기서 말하는 빈 행은 보통 아래 둘 중 하나입니다.

  • 행 전체가 비어 있음 — 모든 셀이 공백
  • 핵심 열이 비어 있음 — 예: A열(이름)만 비어 있고 옆 열에 수식·서식만 남아 있음

후자는 “빈 행처럼 보이지만” 실제로는 값이 있는 셀이 섞여 있을 수 있습니다. 그래서 한 열만 보고 삭제할지, 행 전체를 보고 삭제할지부터 정하는 것이 중요합니다.

[스크린샷: 빈 행이 섞인 표 예시 — A~D열, 3·7·12행이 비어 있음]

2. 30초 퀵 체크 (삭제 전에 이것만)

  1. 원본 백업 — Ctrl+S로 저장한 뒤, 파일을 복사하거나 시트를 복제합니다. (시트 탭 우클릭 → 이동/복사 → 복사본 만들기)
  2. 표(테이블)인지 일반 범위인지 — 리본에 테이블 디자인 탭이 보이면 Excel 표입니다.
  3. 병합 셀 — 제목 행에 병합이 있으면 이동 옵션·필터가 기대와 다르게 동작할 수 있습니다.
  4. 보호된 시트 — 검토 → 시트 보호가 켜져 있으면 행 삭제가 막힙니다.
  5. 삭제 기준 열 하나 정하기 — “A열이 비면 그 행은 버린다”처럼 기준을 먼저 정하세요.

팁: 데이터 안 아무 셀을 클릭한 뒤 Ctrl+Shift+End로 사용 범위 끝까지, 또는 Ctrl+A로 현재 영역을 선택합니다.

3. 방법 1: 이동 옵션(Go To Special)으로 빈 행 한 번에 삭제

가장 빠른 방법입니다. “특정 열의 빈 셀 = 삭제할 행”일 때 특히 잘 맞습니다.

준비

  • 삭제 기준으로 삼을 한 열을 선택합니다. (예: A2부터 A열 데이터 끝까지)
  • 헤더가 있다면 헤더는 제외하세요.

단계

  1. 기준 열에서 데이터 구간을 선택합니다. (예: A2 클릭 → Ctrl+Shift+↓)
  2. F5 (또는 Ctrl+G) → 이동 옵션 클릭 — 또는 홈 → 찾기 및 선택 → 이동 옵션
  3. 빈 셀 선택 → 확인 → 선택한 열 안의 빈 셀만 다중 선택됩니다.
  4. 빈 셀이 선택된 상태에서 행 전체 삭제: Ctrl+- 또는 우클릭 → 삭제 → 행 전체
  5. “행 전체”를 선택하고 확인합니다.

[스크린샷: 이동 옵션 창에서 ‘빈 셀’ 선택]

[스크린샷: 빈 셀 선택 후 Ctrl+- 로 행 삭제]

장점 / 주의

장점주의
클릭 몇 번으로 끝한 열 기준이라, 그 열만 비고 옆 열에 값이 있어도 행이 삭제됨
키보드로 빠르게 반복 가능병합 셀·숨긴 행이 있으면 선택이 어긋날 수 있음
필터를 켜지 않아도 됨“행 전체가 완전 공백”만 지우려면 방법 3이 더 안전

팁: 표 전체를 선택한 채 빈 셀을 찾으면 행 중간 빈 칸까지 잡혀 열이 찌그러지는 삭제가 될 수 있습니다. 기준 열 하나만 선택하세요.

4. 방법 2: 필터로 공백만 보이게 한 뒤 삭제

눈으로 확인하면서 지우고 싶을 때, 또는 특정 열의 (비어 있음)만 걸러내고 싶을 때 적합합니다.

  1. 헤더가 있는 데이터 범위를 선택합니다. (또는 아무 셀에서 Ctrl+A)
  2. 데이터 → 필터 (Ctrl+Shift+L)
  3. 기준 열의 필터 드롭다운 ▼ 클릭
  4. (비어 있음)만 체크하고 확인
  5. 보이는 데이터 행을 선택합니다. 헤더 행은 포함하지 마세요.
  6. 우클릭 → 삭제 → 시트 행 (또는 Ctrl+- → 행 전체)
  7. 데이터 → 필터를 다시 눌러 필터를 해제합니다.

[스크린샷: 필터 메뉴에서 ‘(비어 있음)’ 체크]

[스크린샷: 필터링된 빈 행 선택 후 행 삭제]

Excel 표(테이블)인 경우 필터가 기본으로 켜져 있는 경우가 많고, 행 삭제 시 표 행으로 지워지는 것이 일반적입니다.

5. 방법 3: COUNTA 도우미 열로 “완전 빈 행”만 골라 삭제

옆 열에 서식·수식·공백 문자가 남아 있어 겉보기엔 빈 행인데 이동 옵션으로는 안 잡히는 경우가 있습니다. 행 전체가 진짜로 비었는지 판별한 뒤 지우고 싶을 때 COUNTA가 유용합니다.

  1. 데이터 오른쪽 빈 열에 헤더를 만듭니다. 예: E1에 채움수
  2. 첫 데이터 행에 수식 입력 (A~D열이 데이터라고 가정):
=COUNTA(A2:D2)
  1. 채우기 핸들로 끝까지 복사 (더블클릭으로 자동 채우기 가능)
  2. 채움수 열에 필터를 겁니다.
  3. 0만 표시되도록 필터
  4. 보이는 행을 삭제 후 필터 해제, 필요 없으면 채움수 열 삭제

[스크린샷: E열에 COUNTA 수식과 결과가 0인 행]

변형 수식

목적수식 예
행 구간 값 개수=COUNTA(A2:D2)
특정 열만=COUNTA(A2) 또는 =A2=""
공백 문자까지 비어 있다고 볼 때=LEN(TRIM(A2))=0
여러 열이 모두 공백인지=AND(A2="",B2="",C2="",D2="")

6. 안 될 때 / 주의사항

병합된 셀

병합 구간이 있으면 빈 셀 선택·행 삭제가 오류를 일으킬 수 있습니다. 홈 → 병합하고 가운데 맞춤을 해제(병합 취소)한 뒤 다시 시도하세요.

Excel 표(테이블)

빈 행을 정리한 뒤 표 범위가 남는다면 표 디자인 → 크기 조정으로 맞추거나, 표 디자인 → 범위로 변환 후 작업해도 됩니다.

보호된 시트

검토 → 시트 보호 해제 후 삭제하세요. 비밀번호 우회는 다루지 않습니다.

“빈 칸처럼 보이는데” 안 지워질 때

  • 셀에 스페이스, 줄바꿈, 보이지 않는 문자, "" 수식 결과가 있을 수 있습니다.
  • =LEN(A2)로 길이를 재보거나, 찾기 및 바꾸기로 공백을 제거한 뒤 다시 시도하세요.

7. FAQ

Q1. 뭐가 제일 빠른가요?

기준 열이 명확하면 방법 1(이동 옵션)이 가장 빠릅니다. 확인이 필요하면 방법 2, 행 전체가 비었는지 엄격히 보려면 방법 3을 쓰세요.

Q2. 빈 셀만 지우면 열이 왼쪽으로 당겨지는데요?

Ctrl+- 후 “왼쪽 셀 밀기”를 고르면 행이 아니라 셀만 지워집니다. 반드시 행 전체를 선택하세요. 또 기준 열만 선택한 뒤 진행하세요.

Q3. Microsoft 365와 Excel 2021에서 메뉴가 다른가요?

핵심 기능(이동 옵션, 필터, COUNTA)은 동일합니다. 찾기 및 선택 / 데이터 → 필터 경로를 기준으로 찾으면 됩니다.

Q4. 삭제한 행을 되돌리려면?

저장 전이면 Ctrl+Z. 이미 저장·닫았다면 백업본이 필요합니다.
