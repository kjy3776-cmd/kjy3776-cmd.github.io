웨이브에서 로그인할 수 없거나 로그인 후 결제한 이용권이 보이지 않는다면, 앱을 지우거나 새 계정을 만들기 전에 처음 가입한 방식을 확인하세요. Wavve의 공식 화면은 이메일 회원, 2021년 9월 이전 ID 회원, 카카오·T 아이디·네이버 등 SNS 간편가입 회원의 복구 경로를 다르게 안내합니다. 특히 SNS 간편가입은 기존 POOQ·Wavve 계정과 자동 연동되지 않습니다. 이 글은 2026년 9월 27일 한국 Wavve 계정 복구·회원가입·문의 화면을 대조한 안내이며, 특정 유료 계정에서 직접 로그인 시험을 했다는 뜻은 아닙니다. TV 앱과 제휴·통신사 상품 화면은 다를 수 있으므로 로그인·결제 문제는 실제 가입 경로를 우선 확인하세요.

1. 1분 해결 요약

  1. 이전 로그인 버튼이 카카오·T 아이디·네이버·페이스북·Apple 중 하나였는지, Wavve 이메일·ID와 비밀번호를 직접 입력했는지 떠올립니다.
  2. SNS 간편가입이었다면 같은 SNS 버튼으로 로그인하고, SNS 비밀번호는 해당 서비스의 공식 경로에서 복구합니다. Wavve 자체 비밀번호 재설정 폼에 넣지 마세요.
  3. Wavve 자체 계정이라면 공식 아이디 찾기 또는 공식 비밀번호 재설정에서 가입 시기·방식에 맞는 항목을 선택합니다.
  4. 로그인 후 이용권이 사라진 것처럼 보이면 새 결제 전에 원래 결제한 계정인지 확인합니다. SNS 가입은 기존 계정과 자동 연동되지 않습니다.

3. 가입 방식을 잃지 않는 계정 복구 7단계

1단계: 먼저 가입 방식을 확인

평소 누르던 로그인 버튼, 기존 결제 영수증의 계정 정보, 저장된 비밀번호 관리자의 사이트 이름을 확인합니다. 카카오·T 아이디·네이버·페이스북·Apple로 가입했다면 SNS 간편가입, 직접 이메일 또는 ID와 Wavve 비밀번호를 만들었다면 Wavve 자체 계정입니다. 등록 이메일과 결제 이메일이 항상 같다고 추정하지 말고, 계정 화면에서 확인하세요. 비밀번호나 영수증 전체를 메신저·게시판에 붙여 넣지 마세요.

2단계: SNS 간편가입은 같은 SNS 버튼으로 재시도

Wavve 아이디 찾기 화면은 SNS 회원에게 각 SNS 간편 로그인을 이용하라고 안내합니다. 예전에 카카오로 시작했다면 카카오 버튼, 네이버로 시작했다면 네이버 버튼으로 들어가세요. 같은 이메일 주소가 표시되더라도 로그인 방식이 달라 별도 계정으로 취급될 수 있으므로 새 계정을 만들어 시험하지 마세요. SNS 자체 로그인이 안 되면 해당 서비스의 공식 계정 복구를 이용합니다.

3단계: Wavve 자체 계정이면 공식 아이디 찾기

Wavve 아이디 찾기에서 등록한 이름과 휴대폰 번호 또는 이메일 주소로 간편찾기를 진행합니다. 본인인증 찾기도 제공하지만, 공식 화면에는 본인 명의 휴대폰 인증을 진행한 회원만 사용 가능하고 간편가입 회원은 사용할 수 없다고 적혀 있습니다. 인증 실패만 보고 계정이 없다고 단정하지 마세요.

4단계: 비밀번호 재설정은 ID·이메일 회원을 구분

Wavve 비밀번호 재설정에서 2021년 9월 이전 ID 회원인지 이후 이메일 회원인지 해당 항목을 선택합니다. 공식 폼은 등록 정보에 따라 휴대폰 번호 또는 이메일 주소를 이용한 인증을 보여 줍니다. 인증번호는 공식 Wavve 화면에만 입력하고 타인에게 전달하지 마세요. SNS 가입이었다면 이 단계가 아니라 SNS 제공자의 비밀번호 복구를 이용합니다.

5단계: 복구 후 원래 계정의 이용권 확인

로그인에 성공한 뒤 MY의 계정과 이용권 표시를 확인합니다. Wavve 회원가입 안내는 SNS 간편가입이 기존 POOQ 또는 Wavve 계정과 연동되지 않는다고 명시합니다. 따라서 로그인은 됐는데 기존 이용권이 안 보인다면, 비밀번호 오류가 아니라 다른 계정에 들어간 상황인지 먼저 확인하세요. 바로 다시 구매하면 중복 결제 위험이 있습니다.

6단계: 한 기기에서만 실패하면 환경을 분리

원래 가입 방식으로 공식 Wavve 웹에서 로그인되는데 특정 앱·브라우저에서만 실패한다면, 앱·브라우저를 최신 버전으로 업데이트하고 재시작한 뒤 다시 시도합니다. 다른 기기에서도 같은 증상인지 비교해 계정 문제인지 기기 문제인지 분리합니다. 로그아웃이나 앱 삭제 전에 저장된 로그인 수단과 인증 가능한 휴대폰·이메일을 확인하세요. 기기 캐시나 전체 브라우저 데이터를 무조건 지우지 마세요.

7단계: 복구 정보가 맞지 않으면 공식 1:1 문의

가입 방식을 기억하지 못하거나 본인 명의 인증을 사용할 수 없고 이용권 계정도 식별되지 않는다면 Wavve 공식 1:1 문의를 이용합니다. 공식 문의 양식은 PC 웹·안드로이드·iPhone·스마트TV 등 기기와 OS·브라우저 환경을 받습니다. 가입 방식 후보, 오류 문구, 기기·앱 버전, 결제한 경로를 정리하되 공개 게시판에 영수증 번호·카드 정보·인증번호를 올리지 마세요. 통신사·제휴 결제라면 실제 결제처에도 계정 연결 상태를 확인하세요.

4. 정상 확인과 실패 시 다음 조치

  • 처음 사용한 가입 방식으로 로그인되고, 기존에 결제한 계정의 이용권이 표시되는지 확인합니다.
  • PC 웹에서만 성공하거나 모바일 앱에서만 실패한다면 같은 계정으로 로그인한 것이 맞는지 확인한 후 기기·앱 정보를 고객센터에 전달합니다.
  • 로그인은 되지만 영상 재생에서 오류 코드가 보이면 계정 복구와 다른 문제입니다. 정확한 오류 문구·기기를 기록하고 재생 문제로 따로 문의하세요.
  • 계정 찾기·비밀번호 재설정·SNS 복구가 모두 실패하면 반복 가입·재결제하지 말고 공식 1:1 문의에서 본인 계정 확인 절차를 안내받으세요.

5. 데이터·결제·계정·보안 주의

  • 중복 결제: 새 SNS 계정으로 로그인하거나 새 Wavve 계정을 만들면 기존 이용권이 보이지 않을 수 있습니다. 원래 결제한 계정을 확인하기 전에는 이용권을 다시 구매하지 마세요.
  • 계정 정보: ID 회원과 이메일 회원의 재설정 메뉴가 다르고, SNS 회원은 SNS 제공자의 공식 복구가 우선입니다. 임의 계정 병합이나 제삼자 로그인 대행을 이용하지 마세요.
  • 개인정보: 인증번호·비밀번호·영수증 전체·카드번호를 외부 게시글에 공개하지 마세요. Wavve의 1:1 문의에는 필요한 기기·오류 정보만 공식 화면을 통해 전달합니다.
  • 기기 데이터: 앱 삭제나 브라우저 데이터 전체 삭제는 저장된 로그인 상태와 설정을 잃을 수 있으므로 가입 수단을 확인한 후 마지막에 고려합니다.

6. FAQ

카카오·네이버로 가입했는데 Wavve 비밀번호를 재설정해야 하나요?

아니요. Wavve 공식 복구 화면은 SNS 회원에게 해당 SNS의 공식 로그인·비밀번호 재설정 경로를 이용하라고 안내합니다. Wavve 자체 ID·이메일 회원의 비밀번호 폼과 구분하세요.

예전 Wavve 아이디를 SNS 버튼으로 로그인하면 같은 계정인가요?

자동으로 같아지지 않습니다. Wavve의 회원가입 안내에는 SNS 간편가입이 기존 POOQ·Wavve 계정과 연동되지 않는다고 명시돼 있습니다. 기존 이용권을 찾는다면 원래 가입 방식으로 로그인하세요.

휴대폰 본인인증으로 아이디 찾기가 안 되는 간편가입 회원은 어떻게 하나요?

Wavve 본인인증 찾기는 간편가입 회원이 사용할 수 없다고 표시합니다. 가입한 SNS 로그인으로 돌아가고, 어느 계정인지도 모르면 공식 1:1 문의로 상황을 전달하세요.

로그인은 됐는데 결제한 이용권이 안 보이면 다시 결제해야 하나요?

먼저 원래 결제한 계정으로 로그인했는지 확인하세요. SNS 간편가입은 기존 계정과 자동 연동되지 않습니다. 결제처·계정이 맞는데도 이용권이 없다면 새로 결제하기 전 Wavve 고객센터에 확인받으세요.

TV에서만 로그인 실패하면 이 절차가 그대로 적용되나요?

이 글의 경로는 Wavve 웹 계정 복구 화면 기준입니다. 먼저 휴대폰·PC의 공식 웹에서 같은 계정으로 로그인되는지 확인하고, TV에서만 실패하면 TV 모델·앱 버전·오류 문구를 고객센터에 전달하세요. TV 인증 화면이나 코드를 비공식 사이트에 입력하지 마세요.
