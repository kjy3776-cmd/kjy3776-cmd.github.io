Excel ‘파일 형식 또는 파일 확장명이 잘못되어 열 수 없습니다’ 해결 7단계

“파일 형식 또는 파일 확장명이 잘못되어 ‘파일명.xlsx’ 파일을 열 수 없습니다. 파일이 손상되지 않았는지, 파일 확장명이 파일 형식과 일치하는지 확인하십시오.”라는 오류가 나오면 이름 끝의 .xlsx만 바꾸지 마세요. 파일 이름과 내부 형식이 다를 수도 있지만, 전송이 끝나지 않았거나 통합 문서 자체가 손상됐을 수도 있습니다. Microsoft는 확장자가 실제 형식과 다르다는 경고와 손상된 통합 문서 복구를 별도로 설명합니다. 같은 화면처럼 보여도 원인은 다르므로 아래 순서로 분리합니다. 이 글은 2026년 9월 27일 Microsoft 공식 문서를 대조해 작성했으며, 특정 독자 파일을 직접 복구해 보았다는 의미는 아닙니다.

1. 1분 해결 요약

  1. 문제 파일을 복사해 원본과 사본을 분리합니다. 원본에 덮어쓰지 마세요.
  2. 보낸 사람이나 다운로드 출처와 파일 이름의 실제 확장자(.xlsx·.xls·.csv 등)를 확인합니다.
  3. 메일·클라우드·USB에서만 실패하면 출처를 확인한 뒤 파일을 다시 받아 로컬 사본으로 비교합니다.
  4. 확장자가 맞고 한 파일만 실패하면 Excel 파일 → 열기 → 찾아보기 → 열기 버튼 옆 화살표 → 열기 및 복구를 사본에서 시도합니다.
  5. OneDrive·SharePoint 저장 파일은 버전 기록에 정상 이전본이 있는지 확인하되, 복원 전에 현재본을 별도 보관합니다.

멈춤 기준: 출처가 불명확하거나 파일에 기밀 정보가 있으면 임의의 온라인 복구 사이트에 업로드하지 마세요.

2. 증상별 원인표

보이는 상황구분할 원인먼저 할 일
이름은 .xlsx인데 확장자와 실제 형식이 다르다는 경고텍스트·CSV·구형 형식을 이름만 바꿨을 수 있음발신자에게 실제 저장 형식 확인
메일 첨부·다운로드 파일 하나만 안 열림첨부·전송 오류 또는 해당 파일 손상로컬 저장·재다운로드·재전송
네트워크·USB 위치에서만 실패동기화·저장 장치·연결 문제 가능성원본 보존 후 로컬 사본으로 비교
같은 폴더의 다른 통합 문서는 정상특정 파일의 형식·손상 문제 가능성사본에서 열기 및 복구
OneDrive 웹에서도 손상·확장자 오류클라우드에 저장된 현재 버전 문제 가능성버전 기록의 정상 이전본 확인
모든 Excel 파일이 실패이 글의 특정 파일 오류와 다른 앱 문제 가능성빈 통합 문서와 다른 정상 파일로 비교

이 표는 진단을 위한 가능성 분기입니다. 파일을 검사하지 않고 손상이나 악성 여부를 단정할 수는 없습니다.

3. 쉬운 방법부터 해결하는 7단계

1단계: 원본을 보존하고 오류 문구를 기록

파일 탐색기에서 문제 파일을 복사해 원래 확장자는 그대로 두고 파일 이름에만 -복구용-사본을 붙입니다. 예를 들어 원본이 보고서.xlsx라면 보고서-복구용-사본.xlsx로 만듭니다. 오류가 확장자 불일치 경고인지, 아예 파일을 열 수 없다는 오류인지 문구를 기록합니다. 전자는 Excel이 형식이 다른 파일을 감지한 경우이고, 후자는 손상도 의심해야 합니다.

2단계: 출처와 실제 저장 형식을 확인

파일을 만든 사람·서비스가 Excel 통합 문서로 내보냈는지 확인하세요. 예를 들어 내용이 CSV나 텍스트인데 누군가 이름만 .xlsx로 바꿨다면 Excel 형식으로 변환된 것이 아닙니다. Microsoft는 확장자와 실제 형식이 다른 경우 발신자 신뢰 여부를 먼저 판단하라고 안내합니다. 알 수 없는 발신자의 첨부 파일은 ‘예’나 콘텐츠 사용을 눌러 열지 마세요. 형식이 잘못 저장된 것이 확인되면 발신자에게 Excel의 다른 이름으로 저장으로 올바른 형식으로 내보낸 파일을 요청합니다.

3단계: 받은 파일이면 다시 저장·전송받아 비교

메일 프로그램에서 바로 열 때만 오류가 나면 발신자를 확인한 뒤 첨부 파일을 로컬 폴더에 저장해 엽니다. 다운로드·클라우드 동기화·USB 연결이 중간에 끊겼다면 원본 제공처에서 다시 받거나 제공자에게 재전송을 요청하세요. 파일 크기가 예상보다 아주 작거나 0바이트라면 복구 메뉴보다 정상 원본을 다시 받는 편이 우선입니다. 같은 출처의 다른 정상 파일과 비교하면 앱 전체 문제인지 한 파일 문제인지 분리할 수 있습니다.

4단계: 한 파일만 실패하면 ‘열기 및 복구’ 실행

Windows 데스크톱 Excel에서 빈 통합 문서를 열고 파일 → 열기 → 찾아보기로 복구용 사본을 찾습니다. 파일을 선택한 뒤 열기 버튼 오른쪽 화살표에서 열기 및 복구를 고르고 먼저 복구를 선택합니다. Microsoft 공식 절차입니다. 자동 파일 복구 화면이 먼저 열렸다면 그 결과를 확인하세요. 메뉴 이름이나 위치는 빌드·언어에 따라 달라질 수 있습니다.

5단계: 복구가 실패할 때만 ‘데이터 추출’

4단계의 복구가 통합 문서를 열지 못하면 같은 메뉴에서 데이터 추출을 시도합니다. Microsoft는 값과 수식을 최대한 꺼내는 용도라고 설명합니다. 서식·차트·외부 연결·매크로가 온전히 남는다는 보장은 없습니다. 새 파일로 저장해 시트 수, 핵심 값·수식·차트·피벗·연결을 원본 기대치와 대조하세요. 구조가 중요하다면 추출본을 원본 대신 바로 업무에 쓰지 마세요.

6단계: OneDrive·SharePoint라면 버전 기록 확인

클라우드에 저장된 파일이 웹 Excel에서도 손상 또는 확장자 오류를 보이면 파일의 버전 기록에서 오류 전 버전을 살펴보세요. Microsoft는 Excel 웹의 해당 오류에 이전 버전 복원을 안내합니다. 다만 복원은 선택한 이전 버전으로 현재 버전을 대체해 이후 변경 사항을 잃을 수 있으므로 현재 파일과 필요한 최근 변경을 별도 보관한 뒤 소유자·공동 편집자와 확인하세요. 로컬에만 저장된 파일에는 이 클라우드 버전 기록 절차가 적용되지 않습니다.

7단계: 형식이 다르거나 복구가 안 되면 원본 경로로 돌아가기

실제 형식이 Excel 통합 문서가 아니라고 확인됐다면 이름만 다시 고치기보다 만든 앱이나 발신자에게 올바른 형식으로 다시 내보내기를 요청합니다. 재전송·복구·이전 버전 모두 실패하면 마지막 정상 백업 또는 파일 제공자의 원본을 찾으세요. 회사·학교 파일은 공유 권한과 복구 가능 버전을 IT 관리자·소유자에게 확인하고, Microsoft의 공식 통합 문서 복구 안내에 나온 추가 방법은 사본에서만 검토하세요.

4. 정상 확인과 실패 시 다음 조치

  • 복구한 사본을 닫았다 다시 열어 동일 오류가 사라졌는지 봅니다.
  • 시트 개수, 마지막 데이터 행, 핵심 수식·값, 차트·피벗·외부 연결을 확인합니다. 데이터 추출 결과는 특히 구조가 달라질 수 있습니다.
  • 정상이라면 다른 이름으로 저장에서 실제 내용과 일치하는 형식으로 별도 저장하고, 원본은 비교가 끝날 때까지 보관합니다.
  • 계속 실패하면 정확한 오류 문구, 실제 확장자, 파일 출처, 크기, 저장 위치, Excel 제품·버전을 기록해 파일 제공자 또는 Microsoft 공식 지원 문서를 확인합니다.

5. 데이터·결제·계정·보안 주의

  • 데이터: 복구·버전 복원을 원본에 바로 적용하면 최근 수정분이나 서식이 사라질 수 있습니다. 원본과 사본을 분리하고 확인 전 덮어쓰지 마세요.
  • 결제: 이 오류 해결에 새 Microsoft 365 결제나 유료 제3자 복구 도구를 먼저 구매할 필요는 없습니다. 파일이 중요한 경우 복구 결과를 검증한 뒤 적절한 지원을 결정하세요.
  • 계정: OneDrive·SharePoint 버전 기록은 원래 계정과 파일 권한이 필요합니다. 계정 우회나 다른 사람의 로그인 정보 요청은 하지 마세요.
  • 보안: 출처가 불명확한 파일을 열기 위해 경고를 무시하거나 매크로를 켜지 마세요. 인사·재무·고객 데이터가 든 파일은 온라인 ‘무료 복구’ 사이트에 업로드하지 말고 조직의 공식 복구 경로를 이용하세요.

6. FAQ

.xls를 .xlsx로 이름만 바꾸면 되나요?

아닙니다. 확장자 이름을 바꾸는 것과 실제 파일 형식을 변환하는 것은 다릅니다. 원본 형식으로 정상적으로 열린 파일을 Excel의 다른 이름으로 저장에서 올바른 형식으로 저장하거나 발신자에게 다시 내보내 달라고 하세요.

열기 및 복구의 ‘데이터 추출’은 완전 복구인가요?

아닙니다. 값·수식은 가져올 수 있어도 서식·차트·연결 등이 손실될 수 있습니다. 업무에 쓰기 전에 주요 내용과 구조를 검수하세요.

OneDrive 버전 기록에서 바로 복원해도 되나요?

이전 버전으로 현재 파일이 바뀌며 그 후의 수정분을 잃을 수 있습니다. 현재본을 별도로 보관하고 공동 편집자와 확인한 뒤 복원하세요.

메일에서 바로 열면 오류가 나는데 저장하면 열리는 이유는 무엇인가요?

메일 프로그램에서 바로 여는 경로와 로컬 파일 열기 경로가 다를 수 있습니다. 출처가 신뢰할 수 있는지 확인한 뒤 로컬에 저장한 사본으로 작업하세요. Microsoft도 신뢰 가능한 발신자의 첨부 통합 문서는 PC에 저장해 Excel에서 열어 보라고 안내합니다.

한 줄 요약

원본 복사 → 출처·실제 형식 확인 → 다시 받기 → 사본에서 열기 및 복구 → 필요할 때 데이터 추출·클라우드 버전 기록 순서로 진행하세요.
