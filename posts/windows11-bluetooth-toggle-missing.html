Windows 11 ‘Bluetooth 켜기 버튼 사라짐’ 해결 7단계

2026-09-27 확인·Windows 11 Home·Pro / 내장·USB Bluetooth 어댑터Bluetooth드라이버

빠른 설정에서 파란 Bluetooth 타일만 안 보이는 것과 설정 앱에서 켜기 스위치까지 사라진 것은 다른 문제입니다. 전자는 표시 위치를 확인하면 끝날 수 있지만, 후자는 Windows가 어댑터를 인식하지 못하는지 확인해야 합니다. 이어폰 한 개만 연결되지 않는다면 이 글보다 기기 페어링 문제를 점검하세요.

1. 1분 해결 요약

  1. Win+A의 빠른 설정을 스크롤해 Bluetooth 타일을 찾고, 설정 → Bluetooth 및 장치에 켜기 스위치가 있는지 비교합니다.
  2. 비행기 모드를 끄고, 시작 메뉴의 도움말 보기에서 Bluetooth 문제 해결사를 실행합니다.
  3. 스위치가 계속 없다면 작업을 저장한 뒤 Shift를 누른 채 시작 → 전원 → 시스템 종료를 선택합니다. 전원이 꺼지면 1분 뒤 다시 켭니다.
  4. 장치 관리자에서 Bluetooth 어댑터가 보이는지 확인합니다. 보이면 활성화·드라이버 업데이트, 안 보이면 PC 모델의 지원 여부와 제조사 공식 드라이버를 확인합니다.

회사·학교 PC라면 드라이버·펌웨어·장치 정책을 임의로 바꾸지 말고 관리자에게 먼저 문의하세요. Bluetooth가 없는 데스크톱은 소프트웨어 조치만으로 기능이 생기지 않습니다.

2. 증상별 원인표

확인한 상태우선 해석다음 확인
빠른 설정 타일만 없고 설정에는 켜기 스위치가 있음타일 위치·표시 차이 가능성빠른 설정 스크롤·배치
설정 스위치도 없고 장치 관리자에 어댑터가 보임어댑터 비활성화·드라이버 오류 가능성장치 상태·드라이버
설정 스위치와 장치 관리자 항목 모두 없음미지원 PC, 드라이버·펌웨어·하드웨어 인식 문제 가능성제조사 모델 사양·지원
업데이트 직후부터 스위치가 사라짐새 드라이버와 모델 간 호환성 가능성드라이버 롤백 가능 여부
스위치는 있고 특정 이어폰만 연결 실패어댑터 실종보다 페어링·기기 문제해당 기기 재연결 안내

Wi-Fi가 된다고 Bluetooth 칩까지 정상이라고 단정하지 마세요. 장치 관리자 목록에 없다는 이유만으로 하드웨어 고장을 확정할 수도 없습니다. 제조사의 정확한 모델 사양과 진단 결과를 함께 보아야 합니다.

3. 해결 7단계

1단계: 빠른 설정의 위치와 설정 스위치를 따로 확인

Win+A로 빠른 설정을 열어 타일 목록을 스크롤하고 Bluetooth가 있는지 봅니다. 스크롤형 빠른 설정이 적용된 Windows 11 빌드에서는 예전 안내처럼 항상 연필 아이콘으로 타일을 추가하는 방식이 아닙니다. 이어 설정 → Bluetooth 및 장치에서 상단 스위치를 확인하세요. 설정 스위치가 있다면 어댑터가 사라진 문제로 취급해 드라이버를 삭제하지 마세요. 빠른 설정 배치가 다를 때는 해당 Windows 빌드의 표시 방식에 맞춰 타일을 찾습니다.

2단계: 비행기 모드·도움말 보기 진단

빠른 설정에서 비행기 모드가 꺼져 있는지 확인합니다. 시작 메뉴에서 도움말 보기를 열고 Bluetooth 문제 해결을 검색해 자동 진단을 실행하세요. Microsoft는 Windows 11에서 이 자동 진단을 첫 점검 중 하나로 안내합니다. 회사 PC에서 진단이 정책에 의해 제한되면 관리자에게 화면과 오류 문구를 전달합니다.

3단계: 완전 종료로 어댑터 전원 다시 켜기

열려 있는 작업을 저장하고 Shift를 누른 채 시작 → 전원 → 시스템 종료를 선택합니다. 전원이 완전히 꺼진 뒤 1분 기다렸다 켜세요. Microsoft는 이 문제에서 단순 ‘다시 시작’과 구분해 완전 종료를 안내합니다. 외장 USB Bluetooth 동글이라면 PC를 끈 상태에서 연결 상태도 확인하고, 물리적 손상이 의심되면 억지로 꽂지 마세요.

4단계: 장치 관리자에서 실제 어댑터 상태 확인

시작 버튼을 우클릭해 장치 관리자를 열고 Bluetooth 범주에서 PC의 어댑터 이름을 찾습니다. 아래쪽 화살표로 비활성화되어 있다면 디바이스 사용을 선택하세요. 이름이 아예 없다면 보기 → 숨겨진 장치 표시도 확인하되, 흐리게 보이는 이전 장치만으로 현재 하드웨어가 동작한다고 판단하지 마세요. 제조사 제품 페이지에서 모델이 Bluetooth를 지원하는지 먼저 확인합니다. 일반 데스크톱의 USB 동글은 PC 본체 사양과 별도로 동글 모델도 확인해야 합니다.

5단계: Windows·제조사 드라이버를 모델에 맞게 갱신

어댑터가 보이면 우클릭해 드라이버 업데이트 → 드라이버 자동 검색을 실행하고 재시작합니다. 이어 설정 → Windows 업데이트 → 고급 옵션 → 선택적 업데이트에서 해당 모델의 드라이버·펌웨어가 제공되는지 확인하세요. ‘최적의 드라이버가 이미 설치’되었다고 나와도 제조사 지원 사이트에 더 적합한 모델별 버전이 있을 수 있습니다. PC·동글의 정확한 모델명과 Windows 11용 파일을 맞추고, 제3자 ‘드라이버 자동 수리’ 사이트는 사용하지 마세요.

6단계: 업데이트 직후라면 롤백, 재설치는 준비 후

문제가 드라이버 업데이트 직후 시작됐고 어댑터가 보인다면 장치 관리자 → 어댑터 속성 → 드라이버 → 드라이버 롤백이 활성화됐는지 확인합니다. 롤백이 불가능하거나 실패해도 제조사 공식 설치 파일을 먼저 확보하기 전에는 어댑터를 제거하지 마세요. 다른 입력 수단이 없거나 Bluetooth 마우스·키보드만 쓰는 PC라면 유선 장치를 준비해야 합니다. 마지막으로 디바이스 제거 후 재시작을 검토할 수 있지만, Windows의 자동 재설치가 실패하면 준비한 공식 설치 파일을 사용합니다. 연결 장치는 다시 페어링해야 할 수 있습니다.

7단계: 계속 사라지면 제조사 진단·지원

장치가 계속 감지되지 않거나 같은 오류가 반복되면 PC·동글 제조사의 공식 지원에서 모델별 Bluetooth 진단, 드라이버와 펌웨어 공지를 확인하세요. Microsoft도 Bluetooth 하드웨어 오류가 제조사 드라이버·펌웨어와 관련될 수 있어 모델별 지원을 권합니다. BIOS/UEFI 업데이트는 전원·복구 키·제조사 지침이 필요한 고급 작업이므로 일반적인 ‘버튼 복구’용으로 임의 실행하지 마세요. 구매 기록이 있다면 제조사 수리·보증 경로를 확인합니다.

4. 정상 확인과 실패 시 다음 조치

  • 설정 → Bluetooth 및 장치에 켜기 스위치가 다시 보이고 켜기·끄기가 되는지 확인합니다. 빠른 설정의 타일 위치는 빌드별로 다를 수 있습니다.
  • 본인이 소유한 Bluetooth 기기 한 대를 검색·연결해 봅니다. 스위치는 돌아왔지만 연결만 실패한다면 페어링 문제로 분리하세요.
  • 계속 실패하면 PC 정확한 모델명, Windows 버전·빌드, 장치 관리자에서 어댑터 표시·오류 코드, 문제가 시작된 업데이트 시점을 제조사 또는 Microsoft 지원에 전달합니다. 불필요한 장치 일련번호·계정 정보는 공개 게시판에 올리지 마세요.

5. 데이터·결제·계정·보안 주의

  • 데이터: 일반적인 Bluetooth 드라이버 재설치는 개인 문서 삭제와 다르지만 연결 기기를 다시 페어링하거나 기존 어댑터 설정을 다시 잡아야 할 수 있습니다. 드라이버 제거 전 유선 입력 장치와 공식 설치 파일을 준비하세요.
  • 결제: 버튼 복구를 위해 유료 드라이버 앱을 구매할 필요는 없습니다. 제조사 공식 지원·보증 여부부터 확인하세요.
  • 계정: Microsoft 계정을 새로 만들거나 로그아웃해도 하드웨어 인식 문제의 원인을 확인할 수 없습니다. 조직 PC는 관리자의 드라이버·장치 정책을 따르세요.
  • 보안: 출처 불명 드라이버, 레지스트리 일괄 수정 스크립트, 임의 BIOS 파일을 실행하지 마세요. 펌웨어 업데이트는 제조사 모델별 지침·전원·복구 준비가 된 경우에만 검토합니다.

6. FAQ

빠른 설정에만 Bluetooth 버튼이 없으면 드라이버를 다시 설치해야 하나요?

아닙니다. 설정 앱의 켜기 스위치가 살아 있다면 타일 위치·표시 방식부터 확인하세요. 드라이버 제거는 초기 조치가 아닙니다.

장치 관리자에 Bluetooth 항목이 없으면 하드웨어 고장인가요?

그 표시만으로 확정할 수 없습니다. 해당 PC·동글의 Bluetooth 지원 사양, 완전 종료 후 변화, 제조사 모델별 드라이버·진단을 함께 확인하세요.

드라이버 업데이트 후 버튼이 사라졌다면?

장치 관리자에 어댑터가 보일 때 속성의 드라이버 탭에서 롤백을 확인하세요. 비활성화됐다면 제조사 공식 모델별 드라이버를 사용합니다.

드라이버를 삭제하면 사진이나 문서가 지워지나요?

일반적인 어댑터 드라이버 제거와 개인 파일 삭제는 다릅니다. 다만 재설치에 실패하면 Bluetooth 입력 장치를 쓰지 못할 수 있고 페어링을 다시 해야 할 수 있어 공식 드라이버와 유선 입력 장치를 먼저 준비해야 합니다.
