디스코드 마이크 안 될 때 체크리스트 7단계

디스코드에서 상대에게 내 목소리가 안 들리거나, 스스로도 입력 레벨이 안 움직이면 원인부터 갈립니다. 헤드셋 고장만의 문제가 아니라 윈도우 마이크 권한, 기본 녹음 장치, Discord 음성 설정, 독점 모드, 방화벽까지 겹치는 경우가 많습니다. 7단계 체크리스트로 쉬운 것부터 순서대로 좁혀 갑니다.

1. 문제 정의: “안 됨”이 어떤 증상인가?

증상의미
입력 레벨 막대가 전혀 안 움직임OS·장치·권한 쪽 가능성 큼
내 화면에서는 움직이는데 상대가 못 들음서버 음소거·노이즈 억제·전송 문제
특정 서버/채널만 안 됨서버 Mute / 채널 권한 / 푸시투톡
게임·줌은 되는데 디스코드만 안 됨Discord 권한·단독 설정·관리자 권한 충돌
갑자기 끊김·로봇 소리드라이버·독점 모드·USB 절전

[스크린샷: Discord 음성 설정 — 입력 장치와 입력 감도 막대가 움직이지 않는 상태]

이 글 범위: Windows + Discord 데스크톱 앱 기준. (브라우저 Discord도 비슷하지만 사이트 권한을 추가로 봐야 합니다.)

2. 30초 퀵 체크 (설정 만지기 전에)

  1. 헤드셋/마이크가 꽂혀 있는지 — USB면 다른 포트, 3.5mm면 헤드셋·마이크 단자 구분
  2. Discord 서버/채널 음소거 — 서버 목록 하단 마이크 아이콘, 채널 우클릭 음소거 해제
  3. 푸시투톡 — 키를 안 누르고 말하면 “안 되는 것처럼” 보임 → 잠시 음성 활동으로 바꿔 테스트
  4. Windows 자체 녹음 테스트 — 설정 → 시스템 → 소리 → 입력에서 말해 보기
  5. 최근 변경 — 윈도우 업데이트, 새 헤드셋, VPN·방화벽 앱 설치 여부

Windows 입력 막대가 움직이면 → 3단계(Discord 설정)부터. 안 움직이면 → 1~2단계부터.

3. 체크리스트 7단계

1단계: Windows 마이크 개인정보(권한) 허용

  1. Win+I → 개인 정보 보호 및 보안(Win11) / 개인 정보(Win10)
  2. 마이크 메뉴 진입
  3. 마이크 액세스 = 켜기
  4. 앱이 마이크에 액세스하도록 허용 = 켜기
  5. 목록에서 Discord가 있으면 개별적으로 켜기
  6. Discord를 완전히 종료 후 재실행 (트레이 아이콘 우클릭 → 종료)

[스크린샷: Windows 설정 — 마이크 액세스 / 앱 액세스 허용 화면]

브라우저로 discord.com을 쓰면, 주소창의 사이트 권한에서 마이크 허용도 확인하세요.

2단계: 기본 입력 장치·물리 연결 확인

  1. Windows 설정 → 시스템 → 소리 → 입력
  2. 입력 장치 드롭다운에서 실제 쓰는 마이크/헤드셋을 선택
  3. 말하면서 입력 볼륨 막대가 움직이는지 확인
  4. 장치가 여러 개면(모니터 HDMI, 웹캠 마이크, Realtek 등) 엉뚱한 장치가 기본인지 확인
  5. 상세: mmsys.cpl 실행 → 녹음 탭 → 사용할 장치 우클릭 → 기본 장치로 설정

[스크린샷: mmsys.cpl 녹음 탭 — 기본 장치 설정]

[스크린샷: Windows 소리 설정 입력 볼륨 테스트]

USB 헤드셋 팁: 뽑았다가 다시 꽂고, USB 허브 대신 메인보드 포트에 직접 연결해 보세요.

3단계: Discord 음성·동영상 설정

  1. Discord 좌측 하단 톱니바퀴 → 사용자 설정
  2. 앱 설정 → 음성 및 동영상
  3. 입력 장치를 Windows에서 확인한 그 장치로 수동 지정 («기본값»이 꼬인 경우가 많음)
  4. 입력 감도 — 자동이 과하면 끄고 슬라이더를 조정해 테스트
  5. 마이크 테스트 켜고 입력 막대 확인
  6. 노이즈 억제 / 에코 제거 / 자동 이득을 잠시 모두 끄고 재테스트
  7. 푸시투톡이면 단축키가 다른 앱과 겹치지 않는지 확인

[스크린샷: Discord 음성 및 동영상 — 입력 장치·감도·마이크 테스트]

서버 하단 마이크/헤드셋 음소거 해제, 채널 말하기 권한도 한 번 더 확인하세요.

4단계: 독점 모드(Exclusive Mode) 끄기

  1. mmsys.cpl → 녹음 탭
  2. 사용 중 마이크 → 속성 → 고급 탭
  3. «응용 프로그램이 이 장치를 독점적으로 제어하도록 허용» 체크 해제
  4. «독점 모드인 응용 프로그램의 우선 순위 지정»도 해제
  5. 확인 후 Discord 재시작

[스크린샷: 마이크 속성 고급 — 독점 모드 체크 해제]

5단계: Discord를 관리자 권한으로 / 권한 충돌 정리

  1. Discord 트레이 종료 후, 바로가기 우클릭 → 관리자 권한으로 실행 → 마이크 테스트
  2. 반대로, 항상 관리자로 켜고 있었다면 관리자 없이 실행해 보기
  3. 게임도 관리자, Discord도 비관리자면 권한 레벨이 달라 입력이 이상해질 수 있음 → 둘 다 같게 (가능하면 둘 다 일반 권한)

[스크린샷: Discord 바로가기 — 관리자 권한으로 실행]

6단계: Discord 음성 서비스 초기화·재설치에 가까운 조치

6-A. 빠른 조치 — 음성 채널 나가기→재입장, Discord 완전 종료 후 재실행, 필요 시 services.msc에서 Windows Audio가 실행 중인지 확인.

6-B. 음성 파이프라인 리셋 — 사용자 설정 → 음성 및 동영상에서 음성 처리 초기화류 옵션 사용, 하드웨어 가속 끄기 후 재시작.

6-C. 앱 재설치 — Discord 완전 종료 → 설정 → 앱에서 제거 → 공식 사이트에서 재설치 → 입력 장치·감도 다시 수동 지정.

[스크린샷: Discord 제거 후 재설치 — 설정 앱 목록]

%appdata%\discord 폴더를 지우는 초기화는 효과적이지만 로컬 설정이 날아갑니다. 필요 시 폴더를 통째로 백업한 뒤 삭제하세요. 비밀번호·토큰을 외부에 공유하지 마세요.

7단계: 방화벽·보안 소프트웨어·VPN

  1. Windows 보안 → 방화벽 → 앱 허용에서 Discord(개인·공용) 허용
  2. 백신·방화벽 제품이 Discord를 차단하지 않는지 확인
  3. VPN·학교/회사 네트워크면 음성 UDP가 막힐 수 있음 → VPN 끄고 테스트
  4. 서버 음성 지역이 이상하면 핑이 높아 끊김으로 “안 들림”처럼 느껴질 수 있음

[스크린샷: Windows 방화벽 — Discord 앱 허용]

4. 그래도 안 될 때

증상추가 점검
OS 입력 막대부터 안 움직임다른 마이크 테스트, 장치 관리자에서 드라이버 업데이트/제거 후 재부팅
특정 USB 포트만 실패포트·허브 문제 — 메인 포트로 이동
크랙ling·로봇 목소리샘플 속도 통일, 블루투스면 USB/유선으로 비교
게임 중만 안 됨게임 내 보이스와 Discord 장치 충돌, 관리자 권한 불일치
노트북 내장 마이크만 됨헤드셋이 기본 장치가 아님 — 2단계 재확인

[스크린샷: 장치 관리자 — 오디오 입력 및 출력 장치 목록]

블루투스 헤드셋의 Hands-Free 프로필은 음질·마이크가 제한적인 경우가 많습니다. 가능하면 USB 동글·유선으로 분리 테스트하세요.

5. FAQ

Q. 제일 먼저 뭘까요?

Windows 소리 입력 막대가 움직이는지부터 보세요. 여기서 안 되면 Discord 설정은 의미가 없습니다.

Q. 입력은 움직이는데 상대만 못 들어요.

서버/자신 음소거, 푸시투톡, 노이즈 억제 과다, 방화벽·VPN 순으로 보세요.

Q. “Discord needs access to your microphone” 문구가 뜹니다.

1단계 마이크 개인정보 허용 후 앱을 완전히 종료했다가 다시 켜세요.

Q. 오버레이를 끄면 나아지나요?

가끔 있습니다. 게임 오버레이·하드웨어 가속을 끄고 재테스트해 볼 가치는 있습니다.

Q. 모바일 디스코드는요?

폰 설정 → 앱 → Discord → 마이크 권한을 확인하세요. 이 글은 PC(Windows) 중심입니다.

한 줄 요약

OS 마이크 권한 → 기본 입력 장치 → Discord 입력 장치·감도 → 독점 모드 해제 → 관리자 권한 맞추기 → 음성 초기화/재설치 → 방화벽·VPN.
이 순서대로 가면 대부분의 디스코드 마이크 안됨은 원인 구간이 드러납니다.
