1. 건강보험 자격과 임신 확인부터

지원 대상은 임신·출산이 확인된 건강보험 가입자 또는 피부양자입니다. 유산·사산도 포함되며, 출산한 가입자·피부양자가 사망한 경우 2세 미만 영유아의 법정대리인이 신청하는 별도 경우도 있습니다. 의료급여 대상자나 건강보험 자격 상태가 달라진 사람은 본인에게 적용되는 제도를 공단에 확인하세요.

보건복지부는 일태아 임신 1회당 100만원, 다태아는 기본 140만원과 별도 추가지원 구조를 안내합니다. 다태아 추가지원은 임신주수·출산 시점·신청 시 상태 등의 조건이 있으며, 분만취약지 추가지원도 따로 있습니다. ‘다태아는 무조건 140만원으로 끝’이라고 보거나 최대금액이 모두에게 지급된다고 가정하지 마세요. 적용 금액과 추가 신청 필요 여부는 공단 확인이 필요합니다.

2. 신청서와 카드 상태를 나눠 준비

  • 의료기관 확인: 요양기관에서 건강보험 임신·출산 진료비 지급 신청서와 임신 확인에 필요한 내용을 준비합니다.
  • 신청 정보: 신청인 정보·서명 등 본인이 작성할 부분을 확인합니다. 가족이 신청한다면 관계 증빙 등 추가서류와 신청 가능 사유를 먼저 문의하세요.
  • 국민행복카드: 이미 보유한 카드가 있다면 새 카드를 무조건 만들기 전에 기존 카드 이용 가능 여부와 해당 바우처 등록 상태를 확인합니다.

양산시도 의료기관에서 신청·임신확인서를 받아 공단 지사 또는 카드 영업점에 신청하는 경로를 안내합니다. 방문 전 해당 지사·금융사가 업무를 취급하는지, 본인확인 자료와 추가 원본이 필요한지 확인하면 재방문을 줄일 수 있습니다.

3. 공단·금융사 또는 공식 온라인 경로로 신청

  1. 접수 경로 선택: 공단 지사 또는 국민행복카드 발급 금융사의 취급 창구를 확인합니다. 방문은 준비한 지급 신청서를 바탕으로 진행합니다.
  2. 온라인이라면: 국민건강보험공단 홈페이지에서 ‘임신출산 진료비 온라인 신청’을 찾습니다. 보건복지부는 정부24의 ‘맘편한 임신’ 온라인 통합처리신청도 안내합니다.
  3. 확인·제출: 신청 화면의 임신 확인 정보, 신청인 작성란과 첨부·동의 조건을 읽고 제출합니다. 정보가 확인되지 않으면 의료기관과 접수기관에 보완 방법을 문의하세요.
  4. 지원 등록 점검: 접수 사실과 지원 결정·포인트 생성을 확인합니다. 카드 발급 진행상태와 바우처 등록 진행상태를 구분해 확인하세요.

찾기쉬운 생활법령정보도 공단·금융기관·체신관서 제출과 공단 홈페이지 신청을 설명합니다. 금융사별 카드 상품 혜택과 국가 바우처 대상 확인은 별개이므로, 상품 광고만 보고 지원 등록이 끝났다고 생각하지 마세요.

4. 포인트 생성일과 사용종료일 확인

보건복지부 안내상 사용은 이용권 발급일부터 시작하며, 기존 국민행복카드 보유자는 추가 카드 발급 없이 신청일의 포인트 생성 후 이용할 수 있습니다. 종료일은 분만예정일 또는 출산일(유산·사산일)로부터 2년으로 안내됩니다. 개인별로 실제 등록된 종료일을 확인하고 ‘오늘 신청했으니 오늘부터 2년’으로 임의 계산하지 마세요.

사용 범위는 임산부의 진료와 약제·치료재료 구입 본인부담금, 2세 미만 영유아의 진료 및 처방된 약제·치료재료 구입 본인부담금입니다. 일반 생활용품 구매용 지원금으로 혼동하지 말고, 결제할 때 해당 비용의 바우처 사용 가능 여부를 요양기관에 확인하세요.

결제 실패 시 재신청부터 반복하지 말고 접수 정보와 카드사 안내를 확인하세요. 바우처 자격·등록 문제는 국민건강보험공단, 카드 이용 문제는 해당 금융사에 문의하는 방식으로 원인을 구분하면 좋습니다. 개인별 승인이나 지급액·결제 성공은 보장할 수 없습니다.
