현금영수증 휴대폰번호 등록·변경: 본인 인증·다음날 조회

2026-11-16 확인현금영수증 발급수단
대상·준비등록·변경조회 시점누락·예외

가게에서 휴대전화번호로 현금영수증을 받았는데 홈택스에 내역이 보이지 않는다면, 그 번호가 현금영수증 발급수단으로 등록돼 있는지부터 확인하세요. 전화번호를 바꿨을 때도 회원 연락처와 현금영수증 발급수단을 구분해 점검하는 것이 좋습니다.

확인일: 2026년 11월 16일. 손택스 공식 소비자 발급수단 관리 안내와 「홈택스 이용에 관한 규정」(2026-02-18 시행) 제42~45조를 대조했습니다. 본인 휴대전화번호로 현금영수증을 받는 소비자의 등록·변경·조회가 대상입니다. 사업자의 영수증 발행, 잘못 발급된 거래 정정, 소득공제 요건 판단은 별도입니다. 개인 인증·번호 입력·등록 제출은 하지 않았습니다.

광고

1. 어떤 번호를 등록하는지 확인

발급수단은 영수증을 받을 때 가게에 제시한 휴대전화번호나 카드번호 등입니다. 규정 제42조는 해당 번호로 발급된 내역을 조회하려면 발급수단 정보를 등록하도록 하고, 분실·번호 변경 시에는 삭제 또는 정정하도록 정합니다. 회원정보의 연락처만 바꾼 뒤 끝내지 말고 현금영수증 메뉴의 등록번호를 직접 확인하세요.

손택스 안내상 본인 명의 휴대전화번호만 등록할 수 있고 통신사 본인인증을 완료해야 합니다. 실제 사용하는 전화라고 해도 가족 등 다른 사람 명의라면 같은 방법으로 등록될 것이라고 가정하지 마세요. 본인 명의 여부가 맞지 않거나 인증이 어려우면 현금영수증 카드 등 다른 발급수단 이용을 검토하고 국세상담센터에 문의합니다.

2. 홈택스·손택스에서 등록 또는 변경

공식 서비스 · 광고 아님

국세청 홈택스 접속
  1. 본인 계정으로 접속해 현금영수증 관련 메뉴를 찾습니다. PC에서는 ‘현금영수증 발급용 휴대전화번호/카드관리’, 손택스에서는 ‘소비자 발급수단 관리’라는 메뉴명을 검색하세요. 화면 개편에 따라 상위 메뉴 위치는 달라질 수 있습니다.
  2. 현재 등록된 휴대전화번호를 확인합니다. 등록되지 않았다면 등록, 번호가 바뀌었다면 변경 기능을 선택합니다.
  3. 실제로 영수증 발급에 사용할 본인 명의 번호를 입력하고, 화면에서 요구하는 통신사 본인인증과 확인 절차를 진행합니다.
  4. 처리 결과를 확인한 뒤 같은 관리 화면에서 번호가 원하는 값으로 저장됐는지 다시 확인합니다. 인증창만 닫았거나 오류가 났다면 저장 완료로 판단하지 않습니다.

조회 과정에서 표시되는 번호와 실제 영수증에 사용한 번호를 비교해 보세요. 번호 등록은 가게가 영수증을 발행하는 행위와 다르므로, 구매할 때는 현금영수증 발급을 요청하고 거래 증빙도 보관합니다.

3. 변경 직후 안 보여도 조회 시점을 구분

손택스 소비자 발급수단 안내는 번호를 변경한 경우 다음날부터 사용내역 조회가 가능하다고 설명합니다. 변경 직후 조회되지 않는다는 이유만으로 같은 등록을 여러 번 반복하지 말고 저장 상태와 조회일을 먼저 확인하세요.

또한 규정 제45조는 당일 발급된 영수증은 다음날 오전 8시 이후부터 조회할 수 있도록 정하되 처리 건수에 따라 시각이 달라질 수 있다고 명시합니다. 번호 변경 처리 시점과 가게의 영수증 발급일을 각각 적어 두면 원인을 구분하기 쉽습니다. 반드시 특정 시각에 모든 거래가 나온다는 보장은 아닙니다.

다음날 조회할 때는 거래일·상호·금액 등 보유한 영수증과 사용내역을 대조합니다. 조회 기간이 거래일을 포함하는지도 확인하세요. 규정 제44조는 매일 03~06시 발급내역 구축 중 일시 중단 가능성과 긴급 장애 가능성을 안내하므로, 조회가 아예 열리지 않으면 현재 공지와 이용시간도 확인합니다.

광고

4. 계속 누락될 때와 별도 절차인 경우

  • 다른 번호로 발급: 내 번호를 등록하는 것만으로 타인 번호의 거래를 자동으로 가져올 수 있다고 보지 마세요. 영수증의 발급수단과 거래 사실을 확인해 가맹점 또는 국세상담센터에 정정 방법을 문의합니다.
  • 영수증 자체가 없음: 번호 등록과 영수증 발급은 별개입니다. 가맹점이 발급했는지부터 확인합니다. 발급 거부·미발급 신고와 소비자 발급수단 등록도 서로 다른 절차입니다.
  • 오래된 거래·번호 변경 전 내역: 모든 과거 거래가 언제나 자동 반영된다고 단정하지 않습니다. 실제 발급번호·거래일과 등록 상태를 정리해 귀속·조회 가능 여부를 문의합니다.
  • 모바일카드 사용: 현행 제42조 제2항은 현금영수증 모바일카드 번호 등을 발급수단 번호 등록의 예외로 둡니다. 모바일카드로 받은 내역을 휴대전화번호 미등록 문제와 동일하게 판단하지 마세요.

조회돼도 연말정산에서 같은 금액이 모두 공제되는 것은 아닙니다. 공제 대상·제외 거래·한도 등은 별도 요건으로 확인해야 합니다. 이 글은 환급금이나 소득공제 승인을 보장하지 않습니다.

해결되지 않으면 오류 문구, 등록·변경일, 영수증 발급일과 거래내역을 정리해 국세상담센터 126에 문의하세요. 공식 인증 화면 외에 인증번호나 전체 개인정보를 공개 게시판에 올리지 않도록 주의합니다.
