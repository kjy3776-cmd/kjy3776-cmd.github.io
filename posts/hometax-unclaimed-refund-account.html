홈택스 미수령 국세환급금 조회·환급계좌 신고 방법

2026-09-30 확인·대한민국 국세청 홈택스 PC·손택스 모바일 웹 기준 / 메뉴 변경 가능홈택스국세환급금
1분 요약메뉴 구분조회·신고

“환급금이 있다”는 안내를 받았는데 어디에서 확인하고 어떤 계좌로 받는지 헷갈린다면, 조회와 지급 신청을 분리해서 보세요. 국세청 홈택스의 국세 환급금찾기는 찾아가지 않은 국세환급금의 존재 여부를 확인하는 화면이고, 실제 지급 상태·지급요청은 환급금 상세조회, 계좌 등록은 환급계좌개설(변경)신고에서 다룹니다.

확인일: 2026년 9월 30일. 대한민국 국세청 홈택스 PC 메뉴와 손택스 모바일 웹 공식 화면 기준입니다. 이 글은 미수령 국세환급금에 관한 일반 안내입니다. 연말정산 예상 환급액, 종합소득세 신고서의 환급세액, 근로·자녀장려금 지급 계좌는 같은 조회·신고 절차로 단정할 수 없습니다. 세목·지급 결정 상태와 화면 안내를 먼저 확인하세요.

1. 1분 확인 순서

  1. 주소창에 hometax.go.kr을 직접 입력하고, 납부·고지·환급 → 환급 → 국세 환급금찾기로 이동합니다.
  2. 안내에 맞춰 본인 정보를 입력해 미수령 국세환급금이 있는지 확인합니다. 없다면 이 화면에서 지급 신청할 금액도 확인되지 않은 것입니다.
  3. 금액이 보이면 로그인 후 환급금 상세조회에서 지급구분·지급일·필요한 조치를 확인합니다.
  4. 계좌 수령이 필요한 경우에만 환급계좌개설 신고/변경 신고에서 본인 명의의 수령 가능 계좌를 확인·신고합니다.

혼동 주의: ‘국세 환급금찾기’의 조회 결과만으로 지급이 완료되지는 않습니다. 계좌를 신고해도 이미 지급 결정된 건에 소급 적용된다고 단정할 수 없습니다.

2. 증상별로 어느 메뉴를 써야 할까?

표는 좌우로 스크롤해 전체 내용을 볼 수 있습니다.

3. 조회부터 환급계좌 신고까지

1단계: 공식 사이트에서 미수령 여부 조회

홈택스의 납부·고지·환급 → 환급 → 국세 환급금찾기를 엽니다. 손택스 공식 화면에서는 내·외국인 구분, 주민등록번호 또는 사업자등록번호, 성명 또는 상호 입력란을 안내합니다. 주민등록번호를 입력하는 단계이므로 검색광고·문자메시지의 링크가 아니라 직접 입력한 공식 주소에서만 진행하세요. 국세청은 이 화면에서 최근 5년간 찾아가지 않은 환급금을 안내합니다.

조회 시작 · 국세청홈택스 공식 사이트 바로가기

2단계: 상세조회에서 지급 상태 확인

조회 결과가 있다면 로그인해 환급금 상세조회에서 해당 세목, 환급금액, 지급구분, 지급일과 계좌 표시를 살펴보세요. 국세청 공식 상세조회 화면은 1년이 지난 미수령환급금은 ‘지급요청’ 후 세무서 재결정이 필요하다고 안내합니다. 따라서 단순 계좌 등록만 하고 끝내지 말고 해당 건의 화면에 지급요청 안내가 있는지 확인하세요. 오래된 건이 조회되지 않거나 상태가 모호하면 관할 세무서에 문의합니다.

3단계: 필요한 경우에만 계좌 신고·변경

납부·고지·환급 → 국세환급 → 환급계좌 개설(변경)신고에서 등록된 계좌 상태를 확인합니다. 계좌를 새로 신고하거나 바꿀 때는 세목, 은행, 본인 명의 계좌번호를 화면 안내에 맞춰 입력합니다. 국세청은 신고서에 기재한 계좌가 별도 환급계좌 신고보다 우선 적용될 수 있고, 개별 세목 계좌와 모든 세목 계좌 사이에도 우선순위가 있다고 안내합니다. 따라서 신고서에 이미 적은 계좌가 있다면 그 계좌를 먼저 확인하세요.

공식 설명 · 국세청 손택스환급계좌 신고 안내 확인하기

4단계: 수령 경로와 처리 여부 확인

계좌 신고 화면의 접수 결과를 확인한 뒤, 해당 환급 건의 환급금 상세조회에서 지급 상태를 다시 봅니다. 국세청은 계좌 신고 후 해당 계좌로 지급 가능해지기까지 시간이 필요하다고 안내하며, 이미 계좌로 지급 결정이 끝난 건은 현금 지급으로 다시 바꿀 수 없다고 설명합니다. 우편 통지서·우체국 수령 안내가 뜨는 건은 화면 지시에 따라 세무서와 우체국 절차를 확인하세요. 여기서 구체적인 지급일이나 수령액을 보장할 수는 없습니다.

4. 정상 확인법과 안 될 때의 다음 조치

  • 조회 결과 없음: 이 화면에 표시되는 미수령 국세환급금이 없다는 뜻입니다. 모든 세금 환급 가능성이 없다는 의미는 아닙니다. 연말정산·종합소득세·장려금이라면 해당 전용 화면을 확인하세요.
  • 결과는 있는데 입금되지 않음: 상세조회에서 지급구분·지급일·계좌를 확인하세요. 1년 경과 미수령 건이라면 화면의 지급요청 필요 여부를 먼저 확인합니다.
  • 계좌 신고가 안 됨: 은행·계좌번호와 계좌 유형을 다시 확인하세요. 국세청은 신탁계좌, 가상계좌, 일부 저축은행 계좌로 지급할 수 없다고 안내하므로 금융기관에 수령 가능 여부를 문의하세요.
  • 이미 신고한 계좌와 다름: 신고서에 기재한 계좌가 우선 적용될 수 있습니다. 해당 신고서와 상세조회 내역을 확인하고, 변경이 어려우면 관할 세무서에 문의하세요.

5. 계좌·개인정보 주의사항

조회에 쓰는 주민등록번호, 은행 계좌번호, 인증 정보는 국세청 공식 사이트에만 입력하세요. ‘환급금 수령 수수료’를 요구하거나 원격제어 앱 설치를 시키는 문자·메신저 링크를 따르지 마세요. 계좌를 잘못 신고했거나 지급 내역이 맞지 않으면 홈택스의 해당 내역과 관할 세무서 안내를 통해 정정·문의하세요. 국세청 화면의 계좌 우선순위와 지급 결정 상태에 따라 실제 수령 경로가 다를 수 있으므로, 단순히 계좌 신고가 접수됐다는 사실만으로 입금을 기대하지 마세요.

6. 자주 묻는 질문

Q. 국세 환급금찾기에서 ‘없음’이면 연말정산 환급도 없나요?

아닙니다. 국세청은 연말정산 관련 환급을 별도의 지급명세서 조회 경로에서 확인하도록 안내합니다. 이 화면의 ‘없음’은 안내 대상인 미수령 국세환급금 조회 결과로 이해하세요.

Q. 환급계좌만 등록하면 오래된 미수령 금액이 바로 입금되나요?

그렇지 않습니다. 국세청 상세조회 안내에 따르면 1년이 경과한 미수령환급금은 지급요청과 세무서 재결정이 필요할 수 있습니다. 해당 건의 상세조회 안내와 세무서 확인이 우선입니다.

Q. 근로장려금 받을 계좌도 여기서 바꾸나요?

일반 국세환급계좌 신고와 구분해야 합니다. 국세청은 장려금 계좌 변경을 장려금 신청의 별도 계좌개설(변경·철회)신고서에서 처리하도록 안내합니다.

Q. 계좌가 맞는데도 처리되지 않아요.

상세조회의 지급구분·지급일, 신고서에 기재한 계좌, 계좌 수령 가능 여부를 차례로 확인하세요. 개인정보를 공개 게시판에 적지 말고 관할 세무서에 환급 건별로 문의하세요.
