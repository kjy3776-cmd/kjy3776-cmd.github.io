사업자상태 조회: 홈택스 사업자번호로 휴업·폐업 확인

2026-11-14 확인사업자상태
조회 대상번호 확인조회 순서결과·예외

거래할 업체가 현재 계속사업자인지 확인하려면 홈택스의 사업자상태 조회(사업자등록번호)를 이용합니다. 사업자번호로 과세유형과 계속·휴업·폐업 상태를 확인하는 서비스입니다. 조회 결과는 거래 판단을 돕는 최소한의 정보이며 법적 증빙자료나 거래 안전 보증은 아닙니다.

확인일: 2026년 11월 14일. 국세청 홈택스의 실제 공개 조회 화면, 서울시 사업자등록상태 안내, 국세청 공공데이터 안내를 대조했습니다. 사업자등록번호를 알고 있는 일반 이용자 대상 안내입니다. 공개 화면까지 로그인 없이 확인했으며 실제 사업자번호 입력이나 조회는 하지 않았습니다. 개인의 사업자등록 이력 증명, 인허가 조회, API 개발 절차는 별도 업무입니다.

광고

1. 조회할 수 있는 내용과 한계

홈택스 이용안내는 사업자번호로 조회하면 과세유형과 사업자 상태를 보여준다고 설명합니다. 서울시도 중개사무소의 일반·간이 등 과세유형과 계속·휴업·폐업 상태를 확인할 때 이 서비스를 안내합니다.

반면 업체명만으로 사업자번호를 찾아주는 검색이나 개인의 전체 등록 이력을 증명하는 서비스는 아닙니다. 납세 사실·채무·환불 능력·업종별 허가도 이 화면 하나로 판단하지 마세요. ‘계속’이라는 결과가 계약의 안전성을 인증하는 것은 아닙니다.

2. 사업자등록번호를 먼저 확인

조회하려는 거래처가 제공한 사업자등록번호를 준비하고, 계약서나 사업자등록 관련 자료에 적힌 번호와 대조합니다. 서울시는 공인중개사 사무소 조회 시 중개업소 등록번호가 아닌 사업자번호를 입력해야 한다고 명시합니다. 두 번호를 혼동하지 마세요.

상호·주소가 비슷해도 사업장이 다를 수 있으므로 어느 업체의 번호인지 먼저 확인합니다. 번호를 받지 못했다면 임의로 추측하지 말고 상대 업체에 문의하세요. 타인의 주민등록번호를 받아 다른 조회 메뉴에 넣을 필요는 없습니다.

3. 홈택스에서 조회하는 순서

공식 조회 경로 · 광고 아님국세청 홈택스에서 사업자상태 조회 찾기
  1. 공식 홈택스에 접속해 검색창에 ‘사업자상태’를 검색합니다.
  2. 사업자상태 조회(사업자등록번호)를 선택합니다. 주민등록번호 조회나 민원처리상태 조회와 구분합니다.
  3. ‘사업자등록상태조회’ 화면의 안내를 읽고 사업자등록번호를 입력합니다.
  4. ‘조회’를 누른 후 사업자등록번호·사업자등록상태·조회기준일자를 함께 확인합니다.

확인 당시 화면의 상위 경로는 ‘증명ㆍ등록ㆍ신청ㆍ사업장현황 → 사업자등록 신청·정정·휴폐업’으로 표시됐습니다. 메뉴 위치는 개편될 수 있으므로 업무명으로 찾는 방법도 함께 이용하세요. 화면까지 비로그인 접근이 가능했지만, 실제 서비스 운영 상황이나 추가 안내는 이용 시점에 확인해야 합니다.

4. 조회 결과가 예상과 다를 때

계속·휴업·폐업으로 표시된 경우

홈택스는 계속사업자의 예로 일반과세자 안내를, 폐업사업자의 예로 과세유형과 폐업일자가 포함된 안내를 제시합니다. 결과의 전체 문구와 기준일을 확인하세요. 휴업·폐업 표시가 있다면 예전 사업자등록증만 보고 현재 영업 상태를 단정하지 말고 거래처에 설명을 요청합니다.

등록되지 않은 번호라고 나오는 경우

홈택스는 국세청에 등록되지 않은 번호에 해당 안내를 표시한다고 설명합니다. 입력 번호를 다시 대조하고, 사업자등록 변경사항이 아직 처리 중인지 거래처에 확인하세요. 신규등록·휴업·폐업 등 변경은 세무서 처리 완료 후에만 반영된다는 것이 공식 화면의 조건입니다. 조회가 안 된다는 이유만으로 즉시 사기 또는 미등록 영업이라고 단정하지 않습니다.

사업자단위과세로 전환된 폐업자로 표시된 경우

홈택스는 사업자단위과세자가 하나의 번호로 관리되며, 종된 사업장의 기존 번호는 폐업 처리된다고 안내합니다. 이때는 실제 영업 종료 여부를 거래처에 확인해야 합니다. 일반적인 폐업과 같은 의미로 해석하지 말고 현재 사용 번호와 전환 사실을 확인하세요.

외부 조회 서비스와 결과가 다른 경우

공공데이터포털의 국세청 상태조회 API 안내에는 등록 정보와 30분 주기로 갱신되며 신규 개업은 1~2일이 소요될 수 있다고 적혀 있습니다. 이는 API 제공 안내이므로 모든 홈택스 조회에 동일한 대기시간을 보장하는 뜻은 아닙니다. 외부 서비스의 갱신 시각과 공식 화면의 기준일을 구분하세요.

5. 제출용 서류가 필요하면 별도 발급

홈택스는 이 조회 결과에 증빙자료로서 법적인 효력이 없다고 명시합니다. 제출기관이 증명서를 요구한다면 조회 화면 캡처로 임의 대체하지 마세요.

  • 현재 등록 사항 증명: 사업자등록증명 발급
  • 개인의 사업자등록 사실 여부: 사업자등록사실여부 사실증명
  • 휴업 사실 제출: 휴업사실증명 발급
  • 폐업 사실 제출: 폐업사실증명 발급

상태 조회는 신고를 접수하거나 등록 내용을 바꾸는 기능도 아닙니다. 본인 사업장의 기록이 실제와 다르면 접수한 신고의 처리 여부를 먼저 확인하고 담당 세무서에 문의하세요.

공식 확인 자료

  • 국세청 홈택스 — 사업자상태 검색 후 사업자등록번호 조회 화면의 처리 반영 조건·법적 효력·사업자단위과세 예외 확인
  • 서울시 사업자등록상태 안내 — 홈택스 경로와 과세유형·상태, 중개업소 등록번호 구분
  • 공공데이터포털 국세청 사업자등록정보 진위확인 및 상태조회 — 상태조회와 진위확인 구분·API 정보 갱신 안내
