Windows 11 ‘미리 보기하려는 파일이 컴퓨터에 해를 끼칠 수 있습니다’ 해결 7단계

Windows 11 파일 탐색기 미리 보기 창에 “미리 보기하려는 파일이 컴퓨터에 해를 끼칠 수 있습니다. 파일을 신뢰하고 받은 원본을 신뢰하는 경우 파일을 열어 내용을 봅니다.”가 표시된다면 PDF 뷰어 고장부터 의심할 문제가 아닙니다. Microsoft는 2025년 10월 14일 이후 보안 업데이트부터 인터넷에서 받은 파일에 붙는 Mark of the Web(MotW)을 확인해 미리 보기를 기본 차단합니다. 미리 보기만으로 NTLM 자격 증명 해시가 노출될 수 있는 위험을 줄이기 위한 변경입니다. 아래 순서는 2026년 9월 22일 Microsoft 공식 문서를 교차 확인해, 보안 기능을 끄지 않고 신뢰할 수 있는 파일만 안전하게 처리하도록 정리했습니다.

1. 1분 해결 요약

  1. 경고가 파일 탐색기의 보기 → 표시 → 미리 보기 창에서 나타나는지 확인합니다.
  2. 파일의 보낸 사람·다운로드 주소·확장자를 확인하고 Microsoft Defender로 검사합니다.
  3. 안전하다고 확인한 파일 하나만 우클릭해 속성 → 일반 → 차단 해제 → 적용합니다.
  4. 파일 탐색기를 다시 열어 확인하고, 바로 반영되지 않으면 Windows에서 로그아웃했다가 다시 로그인합니다.
  5. 회사·학교 공유 폴더의 모든 파일이 막히면 개인이 보안 영역을 바꾸지 말고 IT 관리자에게 문의합니다.

SmartScreen, Microsoft Defender, 첨부 파일 관리자 또는 인터넷 보안 영역 전체를 끄는 방법은 이 경고를 없애더라도 공격 파일까지 신뢰하게 만들 수 있으므로 사용하지 마세요.

3. 쉬운 방법부터 해결하는 7단계

1단계: 정확한 화면과 Windows 버전 확인

Windows+E로 파일 탐색기를 열고 보기 → 표시 → 미리 보기 창을 켭니다. 파일을 한 번 선택했을 때 오른쪽 창에 위 경고가 나타나는지 확인하세요. Windows+R → winver에서 Windows 11 버전과 OS 빌드도 기록합니다. 미리 보기 창 자체가 없거나 파일을 두 번 눌러 열 때만 오류가 난다면 이 글과 원인이 다릅니다.

2단계: 원본·확장자·서명을 먼저 확인

보낸 사람이 예상한 사람인지, 공식 사이트에서 직접 내려받았는지, 파일 이름의 마지막 확장자가 예상한 형식인지 확인합니다. 파일 탐색기에서 보기 → 표시 → 파일 이름 확장명을 켜면 견적서.pdf.exe처럼 확장자를 숨긴 파일을 구분할 수 있습니다. 출처가 불명확하거나 갑자기 도착한 첨부 파일은 차단 해제하지 말고 원본 제공자에게 다시 확인하세요.

3단계: Microsoft Defender로 해당 파일 검사

파일을 우클릭해 더 많은 옵션 표시 → Microsoft Defender로 검사를 선택합니다. 메뉴가 없다면 Windows 보안 → 바이러스 및 위협 방지 → 검사 옵션 → 사용자 지정 검사에서 해당 위치를 검사하세요. 탐지 항목은 보호 기록에서 확인하고, 안전하다는 근거 없이 디바이스에서 허용을 누르지 않습니다. 검사 결과가 깨끗해도 출처 확인을 대신하지는 않습니다.

4단계: 신뢰하는 파일 하나만 차단 해제

검사를 마친 파일을 우클릭해 속성을 열고 일반 탭 아래의 보안 문구 옆 차단 해제에 체크한 다음 적용 → 확인을 누릅니다. Microsoft 설명대로 이 작업은 인터넷 출처 표식을 그 파일에서 제거합니다. 파일 탐색기를 닫았다가 다시 열어 미리 보기를 확인하고, 변화가 없으면 작업을 저장한 뒤 로그아웃·로그인합니다.

5단계: 검토한 여러 파일은 PowerShell에서 대상부터 미리 확인

같은 공식 사이트에서 받은 PDF 여러 개처럼 출처와 형식을 모두 검토한 경우에만 PowerShell을 사용하세요. 먼저 폴더를 별도로 만들고 대상 파일만 넣은 뒤, 그 폴더에서 터미널을 열어 아래 첫 명령으로 변경 대상을 확인합니다. 목록이 정확할 때만 두 번째 명령을 실행합니다.

Get-ChildItem -LiteralPath . -Filter *.pdf -File | Unblock-File -WhatIf
Get-ChildItem -LiteralPath . -Filter *.pdf -File | Unblock-File

-Recurse나 다운로드 폴더 전체 와일드카드는 예상하지 못한 첨부 파일까지 해제할 수 있어 사용하지 않습니다. Microsoft의 Unblock-File은 파일 속성의 ‘차단 해제’와 같은 방식으로 Zone.Identifier 정보를 제거합니다.

6단계: 네트워크 공유라면 최신 업데이트와 위치 분류 확인

설정 → Windows Update → 업데이트 확인에서 지원 중인 버전의 최신 누적 업데이트를 설치하고 재시작합니다. Microsoft는 2026년 7월 업데이트에서 연결이 끊겼다가 다시 연결된 DFS 드라이브의 파일을 인터넷 출처로 잘못 표시하던 문제를 수정했습니다. 회사·학교 공유 폴더라면 주소, 발생 시각, winver 결과를 IT 관리자에게 전달하세요. Microsoft가 안내하는 로컬 인트라넷·신뢰할 수 있는 사이트 등록은 해당 공유의 모든 파일에 대한 보안을 낮추므로 관리자가 주소와 정책을 검증한 경우에만 적용해야 합니다.

7단계: 경고가 사라진 뒤 남은 앱 문제만 분리

차단을 해제한 신뢰 파일과 직접 만든 로컬 파일을 각각 선택해 비교합니다. 둘 다 경고 없이 미리 보기가 비어 있다면 파일 탐색기를 재시작하고 PDF·Office 앱을 최신 상태로 업데이트하세요. PDF 하나만 실패하면 브라우저에서 열어 파일 손상 여부를 확인하고 원본을 다시 받습니다. 레지스트리의 SaveZoneInformation 변경, 그룹 정책으로 출처 정보 저장 중지, SmartScreen·Defender 상시 해제는 하지 않습니다.

4. 정상 확인과 실패 시 다음 조치

  • 차단 해제한 신뢰 파일만 미리 보기 창에 내용이 표시되는지 확인합니다.
  • 새로 내려받은 다른 파일에는 여전히 보안 표식과 경고가 적용되는지 확인합니다.
  • Windows 보안 → 보호 기록에 조치가 필요한 탐지 항목이 없는지 봅니다.
  • 공유 드라이브 문제라면 로컬 파일은 정상이고 공유 파일만 실패하는지 기록합니다.

개별 파일에 차단 해제가 없고 로컬 파일은 정상인데 공유 폴더만 계속 실패하면, 공유의 UNC 주소, Windows 버전·빌드, 최근 설치된 KB, 오류 화면을 IT 관리자에게 전달하세요. 경고가 사라졌는데 특정 형식만 비어 있으면 해당 앱의 미리 보기 처리기 문제로 분리해 앱 제조사 지원을 이용합니다.

5. 데이터·계정·보안 주의

  • 차단 해제는 바이러스를 치료하는 기능이 아니라 Windows의 인터넷 출처 경고를 제거하는 작업입니다.
  • 전자 메일·메신저에서 예상하지 못한 파일, 이중 확장자, 실행 파일, 매크로 포함 Office 파일은 열지 않습니다.
  • Defender 탐지를 ‘허용’하거나 격리 파일을 복원하기 전에 공식 배포처와 디지털 서명을 다시 확인합니다.
  • 다운로드 폴더 전체, 하위 폴더 전체, 공유 드라이브 전체를 일괄 차단 해제하지 않습니다.
  • 회사·학교 PC에서는 인터넷 옵션, 그룹 정책, 레지스트리, 보안 프로그램을 개인 판단으로 변경하지 않습니다.

6. FAQ

왜 Windows 업데이트 뒤 PDF 미리 보기가 갑자기 막혔나요?

2025년 10월 14일 이후 Windows 보안 업데이트가 인터넷 출처 MotW가 붙은 파일의 미리 보기를 기본 차단하기 때문입니다. PDF에만 한정된 변경이 아니며 지원되는 미리 보기 형식에 적용될 수 있습니다.

파일 속성에 차단 해제가 없으면 어떻게 하나요?

파일에 MotW가 없거나 네트워크 공유 자체가 인터넷 영역으로 분류된 경우일 수 있습니다. 로컬에서 직접 만든 파일과 비교하고 최신 Windows 업데이트를 적용하세요. 회사 공유 폴더라면 보안 영역을 직접 바꾸지 말고 IT 관리자에게 문의합니다.

모든 다운로드 파일을 한꺼번에 차단 해제해도 되나요?

권장하지 않습니다. 출처와 확장자를 확인하고 Defender 검사를 마친 파일만 개별 해제하세요. 제한된 묶음을 처리해야 한다면 별도 폴더에서 -WhatIf로 목록을 먼저 확인합니다.

Adobe Acrobat을 다시 설치해야 하나요?

경고 문구가 보이는 동안에는 Acrobat보다 Windows의 보안 표식이 우선 원인입니다. 차단 해제 후에도 신뢰할 수 있는 로컬 PDF만 미리 보기가 비어 있을 때 Acrobat 업데이트·복구를 검토하세요.

한 줄 요약

출처·확장자 확인 → Defender 검사 → 신뢰 파일 하나만 속성에서 차단 해제 → 재로그인 → 공유 위치는 업데이트 후 IT 확인 순서로 처리하고, 보안 기능 전체를 끄지 마세요.
