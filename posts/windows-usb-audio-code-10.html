Windows 11 USB 오디오 ‘이 장치를 시작할 수 없습니다(코드 10)’ 해결 7단계

USB 헤드셋·DAC·오디오 인터페이스가 갑자기 사라지고 장치 관리자에 “이 장치를 시작할 수 없습니다. (코드 10)”이 뜬다면, 드라이버부터 지우기 전에 오류가 시작된 날짜와 Windows 업데이트 이력을 비교하세요. Microsoft는 2026년 9월 보안 업데이트 이후 일부 USB Audio Class 1.0 장치에서 이 문제가 생길 수 있다고 공지했습니다. 그러나 모든 USB 오디오 장치의 코드 10이 이 업데이트 탓은 아닙니다. 이 글은 Windows 11 24H2·25H2를 기준으로, 해당 알려진 문제와 케이블·포트·드라이버 등 다른 원인을 구분합니다. 앱 메뉴·KB 번호는 OS 버전과 PC 관리 정책에 따라 달라집니다.

1. 1분 해결 요약

  1. 장치 관리자 → 사운드, 비디오 및 게임 컨트롤러 → 문제 장치 → 속성에서 코드 10과 장치 모델을 확인합니다.
  2. 설정 → Windows Update → 업데이트 기록에서 2026년 9월 업데이트, 특히 24H2·25H2의 KB5124008 설치 시점을 확인합니다.
  3. 작업을 저장하고 USB 허브·도크를 거치지 않고 PC 포트에 직접 다시 연결한 뒤 재시작합니다. 급한 통화는 내장 스피커·다른 정상 장치로 전환합니다.
  4. Windows Update와 제조사의 정확한 모델용 드라이버를 확인합니다. 다만 KB5129195가 코드 10을 모두 고치는 것은 아닙니다.
  5. 계속 실패하면 장치·드라이버 문제와 Microsoft의 미해결 알려진 문제를 나누어 공식 지원에 전달합니다.

2. 증상별 원인표

보이는 증상가능한 원인·범위먼저 확인할 것
9월 업데이트 뒤 USB 오디오 코드 10·무음일부 USB Audio Class 1.0의 Microsoft 알려진 문제 가능성OS 버전·업데이트 이력·릴리스 상태
장치 관리자 오류는 없는데 소리만 안 남출력 장치 선택·음소거·앱별 출력 문제설정의 출력 장치와 볼륨
허브·도크에서만 끊기거나 다른 PC에서도 실패연결·전원·장치 자체 문제 가능성직접 연결·다른 포트·제조사 진단
스테레오는 되지만 8채널·3D에서만 실패Microsoft가 별도로 밝힌 다채널 증상최신 업데이트와 음향 모드
코드 10이 업데이트 전부터 있었음드라이버·장치·포트 등 다른 원인 가능성제조사 모델·드라이버·다른 PC 결과

오류가 코드 43 등 다른 번호라면 이 글의 업데이트 알려진 문제로 단정하지 마세요. 장치 관리자 코드 10 자체도 원인을 하나로 특정하는 진단명이 아닙니다.

3. 쉬운 방법부터 해결하는 7단계

1단계: 정확한 장치·오류·업데이트 시점 기록

시작 버튼을 우클릭해 장치 관리자를 열고 사운드, 비디오 및 게임 컨트롤러와 오디오 입력 및 출력을 확인합니다. USB 오디오 장치의 속성 → 일반 → 장치 상태에 코드 10이 있는지 보세요. 장치 모델·드라이버 공급자·발생 시각을 기록합니다. Windows+R → winver로 24H2/25H2인지 확인하고 설정 → Windows Update → 업데이트 기록에서 KB5124008 또는 이후 업데이트가 증상 직전에 설치됐는지 봅니다. 버전이나 KB가 다르면 해당 버전의 릴리스 상태를 별도로 확인해야 합니다.

2단계: 출력 장치를 바꿔 당장 소리부터 복구

설정 → 시스템 → 소리 → 출력에서 내장 스피커나 다른 정상 장치를 선택하고 음소거·앱별 볼륨을 확인합니다. 이것은 USB 장치의 코드 10을 고치는 방법이 아니라 회의·작업을 이어가기 위한 임시 조치입니다. 문제가 없는 다른 장치에서 소리가 나면 Windows 전체의 오디오 장애와 구분할 수 있습니다.

3단계: 허브를 빼고 직접 연결·재시작

재생·녹음 작업을 저장하고 장치를 안전하게 분리합니다. USB 허브·도크·연장 케이블 대신 PC의 다른 USB 포트에 직접 연결하세요. PC를 재시작한 뒤 장치 상태를 다시 봅니다. 가능하면 제조사가 지원하는 케이블로 바꾸거나, 다른 PC에서 같은 장치를 시험해 연결 문제를 좁힙니다. 다른 PC에서도 고장이라면 제조사 지원을 우선합니다. 기업용 도크·오디오 장치는 IT 정책을 따르세요.

4단계: Windows 오디오 진단과 장치 상태 재확인

설정 → 시스템 → 소리에서 출력 장치를 확인하고 Windows의 오디오 문제 해결 기능 또는 도움말 보기(Get Help) 진단을 실행합니다. 장치 관리자에서 해당 장치가 사용 안 함 상태라면 정확한 장치인지 확인한 뒤 다시 사용합니다. 진단 후에도 코드 10이 남는지 봅니다. 출력 목록에 없을 뿐 코드 10이 아니라면 일반 ‘오디오 출력 장치가 검색되지 않음’ 문제일 수 있습니다.

5단계: Microsoft의 현재 해결 범위를 확인

Windows 11 25H2 릴리스 상태 또는 24H2 릴리스 상태의 USB audio devices might fail to start or produce no sound 항목을 확인합니다. 2026년 9월 23일 기준 Microsoft는 9월 14일 긴급 업데이트 KB5129195가 8채널·3D 음향 증상만 해결했다고 밝히고, 코드 10·무음 등 나머지 증상은 조사 중이라고 적었습니다. 최신 정식 업데이트를 설치하는 것은 보안·다른 오류 해결에 도움이 되지만, 코드 10의 확정 해결책으로 안내할 수는 없습니다. 업데이트 제거·일시 중지로 보안을 낮추지 마세요.

6단계: 정확한 모델용 드라이버만 점검

장치 관리자에서 해당 USB 오디오 장치를 우클릭해 드라이버 업데이트 → 드라이버 자동 검색을 실행하고, 필요하면 Windows Update의 선택적 드라이버 업데이트를 확인합니다. 제조사 사이트에서 장치 모델과 Windows 버전·아키텍처가 맞는 드라이버가 있는지도 봅니다. 공식 제조사 이외의 드라이버 모음·업데이트 프로그램은 사용하지 마세요. 최근 장치 드라이버 교체 직후부터 문제가 생겼고 속성 → 드라이버 → 드라이버 롤백이 활성화돼 있을 때만 롤백을 고려합니다. 9월 Windows 자체의 USB Audio Class 1.0 알려진 문제라면 드라이버 롤백으로 해결된다고 단정할 수 없습니다.

7단계: 장치만 재설치하거나 공식 지원에 전달

문제가 업데이트 알려진 범위와 맞지 않고, 제조사 드라이버 설치 파일·복구 경로를 확보했다면 작업을 저장한 뒤 정확히 해당 오디오 장치만 장치 관리자 → 장치 제거하고 재시작해 Windows의 재인식을 확인합니다. USB 컨트롤러 전체나 모든 오디오 장치를 제거하지 마세요. 드라이버 패키지 삭제 옵션은 복구 파일이 없다면 선택하지 않습니다. 알려진 문제에 부합하거나 재설치 뒤에도 코드 10이면 Microsoft 공식 지원 또는 제조사에 OS 빌드·KB·장치 모델·오류 화면·직접 연결 결과를 전달합니다. 조직 PC는 IT 관리자에게 먼저 문의하세요.

4. 정상 확인과 실패 시 다음 조치

  • 장치 관리자 장치 상태에서 코드 10이 사라지고 장치가 정상 동작하는지 확인합니다.
  • 설정 → 시스템 → 소리 → 출력에 장치가 나타나고 테스트 소리·볼륨 조절이 작동하는지 봅니다.
  • 브라우저와 회의 앱 등 두 앱에서 각각 짧게 재생·녹음해 한 앱의 설정 문제와 구분합니다.
  • 다채널에서만 실패했다면 스테레오와 8채널·3D를 구분해 테스트하고 결과를 기록합니다.

코드 10이 남으면 KB5129195 설치 여부만으로 해결을 기대하지 마세요. 특히 USB Audio Class 1.0과 9월 업데이트 시점이 맞으면 Microsoft의 릴리스 상태 갱신을 확인하고 공식 지원을 이용하세요. 다른 PC에서도 실패하거나 케이블·포트에 따라 달라지면 제조사에 하드웨어 진단을 요청합니다.

5. 데이터·결제·계정·보안 주의

  • 드라이버 조작·재시작 전 녹음 파일과 작업을 저장하세요. USB 장치 재설치 중 회의 소리·녹음이 끊길 수 있습니다. 파일 자체를 삭제하는 절차는 아닙니다.
  • 비공식 드라이버 다운로드·‘원클릭 복구’ 결제·원격 제어 요구를 피하세요. 이 문제를 이유로 유료 오디오 프로그램이나 새 장치를 바로 구매할 필요는 없습니다.
  • Microsoft 계정 암호·인증 코드·장치 일련번호 전체를 공개 게시판에 올리지 마세요. 지원 요청은 Microsoft·제조사의 공식 페이지에서 직접 시작합니다.
  • 9월 보안 업데이트를 무작정 제거하거나 Windows Update를 장기간 중단하지 마세요. 조직 관리 PC는 보안·드라이버 정책을 임의로 변경하지 않습니다.

6. FAQ

KB5129195를 설치하면 코드 10이 반드시 해결되나요?

아니요. Microsoft의 2026년 9월 23일 기준 공지는 8채널·3D 음향 증상만 해결됐고 코드 10·무음·볼륨 이상 등은 조사 중이라고 구분합니다. 이후 해결 상태가 바뀌었는지 릴리스 상태를 다시 확인하세요.

모든 USB 헤드셋·DAC의 코드 10이 이 업데이트 때문인가요?

아닙니다. Microsoft가 밝힌 범위는 일부 USB Audio Class 1.0 장치입니다. 제품명만으로 Class 1.0 여부를 단정하지 말고 제조사 사양·지원에 확인하세요. 다른 클래스나 업데이트 전부터 있던 오류는 별도 원인일 수 있습니다.

드라이버를 바로 삭제해야 하나요?

먼저 오류 코드·업데이트 이력·직접 연결 결과를 기록하세요. 장치가 정확히 식별되고 공식 재설치 파일을 준비한 경우에만 마지막 단계로 재설치합니다. USB 컨트롤러 전체 삭제는 이 안내의 대상이 아닙니다.

스테레오는 되는데 8채널에서만 안 됩니다. 같은 문제인가요?

Microsoft가 별도 증상으로 열거한 사례와 맞을 수 있습니다. 25H2·24H2에서 KB5129195 또는 이후 정식 업데이트는 이 다채널 증상을 해결한다고 공지됐습니다. 코드 10이나 완전한 무음까지 해결한다는 뜻은 아닙니다.

Windows 11 23H2·26H1이나 Windows 10도 같은 KB인가요?

아닙니다. 알려진 문제의 영향 범위에는 다른 OS도 들어갈 수 있지만 KB 번호는 버전마다 다릅니다. 이 글의 KB5124008·KB5129195는 24H2·25H2 기준입니다. 다른 버전은 해당 버전의 Microsoft 릴리스 상태를 확인하세요.

한 줄 요약

코드 10과 KB 설치 시점 확인 → 임시 출력 전환 → 직접 연결·재시작 → 오디오 진단 → 릴리스 상태 확인 → 공식 드라이버 점검 → 필요 시 정확한 장치만 재설치·지원 요청 순서입니다. 2026년 9월 USB Audio Class 1.0 알려진 문제는 아직 부분 해결 상태입니다.
