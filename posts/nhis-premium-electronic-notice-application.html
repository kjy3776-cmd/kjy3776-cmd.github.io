건강보험료 전자고지 신청·변경·해지: 이메일·모바일과 적용 월 확인

2026-11-14 확인건강보험료
대상·채널신청·감액신청 순서미수신 확인

건강보험료 고지서를 이메일이나 모바일로 받고 싶다면 보험료 전자고지서 신청을 확인하세요. 전자고지는 고지서를 받는 방법을 바꾸는 서비스입니다. 보험료를 계좌·카드에서 내는 자동이체와 별개이므로, 전자고지를 신청했다고 보험료가 자동 납부되지는 않습니다.

확인일: 2026년 11월 14일. 국민건강보험공단의 전자고지 신청·홈페이지 고지내역 조회 안내와 사회보험통합징수포털 안내를 대조했습니다. 국내 건강보험 지역가입자의 신청을 중심으로 설명합니다. 국민연금·사업장 고지와 외국인 선납세대는 적용 조건이 다르므로 구분합니다. 실제 로그인·개인정보 입력·신청·해지는 하지 않았습니다.

광고

1. 신청 대상과 받을 채널 선택

공단은 건강보험 전자고지를 지역가입자 세대주·세대원이 신청할 수 있다고 안내합니다. 직장가입자·피부양자가 지역보험료 고지서를 신청하는 것으로 이해하지 마세요. 먼저 본인이 직접 고지받는 보험료인지 확인합니다.

선택 가능한 유형은 이메일, 모바일 카카오 알림톡, 모바일 네이버앱, 홈페이지 고지서입니다. 자주 확인하는 채널과 본인 수신 정보를 기준으로 선택하세요.

  • 이메일 + 홈페이지: 공단은 두 채널의 중복 신청이 가능하다고 안내합니다.
  • 모바일 고지: 이메일·홈페이지 고지와 중복 신청할 수 없습니다. 기존 수신 방식이 어떻게 바뀌는지 신청 결과에서 확인합니다.
  • 사업장: 개인 서비스와 구분해 사회보험통합징수포털의 전자고지 안내를 확인합니다. 사업장용 감액표·신청자격을 지역가입자에게 그대로 적용하지 않습니다.

휴대전화나 이메일을 바꿨다면 기존 등록 정보도 확인하세요. 다른 사람의 번호를 임의로 등록하거나 개인정보를 공개 게시판에 올리지 않습니다.

2. 적용 월과 감액 조건 확인

지역가입자 안내는 당월 15일까지 신청 등록되면 당월분 보험료 고지서부터, 16일 이후에는 익월부터 전자고지가 발송된다고 설명합니다. 화면 작성만 한 상태와 신청이 등록된 상태를 구분하세요. 납부기한이 임박했다면 이번 고지서를 어디서 확인해야 하는지 먼저 살펴봅니다.

외국인 선납세대는 별도 기준입니다. 전월 1일부터 말일까지 신청 등록된 건에 대해 익월분 전자고지가 발송된다고 안내하므로 일반 지역가입자의 15일 기준을 그대로 적용하지 않습니다.

공단의 지역가입자 서비스 안내에는 이메일 고지를 신청하면 건강·연금 각각 신청 월부터 200원 감액이 표시됩니다. 다만 보수 외 소득월액·임의계속가입자는 감액이 적용되지 않습니다. 모바일·홈페이지 신청에도 같은 감액이 있다고 확대 해석하지 말고, 본인에게 적용되는지 실제 고지 내역을 확인하세요.

국민연금은 지역상실·납부예외 상태이면 이 서비스 신청이 불가하며, 당일 자격 취득·납부재개는 익일부터 신청 가능하다는 별도 조건도 있습니다. 건강보험과 국민연금을 함께 확인하더라도 보험별 자격을 구분합니다.

3. 공단에서 신청·변경·해지하기

공식 서비스 안내 · 광고 아님보험료 전자고지서 신청 안내 확인
  1. 공단 누리집의 ‘민원서비스 → 서비스찾기’에서 전자고지를 검색합니다.
  2. ‘보험료 전자고지서 신청’ 안내에서 대상·유형·적용 월을 확인하고 신청하기로 이동합니다.
  3. 본인확인 후 대상 보험, 기존 신청 내역과 수신 정보를 확인합니다.
  4. 신규 신청·수신 정보 변경·해지 중 필요한 업무를 선택하고 현재 화면이 요구하는 동의·확인을 마칩니다.
  5. 접수 결과에서 신청 유형·수신처·반영 상태를 확인합니다.

공단은 홈페이지 외에 건강보험 앱, 전화 1577-1000, 지사 방문, 팩스·우편 경로도 안내합니다. 앱은 현재 공식 건강보험25시에서 업무명으로 찾고, 전화·방문·서면 접수는 본인확인과 필요한 서류를 먼저 문의하세요. 인증 후의 실제 입력 화면은 이번 검증에서 실행하지 않았으므로 버튼 위치를 확정 안내하지 않습니다.

4. 고지서가 오지 않거나 조회되지 않을 때

우선 신청 등록일과 적용 월을 확인합니다. 이어 수신 이메일·휴대전화·선택 채널이 맞는지, 이메일 스팸함이나 앱 알림 설정에 문제가 없는지 점검하세요. 이미 다른 유형으로 변경했는지도 확인합니다.

홈페이지 고지내역 조회는 홈페이지 고지서를 신청해 전자고지가 발행된 월에 한해 확인하는 서비스입니다. 모든 과거 보험료 고지서가 자동으로 이 메뉴에 생기는 것은 아닙니다. 공단은 직장가입자·피부양자를 이 조회 대상에서 제외한다고 안내합니다.

해지·변경을 신청한 뒤에는 실제 등록 결과와 이후 고지 방식을 확인하세요. 정기고지와 독촉고지가 같은 채널로 온다고 단정하지 않습니다. 징수포털 안내는 전자고지에 정기고지서만 발송하고 독촉고지는 별도 우편으로 발송하는 경우를 구분합니다.

수신이 불명확해도 납부기한을 확인하는 일을 미루지 마세요. 공단에서 고지·미납 내역과 납부 방법을 확인하거나 고객센터 1577-1000(평일 09~18시)에 문의합니다. 등록 오류가 의심되면 같은 신청을 반복하기 전에 기존 처리 상태를 먼저 확인합니다.

5. 자동이체·납부확인서와 구분

전자고지 신청은 계좌나 카드의 자동이체 등록·변경·해지를 대신하지 않습니다. 납부 방법까지 바꾸려면 건강보험료 자동이체 신청·변경·해지를 별도로 확인하세요. 자동이체가 이미 등록돼 있어도 실제 출금 결과를 점검해야 합니다.

고지서는 납부할 보험료를 알리는 문서이고, 납부 사실을 제출하는 서류는 건강보험료 납부확인서입니다. 제출처가 요구한 문서를 확인하고 고지서로 임의 대체하지 마세요.
