지방세 전자송달 신청: 위택스·서울 ETAX·수신 확인 방법

2026-11-10 확인지방세 전자송달
대상·자동이체 차이위택스 신청서울 신청수신·변경 확인

지방세 고지서를 우편 대신 이메일이나 앱으로 받고 싶다면 전자송달 신청을 확인하세요. 전자송달은 고지서를 받는 방식을 바꾸는 업무이며, 계좌에서 세금이 자동 출금되게 하는 자동이체와는 다릅니다. 신청 후에는 수신 경로와 적용 대상, 실제 고지 내역을 확인해야 합니다.

확인일: 2026년 11월 10일. 검단구청의 2026년 8월 13일 FAQ와 서울시 인터넷납부 안내를 대조했습니다. 개인 납세자의 지방세 고지서 수신을 중심으로 설명하며 국세 고지, 법인·대리 신청과 개별 과태료 등은 해당 기관 안내를 따르세요.

광고

1. 어떤 고지서를 받는지 먼저 구분

검단구청은 지방세 정기분인 면허세·자동차세·재산세·주민세의 전자고지 수신과 위택스 신청 경로를 안내합니다. 서울시 안내는 정기분 외 일부 수시분·세외수입도 설명하지만 예외 항목이 따로 있습니다. ‘전자송달 한 번이면 모든 세금·과태료를 받는다’고 생각하지 말고 실제 신청 화면에서 대상 세목을 확인하세요.

전자송달을 신청해도 납부가 저절로 완료되는 것은 아닙니다. 자동이체를 원한다면 별도 신청 상태를 확인하고, 고지서를 받았을 때는 납부기한·금액과 납부완료 내역을 따로 점검하세요. 세액공제의 대상·금액도 지역과 요건에 따라 확인해야 하며 전국에 같은 금액을 적용한다고 단정하지 마세요.

2. 위택스에서 신청하는 순서

  1. 공식 접속: 위택스 홈페이지에 접속해 로그인·본인인증 조건을 확인합니다. 세금 안내 문자에 포함된 낯선 주소보다 공식 주소를 직접 이용하세요.
  2. 신청 메뉴 찾기: 검단구청 안내의 경로는 ‘신청 → 전자송달 → 전자송달 신청’입니다. 메뉴가 바뀌면 사이트 검색에서 ‘전자송달’을 찾습니다.
  3. 수신정보 확인: 화면에서 제공하는 수신 방식과 대상 세목을 읽고 이메일 등 필요한 정보를 정확히 입력합니다. 사용하지 않는 계정이나 오타가 없는지 대조하세요.
  4. 제출 후 점검: 동의·최종 신청을 완료한 뒤 신청내역과 적용 안내를 확인합니다. 임시저장이나 이메일 입력만으로 등록 완료라고 판단하지 마세요.

전자송달이 언제부터 적용되는지, 이미 발행된 고지서도 포함되는지는 신청 화면과 과세기관에 확인하세요. 납기가 임박한 현재 고지서는 신청만 해두고 기다리지 말고 기존 고지·납부 내역으로 기한을 관리하세요.

3. 서울은 ETAX·STAX 안내 확인

서울시 공식 안내는 ETAX 로그인 또는 비회원 본인인증 후 신청할 수 있다고 설명합니다. PC의 이메일 신청 경로는 나의 ETAX → 전자송달관리 → 전자송달신청입니다. 모바일 웹은 같은 관리 메뉴에서 신청·변경·해지를, STAX 앱은 ‘MY STAX → 전자송달관리’를 안내합니다.

서울시도 세외수입 중 환경개선부담금 등 일부 적용 예외를 설명합니다. 수신하려는 고지서가 목록에 없으면 다른 세목을 임의 선택하지 말고 고지기관에 문의하세요. 위택스와 ETAX의 메뉴·대상 범위를 동일하게 가정하지 않는 것이 좋습니다.

4. 신청 후 안 오거나 이메일을 바꿀 때

  • 내역: 신청이 실제로 완료됐고 해당 세목·과세기관에 적용되는지 확인합니다.
  • 수신처: 등록한 이메일 주소, 스팸함과 사용하는 앱의 고지서함을 확인합니다. 단순 알림 유무와 고지서 저장·열람 여부는 구분하세요.
  • 납부: 알림이 보이지 않아도 납부할 세금이 없는 것으로 판단하지 말고 공식 사이트에서 고지·미납 내역을 확인합니다.
  • 변경·해지: 이메일이나 이용 앱을 바꾸면 전자송달 관리 메뉴에서 변경·해지 상태와 적용 시점을 확인합니다. 기존 계정 탈퇴만으로 다른 고지 방식이 복구됐다고 가정하지 마세요.

전자송달 내역과 고지서가 맞지 않으면 세목·과세기관·신청일과 오류 문구를 정리해 담당 세무부서에 문의하세요. 인증 오류는 사이트 이용문의와 구분하면 원인을 찾기 쉽습니다. 개인 세금·인증정보가 담긴 화면은 공개 게시판에 올리지 마세요.
