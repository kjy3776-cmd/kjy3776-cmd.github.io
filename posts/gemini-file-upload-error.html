Gemini에서 PDF·엑셀·이미지를 올리지 못할 때 브라우저 문제라고 단정하기 전에 파일 개수, 용량, ZIP 내부 구성, 사용량 제한, 계정 권한부터 확인하세요. Google 공식 도움말 기준으로 오류 문구마다 해결 방법이 다릅니다.

3. 해결 7단계

1단계: 새 채팅에서 파일 1개만 시험

기존 대화의 긴 문맥과 여러 첨부파일 영향을 분리하기 위해 새 채팅을 열고 작은 PDF나 이미지 1개만 올립니다. 이 파일은 되면 원래 파일의 크기·형식·내용 문제일 가능성이 큽니다.

2단계: 파일 수와 실제 크기 확인

Windows 탐색기에서 파일 우클릭 → 속성으로 크기를 확인합니다. 일반 파일은 100MB 아래로 줄이고, 폴더 안 파일도 각각 개수에 포함된다는 점을 확인하세요. 파일명 끝의 확장자가 숨겨져 있다면 보기 → 표시 → 파일 확장명을 켭니다.

3단계: ZIP 내부 구성 정리

ZIP은 100MB 이하라도 내부 파일이 10개를 넘거나 오디오·동영상이 들어 있으면 공식 기준에 맞지 않습니다. 필요한 문서만 새 ZIP으로 만들거나 파일을 개별로 나눠 올리세요. 압축 암호가 걸린 파일은 내용을 읽지 못할 수 있으므로 민감하지 않은 사본에서만 암호를 해제합니다.

4단계: 분석 실패면 다시 저장·재업로드

Google은 ‘파일 분석 실패’가 표시되면 재업로드를 안내합니다. 먼저 원본을 복사해 PDF나 XLSX로 다시 저장하고 새 채팅에 올리세요. 원본을 덮어쓰지 말고 사본을 사용합니다. 스캔 PDF라면 텍스트가 선택되는지 확인하고, 필요한 페이지만 별도 PDF로 만들어 질문 범위를 좁히세요.

5단계: 파일 한도와 모델 사용량을 구분

‘파일이 포함된 채팅의 한도에 도달했습니다’라면 브라우저 재설치보다 재시도 시점을 확인하세요. Google은 파일 업로드·분석량의 한도가 변동적이며 시간이 지나면 재설정된다고 안내합니다. 별도로 Gemini 앱 모델 사용량은 5시간 단위로 갱신되고 주간 한도도 있을 수 있으므로, 파일 한도와 모델 한도를 같은 고정 횟수로 계산하지 마세요. 화면의 초기화 안내와 gemini.google.com → 왼쪽 아래 설정 → 사용량 한도를 확인하세요. 유료 업그레이드는 필수가 아니며 결제 전 필요한 사용량을 비교하세요.

6단계: 활동 저장공간과 계정 구분

‘파일을 업로드하려면 데이터를 삭제하세요’는 Google Drive와 별도인 Gemini 앱 활동 저장공간 오류입니다. 개인 계정은 설정 및 도움말 → 활동에서 삭제 대상을 검토하고 필요한 대화·파일의 사본을 먼저 보관하세요. 삭제한 활동이나 Gems가 저장공간에 반영되기까지 몇 분 걸릴 수 있으므로 즉시 재시도해 같은 메시지가 나오면 잠시 기다립니다. 회사·학교 계정에서는 관리자가 활동을 삭제해야 할 수 있습니다. 삭제는 되돌리기 어려우므로 전체 활동을 무작정 지우지 마세요.

7단계: 브라우저·계정 권한 격리

  1. gemini.google.com을 새로고침하고 다시 로그인합니다.
  2. 시크릿 창이나 최신 Chrome에서 같은 작은 파일을 시험합니다.
  3. 광고 차단·보안 확장을 잠시 끈 새 프로필로 비교합니다.
  4. Drive 파일만 실패하면 개인 계정은 Gemini의 활동 기록 보관과 Google Workspace 연결 상태를 확인합니다. 회사·학교 계정은 관리자에게 Gemini 앱 액세스와 연결 앱 허용 여부를 문의합니다. 조직 정책을 우회하지 마세요.
  5. 서비스 장애가 의심되면 잠시 뒤 다시 시도합니다.

브라우저 캐시 전체 삭제는 로그아웃과 사이트 설정 초기화를 만들 수 있으므로 위 비교 후 마지막에 진행하세요.

4. 정상 확인과 실패 시 다음 조치

같은 계정의 새 채팅에서 민감하지 않은 작은 파일 1개를 올려 Gemini가 파일 이름과 한 페이지의 내용을 정확히 읽는지 확인합니다. 업로드만 성공하고 분석이 틀리면 크기·컨텍스트 문제일 수 있으므로 필요한 페이지만 나눠 질문 범위를 좁히세요. 파일 하나도 여러 브라우저에서 실패하면 오류 문구·파일 형식·크기·계정 유형·발생 시각을 기록하고 Gemini 공식 고객센터의 관련 도움말과 의견 보내기를 이용하세요. 회사·학교 계정의 Drive 권한 문제는 조직 관리자에게 문의하세요. 오류 파일이나 개인정보를 공개 게시판에 올리지 마세요.

5. 민감한 파일을 올리기 전

주민등록번호, 계좌번호, 비밀번호, 의료·인사자료, 고객 명단은 원본 그대로 올리지 마세요. 필요한 부분만 남긴 사본에서 개인정보를 가리고 업로드하세요.

Google의 Gemini 개인정보 안내에 따르면 사용자가 공유한 파일·사진·화면도 Gemini 앱 정보에 포함됩니다. Gemini 앱 활동을 켠 경우 공유한 내용이 활동에 저장되고, 설정과 지역에 따라 서비스 개선 및 사람 검토 과정에 사용될 수 있습니다. 회사 자료는 조직의 AI 사용 정책도 확인하세요.

6. FAQ

100MB보다 작은데도 안 올라갑니다.

같은 프롬프트의 총 파일 수, ZIP 내부 파일 수, 변동 사용량 한도, Gemini 저장공간, 회사 계정 정책을 순서대로 확인하세요.

큰 PDF를 올리면 일부 내용을 빼먹습니다.

업로드 성공과 전체 내용 이해는 별개입니다. 필요한 장이나 페이지로 나누고 ‘3~10쪽 표만 비교’처럼 범위를 지정하세요. Google도 큰 파일에서는 흩어진 세부 연결을 놓칠 수 있다고 안내합니다.

Drive 용량을 비우면 저장공간 오류가 없어지나요?

‘업로드하려면 데이터 삭제’ 오류는 Gemini 활동 저장공간 한도이며 Drive·Workspace 저장공간과 별개라고 안내되어 있습니다.

개인 계정에서 Drive 파일 추가가 안 보입니다.

Gemini 활동 기록 보관과 Google Workspace 연결 상태를 확인하세요. 회사·학교 계정이라면 관리자 정책도 확인해야 합니다.

파일을 삭제하면 Google에서도 즉시 사라지나요?

저장·처리 기간은 Gemini 앱 활동 설정과 개인정보 정책에 따라 달라질 수 있습니다. 중요한 정보는 애초에 최소한만 공유하는 것이 안전합니다.
