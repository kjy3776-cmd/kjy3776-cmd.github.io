Claude 로그인은 Google 계정 또는 이메일로 받은 보안 링크를 사용합니다. 메일 미수신과 코드 오류는 로그인 자체의 문제지만, 로그인 뒤 대화나 구독이 보이지 않는다면 개인·조직 계정 선택 또는 Apple 비공개 이메일 주소를 먼저 확인해야 합니다. 아래 내용은 2026년 9월 27일 Claude·Apple 공식 문서와 대조했습니다. 화면 문구는 앱 버전·계정 유형에 따라 다를 수 있습니다.

1분 해결 요약

  1. 여러 기기에서 실패하면 Claude 상태 페이지의 장애부터 확인합니다.
  2. 이메일 링크는 요청한 기기에서 열거나, 다른 기기에 표시된 코드를 원래 기기에 입력합니다. 메일이 안 오면 @mail.anthropic.com을 스팸·격리함에서 찾습니다.
  3. 로그인은 됐는데 대화·구독이 비어 있으면 결제나 계정 삭제 전에 프로필의 개인·조직 계정 선택과 실제 로그인 이메일을 확인합니다.

2. Claude 로그인 오류 해결 7단계

1단계: Claude 상태 페이지 확인

Claude Status에서 claude.ai 장애가 있는지 봅니다. 여러 기기와 네트워크에서 같은 오류가 나고 진행 중인 사고가 표시되면 계정 설정을 바꾸지 말고 복구를 기다리세요.

2단계: 원래 이메일과 계정 유형 확인

Claude 공식 로그인에서 Continue with Google 또는 Continue with email을 선택합니다. 로그인 수단만 다르다는 이유로 대화가 없는 별도 계정이라고 단정하지 마세요. 먼저 입력한 이메일 주소가 기존 계정 주소와 같은지 확인합니다. 같은 이메일로 개인·Team·Enterprise 계정이 함께 있을 수 있으므로 로그인 후 계정 선택도 점검하세요.

3단계: 로그인 메일을 정확히 찾기

이메일 로그인을 선택했다면 스팸·정크·격리함에서 @mail.anthropic.com 발신 메일을 찾습니다. 회사·학교 메일은 보안 필터가 막을 수 있으므로 관리자에게 해당 도메인 허용을 요청하세요. 몇 분 기다린 뒤 한 번만 다시 요청하고 가장 최근 메일을 사용합니다.

4단계: 요청한 기기에서 링크 열기

로그인 메일을 요청한 브라우저와 같은 기기에서 링크를 여는 것이 가장 확실합니다. 다른 기기에서 열면 원래 기기에 입력할 인증 코드가 표시될 수 있습니다. 링크가 만료됐거나 이미 사용됐다면 새 링크를 요청하고 이전 메일은 닫으세요.

5단계: 시크릿 창으로 충돌 구분

최신 Chrome·Edge·Safari의 시크릿 창에서 다시 시험합니다. 여기서는 되면 기존 창의 쿠키나 광고 차단·개인정보 보호 확장이 원인일 가능성이 큽니다. 먼저 claude.ai 사이트 데이터만 지우고, 브라우저 전체 쿠키 삭제는 다른 사이트에서 로그아웃될 수 있으므로 마지막에 진행하세요.

6단계: Google 연결과 네트워크 점검

Google 로그인이 반복되면 브라우저·네트워크를 바꿔 비교하고 조직 계정이라면 초대된 이메일과 SSO 정책을 관리자에게 확인합니다. 개인 Google 연결 문제로 좁혀졌다면 Google 계정의 연결 관리에서 Claude by Anthropic → See details → Stop using Sign in with Google을 선택한 뒤 Claude에서 Google 로그인을 다시 시도할 수 있습니다. 연결 해제는 로그인 수단에 영향을 주므로 해당 이메일을 수신할 수 있고 조직 정책상 허용되는지 확인한 뒤 진행하세요. 이는 Claude 계정이나 대화를 삭제하는 절차가 아닙니다.

7단계: 공식 지원으로 계정 확인

계속 실패하면 Claude Help Center 오른쪽 아래 메시지 아이콘에서 I can't login을 선택합니다. 오류 문구, 발생 시각, 사용 기기와 브라우저를 적되 비밀번호·인증 코드·신분증 사진을 채팅에 직접 붙이지 마세요. 유료 구독자는 로그인 정보 확인, 구독 취소, 환불 가능 여부를 지원팀에 문의할 수 있습니다.

로그인됐는데 대화·구독이 안 보일 때

  1. 같은 이메일의 두 계정: 개인 계정과 Team·Enterprise 계정을 모두 쓰면 왼쪽 아래 프로필 이니셜을 눌러 원하는 계정을 선택하고 체크 표시를 확인합니다. 두 계정의 대화·프로젝트는 별개일 수 있습니다. 계정 이전·삭제는 되돌리기 어려우므로 문제 진단을 위해 실행하지 마세요.
  2. Apple 이메일 가리기: 가입 시 @privaterelay.appleid.com 주소를 사용했다면 일반 이메일 대신 그 릴레이 주소로 Continue with email을 선택합니다. 기존 iPhone Claude 앱에 로그인돼 있다면 프로필 이니셜 → Settings에서 사용 중인 주소를 확인할 수 있습니다. 링크는 연결된 Apple ID 메일함으로 전달됩니다.
  3. 정말 다른 이메일을 사용했다면: 로그인에 쓰인 주소를 먼저 비교합니다. Claude는 기존 계정 이메일 변경을 지원하지 않으므로, 구독이 있는 계정의 메일 접근권을 잃었다면 새 계정을 결제하기 전에 공식 지원에 로그인·결제 문제를 문의합니다.

3. 휴대폰·신원 인증에서 막힐 때

전화번호 확인 화면이 나오면 SMS를 받을 수 있는 지원 지역의 휴대폰 번호를 사용합니다. Anthropic은 VoIP, 유선전화, 문자 수신이 안 되는 번호를 받지 않는다고 안내합니다. 코드가 5분 이상 오지 않으면 번호를 다시 확인하고 새 코드를 요청해 가장 최근 코드만 입력하세요.

일부 사용 사례에서는 정부 발급 사진 신분증과 휴대폰 카메라를 이용한 신원 확인이 나타날 수 있습니다. 화면의 공식 절차에서만 진행하고, 촬영이 흐리거나 문서가 만료됐으면 다시 촬영합니다. 반복 실패 시 우회 방법을 찾지 말고 공식 지원에 문의하세요.

4. 계정 보안이 의심될 때

본인이 요청하지 않은 로그인 메일이나 인증 코드는 사용하지 말고 누구에게도 전달하지 마세요. 로그인할 수 있다면 웹 Claude의 Settings → Account → Log Out으로 모든 활성 세션에서 로그아웃할 수 있습니다. Google 계정을 사용했다면 Google 보안 페이지에서 최근 로그인과 연결 앱도 확인하세요.

5. FAQ

Claude 비밀번호를 재설정할 수 있나요?

Claude는 Google 로그인 또는 이메일 보안 링크를 사용하므로 일반적인 Claude 전용 비밀번호 재설정 메뉴가 없습니다. Google 방식이면 Google 계정 비밀번호를 관리하고, 이메일 방식이면 새 로그인 링크를 받으세요.

메일 링크를 휴대폰에서 열었더니 코드가 나옵니다.

정상적인 교차 기기 절차일 수 있습니다. 그 코드를 로그인 메일을 요청한 원래 기기의 Claude 화면에 입력하세요.

같은 이메일인데 대화가 사라진 것처럼 보입니다.

왼쪽 아래 프로필에서 개인·조직 계정 중 어느 쪽에 체크 표시가 있는지 확인하세요. Apple 이메일 가리기를 썼다면 원래 계정 주소가 비공개 릴레이 주소인지도 확인합니다. 대화를 찾기 전에는 새 결제·계정 삭제를 하지 마세요.

Apple 비공개 이메일로 만든 계정은 다른 기기에서 어떻게 로그인하나요?

기존 iPhone 앱의 Settings에서 릴레이 주소를 확인한 뒤 다른 기기의 Claude에서 그 주소로 Continue with email을 선택합니다. Apple ID로 전달된 보안 링크를 사용하세요.

앱을 삭제하면 대화가 사라지나요?

앱 재설치 전에 정확한 계정과 로그인 방식을 확인하세요. 다른 계정으로 로그인하면 대화가 사라진 것처럼 보일 수 있습니다. 계정을 삭제하거나 새 계정을 만들 필요는 없습니다.
