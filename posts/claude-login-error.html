Claude 로그인은 전용 비밀번호보다 Google 계정 또는 이메일로 받은 보안 링크를 사용합니다. 따라서 메일이 안 오는 문제, 다른 기기에서 링크를 연 문제, 서비스 장애, 계정 제한을 먼저 구분해야 합니다. 아래 절차는 Anthropic 공식 도움말과 상태 페이지를 2026년 9월 16일에 교차 확인해 정리했습니다.

2. Claude 로그인 오류 해결 7단계

1단계: Claude 상태 페이지 확인

Claude Status에서 claude.ai 장애가 있는지 봅니다. 여러 기기와 네트워크에서 같은 오류가 나고 진행 중인 사고가 표시되면 계정 설정을 바꾸지 말고 복구를 기다리세요.

2단계: 원래 가입 방식을 그대로 사용

Claude 공식 로그인에서 가입할 때 쓴 Continue with Google 또는 Continue with email을 선택합니다. 같은 이메일처럼 보여도 Google 로그인과 이메일 링크 흐름은 다를 수 있습니다. 대화나 구독이 없는 새 계정이 열리면 결제하지 말고 원래 방식을 다시 확인하세요.

3단계: 로그인 메일을 정확히 찾기

이메일 로그인을 선택했다면 스팸·정크·격리함에서 @mail.anthropic.com 발신 메일을 찾습니다. 회사·학교 메일은 보안 필터가 막을 수 있으므로 관리자에게 해당 도메인 허용을 요청하세요. 몇 분 기다린 뒤 한 번만 다시 요청하고 가장 최근 메일을 사용합니다.

4단계: 요청한 기기에서 링크 열기

로그인 메일을 요청한 브라우저와 같은 기기에서 링크를 여는 것이 가장 확실합니다. 다른 기기에서 열면 원래 기기에 입력할 인증 코드가 표시될 수 있습니다. 링크가 만료됐거나 이미 사용됐다면 새 링크를 요청하고 이전 메일은 닫으세요.

5단계: 시크릿 창으로 충돌 구분

최신 Chrome·Edge·Safari의 시크릿 창에서 다시 시험합니다. 여기서는 되면 기존 창의 쿠키나 광고 차단·개인정보 보호 확장이 원인일 가능성이 큽니다. 먼저 claude.ai 사이트 데이터만 지우고, 브라우저 전체 쿠키 삭제는 다른 사이트에서 로그아웃될 수 있으므로 마지막에 진행하세요.

6단계: Google 연결과 네트워크 점검

Google 로그인이 반복되면 VPN·프록시를 끄고 다른 네트워크에서 비교합니다. Google 계정의 연결된 앱에서 Claude 연결을 해제한 뒤 다시 승인할 수도 있지만, 조직 계정은 관리자 정책이 적용될 수 있습니다. 회사 SSO를 쓰는 Team·Enterprise 사용자는 초대받은 이메일과 조직 로그인 주소를 관리자에게 확인하세요.

7단계: 공식 지원으로 계정 확인

계속 실패하면 Claude Help Center 오른쪽 아래 메시지 아이콘에서 I can't login을 선택합니다. 오류 문구, 발생 시각, 사용 기기와 브라우저를 적되 비밀번호·인증 코드·신분증 사진을 채팅에 직접 붙이지 마세요. 유료 구독자는 로그인 정보 확인, 구독 취소, 환불 가능 여부를 지원팀에 문의할 수 있습니다.

3. 휴대폰·신원 인증에서 막힐 때

전화번호 확인 화면이 나오면 SMS를 받을 수 있는 지원 지역의 휴대폰 번호를 사용합니다. Anthropic은 VoIP, 유선전화, 문자 수신이 안 되는 번호를 받지 않는다고 안내합니다. 코드가 5분 이상 오지 않으면 번호를 다시 확인하고 새 코드를 요청해 가장 최근 코드만 입력하세요.

일부 사용 사례에서는 정부 발급 사진 신분증과 휴대폰 카메라를 이용한 신원 확인이 나타날 수 있습니다. 화면의 공식 절차에서만 진행하고, 촬영이 흐리거나 문서가 만료됐으면 다시 촬영합니다. 반복 실패 시 우회 방법을 찾지 말고 공식 지원에 문의하세요.

4. 계정 보안이 의심될 때

본인이 요청하지 않은 로그인 메일이나 인증 코드는 사용하지 말고 누구에게도 전달하지 마세요. 로그인할 수 있다면 웹 Claude의 Settings → Account → Log Out으로 모든 활성 세션에서 로그아웃할 수 있습니다. Google 계정을 사용했다면 Google 보안 페이지에서 최근 로그인과 연결 앱도 확인하세요.

5. FAQ

Claude 비밀번호를 재설정할 수 있나요?

Claude는 Google 로그인 또는 이메일 보안 링크를 사용하므로 일반적인 Claude 전용 비밀번호 재설정 메뉴가 없습니다. Google 방식이면 Google 계정 비밀번호를 관리하고, 이메일 방식이면 새 로그인 링크를 받으세요.

메일 링크를 휴대폰에서 열었더니 코드가 나옵니다.

정상적인 교차 기기 절차일 수 있습니다. 그 코드를 로그인 메일을 요청한 원래 기기의 Claude 화면에 입력하세요.

앱을 삭제하면 대화가 사라지나요?

앱 재설치 전에 정확한 계정과 로그인 방식을 확인하세요. 다른 계정으로 로그인하면 대화가 사라진 것처럼 보일 수 있습니다. 계정을 삭제하거나 새 계정을 만들 필요는 없습니다.
