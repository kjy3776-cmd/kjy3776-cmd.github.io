인스타그램 알림 안 올 때: 아이폰·갤럭시 해결 7단계

2026-09-15 확인·SNS/메신저Instagram알림DM

목차

  1. 30초 원인 구분
  2. 해결 7단계
  3. 증상별 확인표
  4. FAQ

인스타그램 DM·댓글·팔로우 알림이 갑자기 오지 않는다면 인스타그램 앱 안의 알림 설정과 휴대폰 운영체제의 알림 권한을 따로 확인해야 합니다. 둘 중 하나라도 꺼져 있으면 알림이 표시되지 않을 수 있습니다.

1. 30초 안에 원인 구분

  1. 인스타그램 앱을 열어 새 DM이나 활동이 실제로 있는지 확인합니다.
  2. 앱을 열었을 때만 새 내용이 보이면 휴대폰 알림 권한이나 집중 모드를 먼저 봅니다.
  3. 특정 사람의 DM·게시물만 안 오면 해당 대화나 계정별 알림 설정을 봅니다.
  4. 모든 종류가 안 오면 Instagram의 전체 알림 일시 중지와 휴대폰의 앱 알림을 모두 확인합니다.

2. 해결 7단계

1단계: Instagram의 전체 알림 일시 중지 확인

Instagram에서 프로필 → 오른쪽 위 메뉴(≡) → 알림으로 이동합니다. 모두 일시 중단이나 수면 모드가 켜져 있다면 끄고 시험합니다. 메뉴 이름은 앱 버전과 계정에 따라 조금 다를 수 있습니다.

2단계: 필요한 알림 종류 켜기

같은 알림 화면에서 게시물·스토리 및 댓글, 팔로잉 및 팔로워, 메시지, 통화, 라이브 방송 및 릴스를 각각 확인합니다. DM만 문제라면 메시지와 메시지 요청 알림부터 켭니다. 특정 계정 게시물 알림은 그 계정 프로필의 알림(종 모양)에서 따로 설정할 수 있습니다.

3단계: 아이폰 알림 권한 확인

아이폰은 설정 → 알림 → Instagram에서 알림 허용을 켭니다. 잠금 화면·알림 센터·배너 중 원하는 표시 위치와 사운드도 확인하세요. Apple 공식 안내처럼 앱별 설정에서 알림 표시 방식이 따로 관리됩니다.

4단계: 갤럭시·안드로이드 알림 권한 확인

설정 → 알림 → 앱 알림 → Instagram에서 알림을 켭니다. Android 공식 안내에 따르면 기기별 메뉴가 다를 수 있으며, 앱의 전체 알림뿐 아니라 개별 알림 카테고리도 꺼져 있을 수 있습니다. 알림이 ‘무음’으로 지정됐는지도 확인합니다.

5단계: 집중 모드·방해 금지 해제

아이폰의 집중 모드나 안드로이드의 방해 금지가 켜져 있으면 알림이 조용히 처리될 수 있습니다. 빠른 설정에서 잠시 끄고 DM을 받아 보세요. 계속 사용할 모드라면 Instagram을 허용 앱으로 추가합니다.

6단계: 앱과 휴대폰 상태 새로 고침

  1. Instagram을 완전히 종료하고 다시 엽니다.
  2. Wi-Fi와 모바일 데이터를 바꿔 시험합니다.
  3. 앱 스토어에서 Instagram을 업데이트합니다.
  4. 휴대폰을 재시작한 뒤 다른 계정에서 시험 DM을 보냅니다.

로그아웃이나 재설치 전에 로그인 이메일·전화번호와 2단계 인증 수단에 접근할 수 있는지 확인하세요.

7단계: 마지막으로 재로그인·재설치

위 설정이 모두 정상인데도 계속 안 되면 로그아웃 후 다시 로그인합니다. 재설치는 임시 파일 문제를 정리할 수 있지만 초안이나 로그인 상태가 사라질 수 있으므로 마지막에 진행하세요. 여러 사용자에게 동시에 발생하면 서비스 문제일 수 있으니 잠시 뒤 다시 확인합니다.

4. FAQ

알림을 켰는데 배너가 안 뜹니다.

전체 허용과 배너 표시는 별도 설정일 수 있습니다. 아이폰은 Instagram 알림에서 배너를, 안드로이드는 해당 알림 카테고리가 ‘알림’인지 ‘무음’인지 확인하세요.

메시지 요청 알림도 따로 있나요?

네. Instagram의 메시지 알림 안에서 일반 메시지와 요청이 나뉠 수 있습니다. 모르는 계정의 메시지를 기다린다면 요청 항목도 확인하세요.

재설치하면 해결되나요?

설정이나 서버 문제에는 효과가 없을 수 있습니다. 앱 설정 → 휴대폰 권한 → 집중 모드 → 업데이트 순서로 확인한 뒤 마지막 수단으로 사용하세요.

한 줄 요약

Instagram의 알림 일시 중지 해제 → 알림 종류 선택 → 아이폰·안드로이드 앱 권한 → 집중 모드 확인 → 업데이트·재시작 → 재로그인·재설치 순서로 점검하세요.
