Adobe Photoshop ‘스크래치 디스크가 꽉 찼기 때문에 요청을 완료할 수 없음’ 해결 7단계

Photoshop에서 “스크래치 디스크가 꽉 찼기 때문에 요청을 완료할 수 없음” 또는 “스크래치 디스크가 꽉 찼기 때문에 Photoshop을 초기화할 수 없음”이 보인다면 RAM만의 문제가 아닙니다. Photoshop은 작업 중 디스크를 임시 공간으로 쓰며, 지정된 드라이브의 공간이 부족하면 작업 중에도 시작 전에도 멈출 수 있습니다. 같은 ‘꽉 참’ 오류여도 열려 있는 파일을 아직 저장하지 못했는지에 따라 안전한 첫 조치가 다릅니다. 아래 내용은 2026년 9월 27일 Adobe와 Microsoft 공식 문서를 대조한 Windows용 안내이며 특정 PC를 직접 수리했다는 뜻은 아닙니다.

1. 1분 해결 요약

  1. 작업 중 오류라면 Photoshop을 강제로 종료하지 마세요. 우선 다른 이름·다른 저장 드라이브로 저장 가능한지 확인합니다.
  2. Photoshop의 편집 → 환경 설정 → 스크래치 디스크에서 선택된 드라이브와 여유 공간을 확인합니다. 실행이 안 된다면 Windows 파일 탐색기에서 C:와 다른 작업 드라이브의 공간부터 봅니다.
  3. Windows 설정 → 시스템 → 저장소 → 정리 권장 사항에서 삭제 대상을 직접 검토하거나 자신의 불필요한 파일을 다른 드라이브로 옮깁니다. Adobe는 기본 스크래치 디스크에 최소 100GB 여유 공간 확보를 안내합니다.
  4. 공간이 충분한 다른 드라이브를 스크래치 디스크로 선택하고 Photoshop을 다시 시작합니다. 시작 자체가 안 되면 실행할 때 Ctrl+Alt를 누르는 Adobe의 디스크 선택 경로를 시도합니다.

멈춤 기준: 저장되지 않은 작업이 남았거나 삭제할 파일의 용도를 모르면 임시 파일·휴지통·환경 설정을 먼저 지우지 마세요.

2. 증상별 원인표

보이는 상황가능한 원인우선 확인
편집·필터·저장 중 요청을 완료할 수 없음큰 문서·작업 내역으로 임시 디스크 공간 소진미저장 작업 보호, 지정 드라이브 여유 공간
Photoshop 시작 전 초기화할 수 없음기본 스크래치 디스크 공간 부족파일 탐색기의 디스크 공간, 시작 시 디스크 선택
C:에는 공간이 있는데 같은 오류다른 드라이브가 선택됐거나 작업에 필요한 공간 부족스크래치 디스크 설정·우선순위
공간을 확보했는데 오류가 반복됨재시작 전 설정 미적용, 임시 파일 또는 환경 설정 문제 가능성저장 후 재시작, 마지막에 설정 재검토
특정 대형 파일·복잡한 작업에서만 발생작업 내역·자동 복구 데이터의 임시 공간 사용 증가문서 사본 저장 후 작업 내역 설정

표는 원인을 확정하는 검사가 아니라 다음 단계를 고르는 분기입니다. ‘디스크 꽉 참’과 손상된 PSD, GPU 오류, 계정 오류는 서로 다른 문제일 수 있습니다.

3. 쉬운 방법부터 해결하는 7단계

1단계: 열린 작업을 먼저 보호

Photoshop이 살아 있다면 새 필터·되돌리기 초기화·강제 종료를 멈춥니다. 파일 → 다른 이름으로 저장에서 여유 공간이 있는 다른 내부 드라이브에 PSD 또는 필요한 원본 형식의 새 사본을 저장해 보세요. 저장 공간 오류 때문에 저장도 안 되면 프로그램을 열어 둔 채 Windows에서 삭제해도 되는 자신의 파일을 신중히 옮겨 공간을 확보합니다. 저장 성공 여부를 확인하기 전에는 앱 종료나 임시 파일 삭제를 하지 마세요. Photoshop의 임시 파일은 원본 PSD와 동일한 백업이 아닙니다.

2단계: 실제로 선택된 스크래치 디스크와 여유 공간 확인

앱이 열리면 Windows Photoshop의 편집 → 환경 설정 → 스크래치 디스크에서 체크된 드라이브를 확인합니다. 파일 탐색기 내 PC에서 그 드라이브의 여유 공간을 비교하세요. 기본값이 C:라고 가정하지 마세요. Adobe 한국어 문서는 기본 스크래치 디스크에서 최소 100GB의 공간 확보를 안내합니다. 이는 문서 크기와 작업에 무관한 ‘무조건 실행 가능/불가’ 경계가 아니라 문제 해결을 위한 권장 여유 공간입니다.

3단계: Windows에서 삭제 대상을 검토하며 공간 확보

Windows 11은 설정 → 시스템 → 저장소 → 정리 권장 사항에서 임시 파일과 큰 파일을 검토합니다. Windows 10은 작업 표시줄에서 디스크 정리를 검색해 드라이브와 삭제 항목을 직접 선택합니다. Microsoft의 버전별 저장소 안내에 따라 자신에게 불필요한 항목만 고르세요. 다운로드 폴더·휴지통·이전 Windows 설치에는 다시 필요한 자료나 복구 경로가 있을 수 있습니다. 특히 이전 Windows 설치 삭제는 이전 버전으로 돌아갈 수 없게 할 수 있습니다. Storage Sense는 기본적으로 시스템 드라이브에서 동작하고 다운로드·클라우드 파일도 설정 없이는 건드리지 않으므로, 다른 스크래치 디스크의 공간은 따로 확인하세요. 삭제가 불안하면 자신의 완료된 프로젝트 사본을 확인한 뒤 다른 드라이브에 옮기는 편이 안전합니다.

4단계: 공간 있는 드라이브를 추가·우선 지정

Photoshop이 열리면 편집 → 환경 설정 → 스크래치 디스크에서 여유 공간이 충분한 드라이브를 선택하고, 가능하면 빠른 드라이브를 위쪽 우선순위로 둔 뒤 확인하고 앱을 다시 시작합니다. Adobe는 Windows용 스크래치 디스크 형식으로 NTFS·exFAT·FAT32를 안내합니다. Photoshop이 시작도 안 되면 Windows에서 실행할 때 Ctrl+Alt를 누른 상태로 새 스크래치 디스크를 고르는 Adobe의 시작 경로를 사용합니다. 여기서도 기존 프로젝트 파일을 삭제하거나 다른 사람의 드라이브를 임의로 사용하지 마세요.

5단계: 남은 Photoshop 임시 파일은 앱 종료 후에만 구분

먼저 열린 작업을 저장하고 Photoshop을 완전히 종료하세요. Adobe는 Windows의 C:\에서 이름이 Photoshop Temp로 시작하는 파일 삭제를 안내합니다. 다만 현재 열려 있는 Photoshop의 파일이거나 복구가 필요한 작업인지 구분하지 않은 채 폴더 전체, %TEMP% 전체, PSD 원본을 일괄 삭제하지 마세요. 파일을 확실히 식별하지 못한다면 이 단계를 건너뛰고 4단계의 디스크 변경 또는 Adobe 지원을 이용하세요. 정리한 뒤 Photoshop을 다시 시작해 오류를 확인합니다.

6단계: 반복되는 큰 작업에서는 작업 내역 수 조정

저장한 프로젝트를 기준으로 편집 → 환경 설정 → 성능 → 작업 내역 및 캐시에서 작업 내역 상태 수를 필요한 수준으로 낮춥니다. Adobe 문서의 기본값은 50이며, 큰 이미지 전체에 필터를 반복하면 작업 내역이 디스크를 더 쓸 수 있습니다. 줄이면 과거 단계로 되돌릴 수 있는 범위가 감소하므로 편집본을 먼저 별도 저장하세요. 자동 복구를 끄는 것을 첫 해결책으로 권하지 않습니다. Adobe는 큰 파일 작업에서 복구 정보 자동 저장을 선택하도록 안내합니다.

7단계: 계속 실패할 때만 환경 설정 재설정

공간·디스크 선택·재시작을 확인했는데도 같은 오류가 반복될 때 마지막으로 Adobe의 환경 설정 재설정을 검토하세요. 설정값·작업 공간·개인화 항목이 기본값으로 돌아갈 수 있으므로 현재 설정을 기록하고 동기화·백업 가능 여부를 확인합니다. Photoshop을 종료한 뒤 시작할 때 Shift+Alt+Ctrl을 눌러 설정 파일 삭제 확인 창에서 진행합니다. 재설정 후 스크래치 디스크를 다시 구성해야 합니다. 회사·학교 장비라면 관리자의 정책을 먼저 확인하세요.

4. 정상 확인과 실패 시 다음 조치

  • Photoshop을 재시작해 시작 오류가 사라졌는지, 작은 테스트 문서가 열리고 별도 사본으로 저장되는지 확인합니다.
  • 문제가 났던 문서를 원본을 보존한 채 다시 열어 같은 작업을 조금씩 수행합니다. 큰 작업에서만 재발하면 드라이브 여유 공간과 작업 내역 설정을 다시 봅니다.
  • 여전히 실패하면 오류 문구·Photoshop 버전·Windows 버전·스크래치 디스크 문자와 남은 용량·특정 파일에서만 발생하는지를 기록해 Adobe 공식 문제 해결 문서 또는 조직의 IT 담당자에게 전달합니다. 파일 손상이나 GPU 오류라면 이 글의 디스크 절차로 단정하지 마세요.

5. 데이터·결제·계정·보안 주의

  • 데이터: 저장하지 않은 PSD가 있으면 강제 종료·임시 파일 삭제·전체 퍼지·환경 설정 재설정 전에 저장 가능성을 확인하세요. 휴지통 비우기와 이전 Windows 설치 삭제는 되돌리기 어려울 수 있습니다.
  • 결제: 이 오류만으로 새 Adobe 플랜 결제나 유료 ‘디스크 클리너’를 먼저 구매할 필요는 없습니다. 추가 저장 장치를 고를 때도 공식 호환 형식과 실제 여유 공간을 확인하세요.
  • 계정: Creative Cloud 로그아웃·계정 변경은 스크래치 디스크 공간 해결 단계가 아닙니다. 회사·학교 관리 장치의 권한 변경은 관리자에게 문의하세요.
  • 보안: ‘포토샵 임시 파일 자동 삭제’라는 비공식 앱이나 확장 프로그램을 설치하지 마세요. 필요한 파일을 먼저 확인하고 Windows·Adobe의 공식 경로만 사용하세요.

6. FAQ

C:에 여유 공간이 있는데도 왜 오류가 나나요?

Photoshop이 다른 스크래치 디스크를 사용하거나, 현재 문서의 작업을 이어 가기에 필요한 임시 공간이 부족할 수 있습니다. 설정에서 선택된 드라이브와 각 드라이브의 여유 공간을 확인하세요.

Photoshop Temp 파일을 전부 삭제해도 되나요?

아닙니다. 미저장 작업과 복구 가능성을 먼저 확인하세요. Photoshop을 완전히 종료한 뒤 Adobe가 안내한 C:\의 Photoshop Temp로 시작하는 파일만 식별해 처리하고, 확신할 수 없다면 삭제하지 마세요.

100GB가 없으면 Photoshop을 전혀 쓸 수 없나요?

Adobe가 기본 스크래치 디스크에 최소 100GB 확보를 안내하는 것은 문제 해결을 위한 권장치입니다. 실제 필요한 공간은 이미지 크기·레이어·작업 내역에 따라 달라집니다.

앱이 아예 실행되지 않으면 어떻게 하나요?

Windows에서 Photoshop 시작 시 Ctrl+Alt를 누르면 새 스크래치 디스크를 선택할 수 있다는 Adobe의 안내를 따르세요. 여유 공간이 있는 지원 형식의 드라이브를 선택한 뒤 다시 실행합니다.

한 줄 요약

미저장 작업 보호 → 선택된 드라이브 공간 확인 → Windows 정리 → 다른 스크래치 디스크 선택·재시작 → 임시 파일·작업 내역·환경 설정은 신중히 순서로 점검하세요.
