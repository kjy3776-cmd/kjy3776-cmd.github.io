이 사이트의 기능

막힘해결은 PC·프로그램 도움말을 제공하는 정적 사이트입니다. 현재 회원가입, 댓글, 파일 업로드 기능을 제공하지 않습니다. 사이트 검색은 브라우저 안에서 글 목록을 검색합니다.

Google 광고와 쿠키

이 사이트에는 Google AdSense 코드가 포함되어 있습니다. Google을 포함한 제3자 광고 제공업체는 쿠키를 사용하여 이용자의 이 사이트 또는 다른 사이트 방문 기록을 바탕으로 광고를 게재할 수 있습니다. Google과 파트너는 광고 쿠키를 통해 방문 기록에 맞춘 광고를 제공할 수 있습니다.

Google 내 광고 센터에서 개인 맞춤 광고 설정을 관리할 수 있습니다. 다른 광고 업체의 선택 사항은 광고 선택 안내를 참고하세요. 브라우저 설정에서도 쿠키를 삭제하거나 차단할 수 있습니다.

Google이 데이터를 사용하는 방식은 Google 파트너 사이트 데이터 안내와 Google 개인정보처리방침을 확인하세요.

호스팅과 외부 링크

사이트는 GitHub Pages에서 제공됩니다. 접속 과정의 데이터 처리는 GitHub 개인정보처리방침을 따릅니다. 외부 링크를 열면 해당 서비스의 개인정보 안내가 적용됩니다.

제휴 링크

현재 HEIC 가이드의 제품 링크는 일반 공식 링크입니다. 추후 제휴 수수료가 발생하는 링크를 추가하면 해당 글에서 알립니다.
